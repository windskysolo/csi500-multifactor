## 一、读懂本文档所需的基础概念

### 1.1 IC 和 IC_IR 是什么

**IC（Information Coefficient，信息系数）**：衡量因子值和下期股票收益之间的相关性。

- 每个月末，对所有中证500成分股，计算因子值与下月收益的 Spearman 秩相关
- IC 接近 +1：因子高的股票收益更好（正向因子）
- IC 接近 -1：因子高的股票收益更差（负向因子，如换手率）
- IC 接近 0：因子无预测力

**IC_IR（IC 信息比率）**：= IC 均值 / IC 标准差

- 衡量因子的「稳定性」——不只看平均预测力，更看能不能每期都表现一致
- IC_IR 的绝对值 ≥ 0.30 才算统计显著有效
- IC_IR 越高，合成时自动获得越大的权重

### 1.2 因子健康状态定义

| 状态 | 含义 | 处理思路 |
|------|------|---------|
| **stable（稳定）** | 验证期 IC_IR 与训练期方向一致，衰减 < 50% | 放心用，维持正常权重 |
| **weak（偏弱）** | 方向未变，但验证期 IC_IR 衰减 50-75% | 保留，权重自动缩减 |
| **warn（警告）** | 验证期 IC_IR 接近 0 或已转负 | 保留观察，IC_IR 权重接近 0 |
| **reverse（反转）** | 验证期 IC_IR 方向明确反转 | 需要诊断，IC_IR 会自动给负权重 |

### 1.3 什么是 PIT（Point-in-Time）

**PIT** 是本项目最重要的数据处理原则：调仓日 T 只能使用 T 日之前已公开的数据。

财务数据有「公告延迟」——2024 年 Q3 的报告可能在 2024 年 10 月底才公布。因此不能用「报告期截止日」，必须用「公告日」来过滤数据，否则会用到未来信息，回测结果虚高。

### 1.4 四道评估门槛

每个候选因子必须通过四关才能入池：

| Gate | 内容 | 要求 |
|------|------|------|
| Gate 0 | 数据覆盖率 | 平均每期有效股票数 ≥ 宇宙的 80% |
| Gate 1 | IC 统计显著 | IC_IR ≥ 0.30，且 t 统计量 ≥ 2 |
| Gate 2 | 时间错位检验 | lead_ratio < 1.5x（防止用了未来数据） |
| Gate 3 | 验证期稳定 | 验证期 IC_IR ≥ 0.20，方向不变 |

### 【估值维度】衡量股票有多便宜

#### F01 · ep_ttm — 滚动市盈率倒数（收益率）

**状态：weak（偏弱）**  
**预期方向：+ （值越高越好）**

**是什么**：用「过去12个月累计净利润 / 当前总市值」衡量一块钱市值对应多少净利润。数值越高，股票越便宜，价值溢价越大。

**计算公式**：
```
ep_ttm = TTM净利润 / 总市值
```
- TTM = 过去4个季度累计值（消除季节性）
- 净利润从财务报告取，严格用公告日（Annodt）过滤
- 总市值从每日行情数据取 T 日收盘后的值

**经济逻辑**：价值效应——便宜的股票长期有更高收益。但 A 股价值因子有周期性，在成长/科技行情中会持续跑输。

**实际数据**：

| 指标 | 数值 |
|------|------|
| 训练期 IC_IR | +0.473 |
| 验证期 IC_IR | +0.119 |
| 衰减率 | -75%（偏大但方向保持） |
| 训练期正向占比 | 64.2% |
| lead_ratio | < 1.5x（无未来数据风险）|

**为什么验证期衰减**：2021-2022 年新能源/半导体赛道主导，传统价值估值逻辑失效。这是风格周期，不是因子本身有问题。

---

#### F02 · cfp — 现金流收益率

**状态：weak（偏弱）**  
**预期方向：+（值越高越好）**

**是什么**：TTM 经营现金流 / 总市值。类似 ep_ttm，但用「真实现金流入」代替利润，对盈利质量的区分更强——利润可以做账，现金流很难造假。

**计算公式**：
```
cfp = TTM经营活动现金流净额 / 总市值
```

**经济逻辑**：现金流估值比盈利估值更稳健，A 股财务操控现象相对常见，cfp 能过滤部分「纸面利润」股票。

**实际数据**：

| 指标 | 数值 |
|------|------|
| 训练期 IC_IR | +0.441 |
| 验证期 IC_IR | +0.190 |
| 衰减率 | -57% |
| 训练期正向占比 | 65.1% |

**与 ep_ttm 的关系**：两者相关性约 0.5-0.6，不是完全冗余。cfp 在价值维度提供了补充视角（现金流 vs 利润），验证期比 ep_ttm 更稳定一些。

### 【财务质量维度】衡量公司盈利的质量和稳健性

---

#### F03 · q_roe — 单季净资产收益率

**状态：warn（警告）**  
**预期方向：+（值越高越好）**

**是什么**：当期单季度净利润 / 平均净资产。衡量「最近这一季度的盈利能力有多强」。比全年累计 ROE 对近期变化更敏感。

**计算公式**：
```
q_roe = 单季净利润 / 当期平均净资产  （来自 Tushare indicator_pit 的 q_roe 字段）
```

**经济逻辑**：高 ROE 公司能持续为股东创造价值，市场通常给予估值溢价。

**实际数据**：

| 指标 | 数值 |
|------|------|
| 训练期 IC_IR | +0.486 |
| 验证期 IC_IR | **-0.098**（已接近反转！）|
| 衰减率 | > 100%（方向接近翻转）|

**为什么警告**：2021-2022 年「高成长、低 ROE」的科技赛道股跑赢了「高 ROE、低成长」的传统企业，导致 ROE 信号临时失效。这是结构性风格问题，不代表 ROE 逻辑本身错误。

---

#### F04 · gross_margin — 毛利率

**状态：warn（警告）**  
**预期方向：+（值越高越好）**

**是什么**：（营业收入 - 营业成本）/ 营业收入。高毛利率通常意味着企业有竞争护城河（品牌、专利、网络效应）。

**计算公式**：
```
gross_margin = 毛利润 / 营业收入（来自 indicator_pit 的 grossprofit_margin 字段）
```

**经济逻辑**：高毛利率 = 定价权强 = 护城河宽。长期来看，能维持高毛利的公司通常是行业龙头。

**实际数据**：

| 指标 | 数值 |
|------|------|
| 训练期 IC_IR | +0.333 |
| 验证期 IC_IR | -0.040 |
| 衰减率 | > 100% |

**注意**：金融股（银行/保险）的毛利率定义与其他行业不同，因此因子值会被置为 NaN（在预处理阶段过滤）。

#### F05 · piotroski_f — Piotroski 财务健康评分

**状态：reverse（反转）** — 唯一确认方向反转的因子  
**预期方向：+ 在训练期（验证期已反转，当前 IC_IR 权重为负）**

**是什么**：由 7 个二元财务健康指标加总，满分 7 分，分数越高代表财务状况越健康。

**计算公式（7 个子项，每项满足得 1 分）**：
```
F1 = ROA > 0（当期盈利）
F2 = TTM 经营现金流 > 0
F3 = ROA 同比改善
F4 = 经营现金流 > 净利润（现金质量好）
F5 = 资产负债率同比下降（去杠杆）
F8 = 毛利率同比上升
F9 = 资产周转率同比上升
```
有效分项 < 5 个时，结果为 NaN（数据不足）。

**实际数据**：

| 指标 | 数值 |
|------|------|
| 训练期 IC_IR | +0.615（训练期最强因子之一！）|
| 验证期 IC_IR | **-0.200**（方向完全反转）|

**反转原因分析（两个假说）**：

假说 A（风格周期）：2021-22 年市场偏好高成长/高估值赛道，财务健康的传统行业公司系统性跑输。如果是这个原因，风格轮转后信号会自然恢复。

假说 B（A 股会计失配）：F-score 基于美国 GAAP 设计，部分子项在 A 股语境下方向本身就是错的。如果是这个原因，需要修复或剔除问题子项。

**当前处理**：IC_IR 权重机制自动给它**负权重**（等于反向使用），合成信号中 F-score 低的股票反而得到更高分。暂不剔除，等候诊断结论。

#### F06 · roe_delta — ROE 同比变化

**状态：warn（警告）**  
**预期方向：+（值越高越好）**

**是什么**：当期 ROE 减去上年同期 ROE（百分点差值）。衡量「盈利能力有没有在改善」。

**计算公式**：
```
roe_delta = ROE（当期） - ROE（上年同期）
（例如：Q3 2023 对比 Q3 2022，Annual 2023 对比 Annual 2022）
```

**经济逻辑**：ROE 改善趋势比 ROE 绝对水平更具预测力——公司从 5% 升到 10% 比一直维持 15% 更受市场追捧。

**实际数据**：

| 指标 | 数值 |
|------|------|
| 训练期 IC_IR | +0.483 |
| 验证期 IC_IR | -0.040 |
| 衰减率 | > 100% |

**与 roe_delta_3q 的区别**：roe_delta 是跨年同比（12 个月窗口），roe_delta_3q 是过去 3 个季度的变化（更近期、更短窗口）。验证期 roe_delta_3q 更稳定（IC_IR = +0.338），说明近期加速度信号比跨年比更有效。

---

#### F07 · roe_delta_3q — ROE 三季度改善速度

**状态：stable（稳定）**  
**预期方向：+（值越高越好）**

**是什么**：最新单季 ROE 减去 3 个季度前的单季 ROE。衡量最近 9 个月 ROE 的加速或减速。

**计算公式**：
```
roe_delta_3q = q_roe（最新季） - q_roe（3季度前）
```
需要至少 4 期有效季度数据，否则返回 NaN。

**经济逻辑**：「加速盈利改善」是比「高盈利水平」更强的前瞻信号。企业从底部反转的初期，绝对 ROE 可能仍不高，但变化方向已经告诉市场基本面在改善。

**实际数据**：

| 指标 | 数值 |
|------|------|
| 训练期 IC_IR | +0.518 |
| 验证期 IC_IR | +0.338（方向稳定！）|
| 衰减率 | -35% |

**为什么比 roe_delta 稳定**：3 季度窗口更敏感于近期变化，避免了因为「去年基数」导致的噪音。即使在 2021-22 反质量行情中，ROE 近期加速的信号仍有效。

#### F08 · rev_yoy — 营收同比增速

**状态：warn（警告）**  
**预期方向：+（值越高越好）**

**是什么**：本期营业收入 / 上年同期营业收入 - 1（来自 Tushare indicator_pit 的 or_yoy 字段）。

**经济逻辑**：营收增速比利润增速更稳定（不受会计政策影响）。高增速意味着公司业务扩张。

**实际数据**：

| 指标 | 数值 |
|------|------|
| 训练期 IC_IR | +0.448 |
| 验证期 IC_IR | -0.020 |
| 衰减率 | > 100% |

**验证期失效的根本原因**：2020 年疫情导致极低基数，2021 年营收同比增速虚高（不是真正的成长加速，而是低基数效应）；2022 年基数正常化，增速骤降，但公司实际经营并未恶化。静态同比增速无法区分「真实成长」和「基数效应」。

**已有更好的替代信号**：`rev_acceleration`（F09）直接衡量增速的变化方向，绕过了基数问题。

---

#### F09 · rev_acceleration — 营收增速加速度（最新加入）

**状态：stable（稳定）** — 17 个因子中验证期表现最强  
**预期方向：+（值越高越好）**

**是什么**：本期同比增速 - 上期同比增速。不关注「增速是多少」，只关注「增速有没有在提升」。

**计算公式**：
```
本期同比增速 = (Q0 - Q4) / |Q4|   （Q0=最新季，Q4=4季度前）
上期同比增速 = (Q1 - Q5) / |Q5|   （Q1=上一季，Q5=5季度前）
rev_acceleration = 本期同比增速 - 上期同比增速
```
分母取绝对值，避免去年同期亏损时方向颠倒。

**经济逻辑**：投资者更看重增速的「拐点」而非水平。增速从 10% 升到 20% 的公司比一直维持 30% 的公司更受市场追捧（预期差效应）。

**实际数据**：

| 指标 | 数值 |
|------|------|
| 训练期 IC_IR | +0.574 |
| 验证期 IC_IR | **+0.725**（验证期比训练期还强！）|
| lead_ratio | < 1.5x（无未来数据风险）|

**为什么在 2021-22 反质量行情中仍然有效**：rev_acceleration 绕开了利润端噪音，直接测量营收动能的变化。即使在成长赛道主导的市场中，营收加速依然是有效的选股信号。

#### F10 · gross_margin_trend — 毛利率同比趋势

**状态：warn（警告）**  
**预期方向：+（值越高越好）**

**是什么**：当期累计毛利率 - 上年同期累计毛利率（百分点差值）。衡量护城河在变宽还是变窄。

**计算公式**：
```
gross_margin_trend = grossprofit_margin（当期） - grossprofit_margin（上年同期）
```
用同比对比（Q2 vs 去年 Q2）天然消除季节性。

**实际数据**：

| 指标 | 数值 |
|------|------|
| 训练期 IC_IR | +0.429 |
| 验证期 IC_IR | -0.069 |

**注意**：与 gross_margin（F04，毛利率水平）高度相关（r ≈ 0.6-0.7），两者在验证期均失效，体现的是同一个「质量信号在 2021-22 年失效」问题。研究方向建议：将 gross_margin 和 gross_margin_trend 合并为一个综合毛利率因子，减少冗余。

#### F11 · hk_hold_ratio — 北向持仓比例

**状态：stable（稳定）**  
**预期方向：+（值越高越好）**

**是什么**：沪深港通北向资金持有某股票的股份 / 该股票流通股总数。外资持仓比例越高，说明「聪明钱」越认可这家公司。

**计算公式**：
```
hk_hold_ratio = 港股通持股数 / 流通股数（来自 hk_hold.parquet，取 T 日最近快照）
```

**经济逻辑**：北向资金以机构为主，信息处理能力和价值投资理念强于 A 股散户。其持仓比例是市场对股票质量的一个高质量代理信号。

**实际数据**：

| 指标 | 数值 |
|------|------|
| 训练期 IC_IR | +0.579（只有 47 期有效，2014 年才开通沪深港通）|
| 验证期 IC_IR | +0.425 |
| 衰减率 | -27% |
| 合成权重 | 降权 0.5（早期覆盖不足补偿）|

**覆盖限制**：2014 年 11 月 17 日沪港通开通前，该因子全部为 NaN，属正常现象。

#### F12 · hk_hold_chg — 北向持仓比例变化

**状态：weak（偏弱）**  
**预期方向：+（值越高越好）**

**是什么**：最近 30 个交易日内，北向持仓比例的变化量（百分点）。衡量外资是在买入还是卖出。

**计算公式**：
```
hk_hold_chg = ratio(T日) - ratio(T-30个交易日)
```

**经济逻辑**：北向资金「加仓」是看多信号；「减仓」是看空信号。动态变化比静态持仓比例更敏感于近期预期变化。

**实际数据**：

| 指标 | 数值 |
|------|------|
| 训练期 IC_IR | +0.497（只有 46 期有效）|
| 验证期 IC_IR | +0.154 |
| 衰减率 | -69% |

**为什么比 hk_hold_ratio 衰减更大**：动态变化信号（流量）比静态持仓（存量）噪音更大，在短期市场波动中易产生虚假信号。

#### F13 · holder_chg — 股东人数变化率

**状态：stable（稳定）**  
**预期方向：+（值越高越好）**

**是什么**：股东人数减少 = 筹码集中 = 利好。因子值 = -(本期股东人数 - 上期股东人数) / 上期股东人数。负号使「股东人数减少」的股票因子值更高。

**计算公式**：
```
holder_chg = -(holder_num_latest - holder_num_prev) / holder_num_prev
```
PIT 处理：只用 available_date（公告日）≤ T 的数据，取最新两期快照计算。最新期距 T 超过 18 个月视为过期，返回 NaN。

**经济逻辑**：A 股特有信号。股东人数减少意味着筹码从散户手中向机构集中（筹码集中度提升），市场预期通常偏正向。反之，股东人数暴增往往伴随散户蜂拥而入的短期情绪顶部。

**实际数据**：

| 指标 | 数值 |
|------|------|
| 训练期 IC_IR | +0.379 |
| 验证期 IC_IR | +0.319 |
| 衰减率 | -16%（极低！）|

**为什么跨周期稳定**：筹码集中度机制与市场风格关联弱，不论是价值行情还是成长行情，机构资金集中持有的股票通常都有更好表现。

### 【动量/反转维度】衡量价格和基本面趋势

#### F14 · analyst_eps_revision — 分析师 EPS 修正幅度

**状态：stable（稳定）**  
**预期方向：+（值越高越好）**

**是什么**：近期分析师对 EPS 预期的上调或下调幅度。近期中位数 EPS / 远期中位数 EPS - 1。

**计算公式**：
```
近期 = 最近 90 天内的研报 EPS 预测（中位数）
远期 = 91-180 天前的研报 EPS 预测（中位数）
analyst_eps_revision = 近期中位数 / 远期中位数 - 1
```
两端各至少需要 2 份研报，否则返回 NaN（覆盖率约 25%，覆盖率偏低）。

**经济逻辑**：分析师集体上调 EPS 预期 = 基本面前景改善 = 前瞻性正向信号。这是项目中**唯一的基本面动量因子**（不是价格动量，是预期动量）。在 2021-22 科技行情中，分析师快速上调新能源/半导体 EPS，因此该因子在验证期表现良好。

**实际数据**：

| 指标 | 数值 |
|------|------|
| 训练期 IC_IR | +0.352 |
| 验证期 IC_IR | +0.332 |
| 衰减率 | -6%（极低！）|
| lead_ratio | 1.66x（轻微警告区，经济逻辑充分，保留）|

### 【风险特征维度】衡量股票的波动特性

---

#### F15 · ivol_60d — 60日特质波动率

**状态：stable（稳定）**  
**预期方向：-（值越低越好）**

**是什么**：用 CAPM 模型剥离市场风险后，个股收益的「自身波动」（残差标准差）。衡量股票特有的波动程度，与整个市场无关。

**计算公式**：
```
每日：ret_stock = alpha + beta × ret_market + epsilon
ivol_60d = std(epsilon, 过去60个交易日)
```
向量化 OLS（同时估计全部股票），停牌日用零收益补全后估计。

**经济逻辑**：「低特质波动」溢价效应（BAB Factor）。高特质波动的股票往往被散户当彩票追捧（彩票偏好），短期价格过高，后续超额收益为负。低特质波动的股票更可能是有护城河、盈利稳定的优质公司。

**实际数据**：

| 指标 | 数值 |
|------|------|
| 训练期 IC_IR | -0.675（负值！方向是低波动跑赢）|
| 验证期 IC_IR | -0.641 |
| 衰减率 | -5%（近乎零衰减，跨周期最稳定因子之一）|

**是项目里最稳定的因子**：无论 2012-20 的训练期还是 2021-22 的验证期，低特质波动溢价一直存在，几乎不受市场风格切换影响。

### 【流动性维度】衡量股票的交易难易程度

---

#### F16 · turn_20d — 20日平均换手率

**状态：stable（稳定）**  
**预期方向：-（值越低越好）**

**是什么**：过去 20 个交易日的自由流通换手率均值。换手率低 = 交易不活跃 = 低流动性溢价的享受方。

**计算公式**：
```
turn_20d = mean(turnover_rate_f, 过去20个交易日)
```
使用自由流通换手率（非总股本），更能反映实际活跃投资者的交易行为。

**经济逻辑**：低换手溢价——机构持股比例高、筹码稳定的股票换手率低，往往对应更好的长期收益；高换手股票经常是散户追捧的「热门股」，短期过高估值导致后续回调。

**实际数据**：

| 指标 | 数值 |
|------|------|
| 训练期 IC_IR | -0.689（整个因子池训练期最强因子！）|
| 验证期 IC_IR | -0.707（验证期比训练期还强！）|
| 衰减率 | +3%（负值，实际是增强而非衰减）|
| lead_ratio | 1.70x（警告区，经济逻辑充分，保留）|

**是整个因子池最稳定、最强的因子**：无论市场风格如何变化，低换手股票相对高换手股票的超额收益几乎每年都成立。

---

#### F17 · amihud — Amihud 非流动性指标

**状态：stable（偏弱方向稳定）**  
**预期方向：+（值越高越好）**

**是什么**：过去 20 个交易日，每天的「单位成交额价格冲击」的均值。数值越大 = 流动性越差。

**计算公式**：
```
日度：ratio_t = |ret_t| / amount_t（amount 单位：千元）
amihud = mean(ratio_t, 过去20个交易日，停牌日排除)
```

**经济逻辑**：非流动性溢价（Amihud 2002）。流动性差的股票有更高的「变现成本」，理性投资者要求更高的预期收益作为补偿（非流动性溢价）。

**实际数据**：

| 指标 | 数值 |
|------|------|
| 训练期 IC_IR | +0.492 |
| 验证期 IC_IR | +0.211 |
| 衰减率 | -57% |

### 【候补因子】通过评估但暂不入池

---

#### F18 · high_52w_v2 — 52 周高点比率（修正版）

**状态：通过全部四道门但暂缓入池**  
**预期方向：+（值越高越好）**

**是什么**：当前价格（T-20日）相对过去 52 周最高价的比率。比率接近 1 说明股票强势（接近高点），远小于 1 说明股票处于低谷。

**为什么有「v2」修正**：原版 high_52w 用 T 日收盘价做分子，但该价格也出现在「下期收益」的分母里，造成机械负相关（lead_ratio 高达 37.6x）。v2 改用 T-20 日收盘价为分子，彻底消除这个问题（lead_ratio 降至 0.09）。

**计算公式**：
```
high_52w_v2 = close_adj(T-20td) / max(high × adj_factor, 窗口[T-271td, T-20td])
```
其中分母取 252 个交易日（跳过最近 20 日）的最高后复权价。

**实际数据**：

| 指标 | 数值 |
|------|------|
| 训练期 IC_IR | +0.328（通过 Gate 1）|
| 验证期 IC_IR | 稳定（通过 Gate 3）|
| lead_ratio | 0.09（极低，通过 Gate 2）|

**为什么暂不入池**：加入 IC_IR 流水线测试后，策略整体 IR 从 0.341 暴跌至 0.091。根因：IC_IR 加权给它约 40% 的权重，但 2021-22 年动量因子整体失效，导致组合超额从 2.77% 跌至 0.56%。

**结论**：单因子层面是有效的价格动量信号，但目前时机不对（动量风格低谷期）。Ridge 流水线可能给它更合理的权重，有待测试。

## 四、五种信号合成方式与整体表现

本项目共有 **5 种信号合成方式**，均在 `训练期（2012-2020） + 验证期（2021-2022）` 范围内运行，测试集（2023-2025）锁定未动。

### 策略架构概述

**所有策略共享**：
- 同一份经过预处理（去极值 + 行业/市值中性化 + 标准化）的因子数据
- 同一组合优化框架：行业偏离 ±3%，单股偏离 ±1.5%，年化 TE 目标 6%，换手惩罚 λ=0.005
- T+1 开盘成交，含印花税（2023-08-28 前 10bps，之后 5bps）、佣金各 2.5bps、8bps 滑点

**五种策略的差异**：只有**信号合成方式**不同——即如何把 17 个因子合成一个选股分数。

---

### 4.0 策略零：baseline_icir_expanding（IC_IR 加权基线）

**信号方法**：IC_IR 加权，扩张窗口

**是什么**：这是最经典、最直接的多因子合成方式。每个因子在调仓日 T 的权重 = 该因子过去 24 个月 IC 的均值 / IC 的标准差（即 IC_IR）。IC_IR 越高，权重越大；IC_IR 为负的因子自动获得负权重（等于反向使用该因子），不需要手动指定方向。权重计算只用 T 之前的历史 IC，不含当期，无泄露风险。

**与 Ridge 的本质区别**：
- IC_IR 加权：每个因子权重独立估计，不考虑因子之间的相关性
- Ridge 回归：联合估计所有因子权重，通过 L2 正则化把高度相关的因子之间的权重更均匀地分配，抑制共线性引起的权重不稳定

## 六、读懂这些信息后的决策框架

### 6.1 什么时候应该换掉因子（调池）

以下情况才考虑从池中移除：

| 情况 | 例子 | 行动 |
|------|------|------|
| 发现了结构性错误（如数据污染）| piotroski_f 的假说 B：A 股会计失配 | 修复子项或移除 |
| 有更好的替代且相关性高 | rev_acceleration 已入池，rev_yoy 是否替换 | 保留两者（独立信号）|
| 连续多个验证窗口仍无改善 | 目前 warn 因子只有 2 年验证期数据 | 继续等待，不轻易删除 |

### 6.2 什么时候让权重机制自动处理（不调池）

以下情况 IC_IR 权重机制已经自动处理，不需要手动干预：

- **warn 因子**（q_roe 等 5 个）：IC_IR 近零 → 权重自动趋近 0 → 贡献极小
- **piotroski_f（reverse）**：IC_IR 为负 → 自动获得负权重 → 相当于反向使用
- **强因子（stable）**：IC_IR 高 → 权重自动偏高 → 自动贡献更多

**一句话总结**：在 IC_IR 加权流水线里，「调整权重」的事情系统已经在做了。你需要决策的是「调池」——什么时候换掉一个因子、什么时候加入新因子。

### 6.3 当前最优先的两个行动项

**行动 1（诊断，低成本）**：对 piotroski_f 做分期 IC 分析

把训练期按 2012-15、2016-18、2019-20、2021-22 分段，分别计算 IC_IR。
- 只有最后一段（2021-22）反转 → 风格周期，继续保留（IC_IR 会自动负向使用）
- 多个阶段都有反转 → 会计失配，需要逐项检查 7 个子指标，修复方向错误的那项

**行动 2（方向明确，可直接推进）**：在 Ridge 流水线中测试 high_52w_v2

`high_52w_v2` 在单因子层面是有效的价格动量信号（IC_IR=0.328，四道门全过）。它在 IC_IR 加权流水线失败的原因是「IC_IR 给了它过高权重」。Ridge 流水线通过 L2 正则化会更均衡地分配权重，预期结果可能好很多。
