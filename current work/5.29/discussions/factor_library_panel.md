# 因子库总面板

> 截至：2026-05-29  
> 数据来源：`reports/factor_evaluation/final_factors.json`、`current work/5.28/factor_guide.md`、`docs/research/factor_roadmap/factor_research_guide.md`  
> 评估区间：训练期 2012-2020（108期）/ 验证期 2021-2022（24期）  
> Gate 体系：Gate 0 覆盖率 ≥80% → Gate 1 IC_IR ≥ 0.30, t ≥ 2 → Gate 2 lead_ratio < 1.5x → Gate 3 验证期 IC_IR ≥ 0.20 且方向不变

## 一、入选因子（18 个）

17 个正式入池 + 1 个通过四道门但暂缓并入的候补（high_52w_v2）。

**状态说明**：stable（衰减<50%且方向不变）/ weak（方向不变，衰减50-75%）/ warn（接近0或大幅衰减）/ reverse（方向反转）

## 二、未入选因子（37 个）

来自 `final_factors.json` 的 excluded 列表，按维度/类型分组。

排除原因分类（简写）：
- **G1** Gate 1 不通过：IC_IR < 0.30 或 t < 2
- **G2** Gate 2 不通过：lead_ratio ≥ 2.0（疑似未来函数）
- **G3** Gate 3 不通过：验证期 IC_IR < 0.20 或方向反转
- **冗余** 与现有入选因子高度相关（|r| > 0.5）或信息量无增量
- **覆盖** 数据覆盖率不足（Gate 0）

---

### 2.1 价格动量 / 技术指标（12 个）

> 这是失败最集中的类别。核心问题：技术类信号周期为日/周级，月频调仓下 lead_ratio 极高；价格动量在 A 股月频信噪比低。

| 因子 | 构造方式 | 排除原因 |
|------|---------|---------|
| **high_52w** | `close_adj(T日) / max(high×adj_factor, [T−252td, T])` | **G2**：分子 T 日价格同时出现在 fwd_ret 分母中，lead_ratio = **37.6x**（严重未来函数）；已由 high_52w_v2 修正 |
| **mom_6_1** | `ret(T−6m 到 T−1m)`，跳过最近 1 个月的 6 月累计收益 | **G1**：IC_IR = 0.042，A 股月频下价格动量信噪比极低 |
| **mom_12_1** | `ret(T−12m 到 T−1m)`，跳过最近 1 个月的 12 月累计收益 | **G2**：lead_ratio = 3.25；与 mom_6_1 同属原始价格动量，A 股月频有效性差 |
| **ret_1m** | `ret(T−20td 到 T)`，过去 20 个交易日收益率 | **方向错误**：实质是短期反转因子，IC 方向为负（与动量方向相反），不应作为动量因子 |
| **ind_adj_mom** | `ret_i[T−12m, T−1m] − mean(ret_ind, [T−12m, T−1m])`，行业调整动量旧版（基于 mom_12_1） | **G2**：继承 mom_12_1 的 lead_ratio 问题；已在 Sprint 2 用 ind_adj_mom_6_1 重新实现 |
| **ind_adj_mom_6_1** | `ret_i[T−6m, T−1m] − mean(ret_ind_eq_wt, [T−6m, T−1m])`，个股减行业等权均值收益 | **G1**：IC_IR = 0.041；与 mom_6_1 的截面相关系数 r = **0.997**（完全冗余，无增量） |
| **mom_risk_adj** | `cum_ret[T−6m, T−1m] / std(ret, [T−6m, T−1m])`，Sharpe 式风险调整动量 | **G1** + **冗余**：IC_IR 不达标；分母涉及波动率，与 ivol_60d 截面相关偏高 |
| **mom_consistency_6** | `(正收益月数 / 6) × sign(累计收益)`，过去 6 月中正收益月数比例 | **G1**：IC_IR = 0.082，远低于门槛；月频序列相关性低，一致性计数信息量不足 |
| **macd_cross** | MACD 金叉/死叉信号（EMA12 − EMA26 vs 信号线），日频参数 | **G2**：lead_ratio = 14−27x，日内/周频信号，月频调仓只抓到残余噪音 |
| **rsi_6** | RSI 6 日（相对强弱指标，6 日参数） | **G2**：lead_ratio 极高（日频指标），月频无效 |
| **rsi_12** | RSI 12 日（相对强弱指标，12 日参数） | **G2**：lead_ratio 极高（日频指标），月频无效 |
| **boll_pct** | `(close − 下轨) / (上轨 − 下轨)`，布林带百分位（20 日参数） | **G2**：lead_ratio 极高（日频/周频信号），月频无效 |
