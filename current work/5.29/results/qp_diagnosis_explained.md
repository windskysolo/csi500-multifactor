# QP 优化器诊断：通俗解读与未来改进路径

> 本文档是 `qp_constraint_diagnosis_conclusion.md` 的配套解读，面向"想真正理解发生了什么"的读者。

---

## 一、先搞清楚"问题是什么"

### 核心矛盾一句话

> **完全相同的选股信号**，用两种方式分配权重，最终 IR 相差 2 倍：
> - TopN50 等权（不用 QP 优化）：**IR = 0.924，年化超额 +6.24%**
> - QP 二次规划（用优化器）：**IR = 0.402，年化超额 +2.45%**

这很反直觉：优化器比"傻乎乎的等权"差这么多？

---

## 二、我们做了什么实验，证明了什么

### 实验设计

7 个实验用**完全相同的信号**（sha256 = 23024863，保证信号零差异），只改变优化器配置，逐一测试"是哪个约束在拖累 QP"：

| 实验 | 改动 | IR | 
|------|------|---:|
| TopN50 EW（基准对照） | 不用 QP | **0.924** |
| QP + TE=6% + 行业±3% | 原始 QP | 0.402 |
| QP + TE=10% | TE 放宽 | 0.356 |
| QP + TE=15% | TE 更宽 | 0.356 |
| QP + 去掉 TE 约束（L2）| 无 TE 约束 | 0.356 |
| QP + 行业±5% | 行业约束放宽 | 0.146 |
| QP + 无行业约束 | 无行业约束 | 0.240 |

### 实验结论

**第一个意外**：松开 TE 约束（从 6% 到 10% 到 15% 到无约束），IR 没有上升，反而三者产生了完全相同的结果（IR=0.356），说明 TE 约束根本不是限制因素。

**第二个意外**：松开行业约束（从±3% 到±5% 到无约束），IR 大幅下降（0.402→0.146），方向完全反了！原本以为"约束压制了 alpha"，实际上是"约束在保护 alpha"。

---

## 三、为什么会这样？根本原因逐层解释

### 3.1 第一层：TE 约束其实在帮忙

**TE（跟踪误差）约束是什么**：限制组合相对于基准的偏离程度不能太大。

**为什么大家以为它会拖累 IR**：直觉是"约束越紧 → 自由度越低 → 收益越差"。

**实际发生了什么**：

```
放开 TE 约束（TE=10%, 15%, 无约束）后：
  → 优化器本来就不会超过 6% TE
  → 原来 TE=6% 约束正好是绑定的（tight）
  → 略微收紧（6%）反而给出更好结果

结论：TE=6% 约束在充当"正则化"——
  就像 L2 正则化防止过拟合一样，TE 约束防止优化器在噪声方向过度押注。
```

类比：给一个记性不好的学生设定"每次考试不能偏科太严重"的约束，这个约束实际上帮助他维持了总分——去掉这个约束他反而去死磕自己以为最强的科目，结果偏科更严重总分更低。

### 3.2 第二层：行业约束是在限制"系统性偏见"

**行业约束是什么**：每个行业的持股权重相对于指数的偏差不能超过±3%。

**为什么放宽行业约束会让 IR 变差**：

IC_IR 信号是用 2012-2020 年的数据训练的。这 9 年里，ROE 高、毛利率高的股票（主要集中在消费、医药行业）确实有更好的超额收益。所以信号学到了"消费/医药因子权重要高"。

但 2021-2022 年验证期发生了结构切换：
- 消费/医药经历了大幅回撤
- 成长股、新能源崛起
- 历史高 IC 的行业变成了当期"坑"

```
没有行业约束的 QP：
  → 信号说"消费/医药的 alpha 更高"
  → 优化器把更多权重集中到这些行业
  → 2021-2022 年这些行业恰好表现差
  → IR 大幅下降（0.402 → 0.240 → 0.146）

有±3% 行业约束的 QP：
  → 信号偏见被强制限制在±3%以内
  → 不能过度押注历史好行业
  → 保留了部分有效的股票选择能力
  → IR = 0.402
```

**类比**：一个基金经理在2012-2020年靠重仓消费赚了钱，2021年他还在按历史习惯重仓消费。约束他"不许在任何一个行业超配太多"的规定在这时候保护了他。

### 3.3 第三层（根因）：序数 vs 基数——QP 用错了信息类型

这是最核心的机制，也是最难理解的部分。

**关键数字**：IC 均值 ≈ 0.047（月均）

IC（信息系数）= 0.047 是什么意思？

> 每个月，信号对 500 只股票的截面排序，只有大约 52.4% 是正确的（比随机 50% 好一点点）。
> 换句话说，**47.6% 的排序是随机噪声**。

在这个噪声水平下，TopN50 和 QP 的差异就很关键了：

---

**TopN50 的逻辑（只用序数信息）：**

```
信号：[股票A=0.8, 股票B=0.7, 股票C=0.3, ..., 股票Z=0.1]
TopN50 做的：找出排名前50的股票，每只分配2%权重
TopN50 需要的：只需要知道"谁在前50，谁不在前50"
TopN50 对噪声的敏感度：某只股票信号0.8变成0.75或0.85，只要还在前50，权重不变
```

**QP 的逻辑（用基数信息）：**

```
信号：[股票A=0.8, 股票B=0.7, 股票C=0.3, ..., 股票Z=0.1]
QP 做的：根据信号绝对大小 按比例 分配权重（alpha最大的获得最高权重）
QP 需要的：不仅需要排名正确，还需要 alpha 量级（0.8 vs 0.7 的差距）对应真实收益差距
QP 对噪声的敏感度：股票A信号0.8→0.85（纯噪声），QP就会给它更多权重
```

**问题所在**：

IC_IR 信号的 alpha 量级（0.8 vs 0.7 这个绝对差距）并不对应真实的预期超额收益差距。它只是各因子加权平均后的一个合成得分，量级本身没有经过校准，含有大量噪声。

```
TopN50：
  信号的50%噪声 → 有几只噪声股进了Top50 → 但等权稀释后，
  这些噪声股只贡献2%权重 → 总组合受影响有限

QP：
  信号的50%噪声 → 噪声最大的股票 alpha 量级也最大 → 
  QP 把最多权重给了这些噪声最大的股票 → 组合被噪声驱动
```

**通俗类比**：

想象你要组一支篮球队，有10个候选球员。
- 教练评分 = 信号（IC=0.047意味着评分有47%是随机误差）

**TopN50 策略**：取评分最高的5人，每人上场时间相等。
- 即使评分有误差，5人里真正强的球员大概率占多数，整体战绩不错。

**QP 策略**：按评分比例分配上场时间。评分10分上场100分钟，评分9分上场90分钟。
- 问题：评分误差很大（10分可能实际上是9分水平，8分可能实际上是10分水平）
- 结果：上场时间最多的不是最强的球员，而是被过度高估的球员

## 五、为什么"更复杂的方法"反而更差？（违反直觉的原因）

QP 是均值-方差优化（Markowitz），从理论上讲是最优的。但理论成立需要两个前提：

1. **alpha 量级对应真实预期收益** ← 这里不满足
2. **协方差矩阵估计准确** ← 这里也不完全满足（LedoitWolf 有改善但还是近似）

当前项目中，alpha 是多因子加权合成的原始得分，没有经过校准（没有转化成"预期年化超额收益%"），所以 QP 的前提不满足。TopN50 因为不依赖这个前提，反而表现更稳。

## 六、未来改进路径（从易到难）

### 路径 1：立即可做——换信号不换优化器

**问题**：现在用的是 IC_IR expanding 信号（用全历史 IC 加权）
**改进**：换成 rolling-48 Ridge 信号

为什么？rolling-48 Ridge 已经通过实验证明：
- TopN50 版本 IR = 1.771（验证期最优）
- QP 版本 IR = 1.489（也比当前 IC_IR 信号的 QP 版本高很多）

说明 rolling-48 Ridge 信号的 alpha 量级比 IC_IR 信号更接近真实收益，QP 的表现也更好。

```
行动：将主线信号从 expanding IC_IR → rolling-48 Ridge
      不需要改优化器代码，只改 Spec 文件中的 signal_method 参数
```

### 路径 2：中期——alpha 校准（让 QP 更好用）

**核心思路**：给 QP 提供"经过校准的 alpha"，让 alpha 量级有意义。

**方法**：
```python
# 当前：alpha = 因子加权合成得分（原始）
alpha_raw = combiner.output()

# 改进：alpha_calibrated = 排名 × 预期信息含量
alpha_calibrated = alpha_raw * rolling_IC * stock_vol
```

这样做的效果：
- `rolling_IC`：代表这个信号在近期的真实预测力（近期 IC 高 → 信号可靠 → 可以给更大权重）
- `stock_vol`：代表该股票的预期波动率（波动率高的股票，alpha 要更高才值得持有）
- 校准后的 alpha 量级更接近真实预期超额收益，QP 权重分配更合理

**代价**：需要修改 `src/pipeline/stages.py` 中的信号合成步骤，增加校准层。

### 路径 3：中期——TopN100/150（在 TopN 和 QP 之间找中间点）

**现状**：
- TopN50 IR=0.924，TE=6.75%，持股集中
- TopN100 可能 IR 略低但持股更分散，换手可能更低

**实验方法**：修改 Spec 文件的 `topn` 参数从 50 → 100，直接对比。

### 路径 4：长期——Black-Litterman 框架

**核心思路**：不直接用原始 alpha，而是把 alpha 当作"观点"，通过贝叶斯方式与市场均衡（CAPM 预期收益）混合。

**优势**：自动解决"序数 vs 基数"问题——观点的置信度（IC_IR）决定与均衡混合的比例，量级问题被框架内部处理掉。

**代价**：需要较多新代码，改动较大，风险也相对高。

## 七、行动优先级建议

```
现在（本周）：
  ✅ 已完成诊断，QP TE=6% + 行业±3% 是 QP 框架下的最优点
  → 不要再花时间调 QP 约束参数（已验证没有提升空间）
  → 主力精力转移到 rolling-48 Ridge 信号主线（路径1）

  → 测试 TopN100/150 作为候选变体（路径2）
  → 评估 alpha 校准是否进一步提升 QP 版本

长期：
  → 如果需要更低换手或更好风险控制，考虑 Black-Litterman（路径4）
```

## 八、一句话总结

> **QP 优化器本身没有问题，问题在于它需要"量级可信的 alpha"作为输入，而我们当前提供的 IC_IR 合成信号的量级只有 47% 的可信度（IC=0.047）。TopN50 因为不依赖量级，对噪声天然鲁棒，所以在当前信号质量下表现更好。**
>
> **解决方向：要么提升信号质量（rolling-48 Ridge 信号量级更可信），要么对 alpha 做校准，要么切换到不依赖量级的分配机制（TopN 变体）。**
