# check/

本目录保存阶段性审计、问题复现和修复验证证据。它不是生产代码、正式 run 或当前状态说明的存放位置。

## 当前内容

- `0526/`：2026-05-26 流水线等价性、指标复算和阶段审计证据。
- `0527/`：迁移前文件清单。
- `0529/`：因子与优化器专项诊断。

这些目录均为历史批次。是否仍代表当前实现，必须结合当前源码、测试和 canonical 审计账本重新判断。

## 后续批次约定

建议使用 `YYYYMMDD_<topic>/` 命名，并包含：

- `README.md`：目的、范围、只读/写入边界、结论；
- `inputs.json` 或清单：输入路径、run id、代码版本；
- 小型 CSV/JSON/Markdown：可审计证据；
- `tmp/`：可删除的中间产物，不入 Git。

## 禁止事项

- 不把 `check/` 中的临时结果复制成正式数据或主线 run。
- 不在这里保存唯一版本的生产代码。
- 不用日期目录中的旧结论覆盖 `registry/`、`runs/` 或测试集 ledger。
- 大型 Parquet、图片和日志应保持可再生并由 `.gitignore` 排除。
