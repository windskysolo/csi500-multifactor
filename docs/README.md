# 项目文档入口

本目录只保留三个用途明确的区域：

- [当前文档](当前文档/00_文档总览.md)：当前有效、需要继续维护和阅读的人工文档。
- [历史归档](历史归档/README.md)：旧版本、过程记录和被替代的教学材料，仅用于追溯。
- `logs/` 与 `evidence/`：机器账本和核验证据，因代码路径依赖保持原位。

首次进入项目时：

1. AI 编码助手先完整读取根目录 `AGENTS.md`，并按其中第 0 节建立上下文。
2. 人工阅读从根目录 `README.md` 了解项目与代码结构，再进入[当前文档总览](当前文档/00_文档总览.md)。
3. 继续工作前按[学习与审计主线](当前文档/01_项目治理/学习与审计主线.md)定位当前阶段。

历史归档中的数字、结论和路径不得直接作为当前事实引用。
