### 3.2 样本期切分（L19-29）

```python
MARKET_START = pd.Timestamp("2016-01-01")   # 行情数据起点
MARKET_END   = pd.Timestamp("2025-12-31")   # 行情数据终点

EARLY_START  = pd.Timestamp("2014-01-01")   # 财务/股东数据提前下载起点

TRAIN_START  = pd.Timestamp("2016-01-01")   # 训练期
TRAIN_END    = pd.Timestamp("2021-12-31")
VALID_START  = pd.Timestamp("2022-01-01")   # 验证期（调参后检验稳健性）
VALID_END    = pd.Timestamp("2022-12-31")
TEST_START   = pd.Timestamp("2023-01-01")   # 测试期（最多运行2次）
TEST_END     = pd.Timestamp("2025-12-31")
```

**为什么要用 `pd.Timestamp` 而不是字符串？**

字符串 `"2016-01-01"` 在比较时行为不直观（字符串比较 vs 日期比较），而 `pd.Timestamp` 支持直接与 DataFrame 索引进行比较过滤，不需要额外转换。

**为什么训练期是 6 年（2016-2021）？**

- 因子评价的 IC 序列需要足够长才有统计意义（IC_IR 的 t 统计量 = IC_IR × √n，n=72 个月时 IC_IR=0.3 对应 t≈2.5，刚好 95% 显著）
- 涵盖牛市（2019-2020）和熊市（2018）周期，避免单一市场环境下过拟合

**为什么 `EARLY_START = 2014-01-01`？**

财务数据需要"提前量"：
- PIT 要求用 `ann_date`（公告日），但财报往往在季末后 1-4 个月才公告
- 计算 TTM 需要上年同期数据
- 因此 2016-01-01 开始的训练期需要追溯到 2014 年的财务历史

**参数冻结原则（最重要）：**

`TRAIN_*`、`VALID_*`、`TEST_*` 切分点一旦确定，不允许修改。任何基于测试期结果反过来调整参数的操作，都相当于"偷看答案"，会引入测试集过拟合。所有调参必须只在训练期数据上进行。

### 3.3 交易成本（L34-40）

```python
STAMP_DUTY_CUT_DATE = pd.Timestamp("2023-08-28")
STAMP_DUTY_BEFORE   = 0.001     # 10 bps（卖出单边）
STAMP_DUTY_AFTER    = 0.0005    # 5 bps（卖出单边）

COMMISSION_RATE = 0.00025       # 双边各 2.5 bps
SLIPPAGE_RATE   = 0.0008        # 8 bps（保守滑点估计）
```

**`STAMP_DUTY_CUT_DATE = 2023-08-28` 的历史背景：**

2023 年 8 月 28 日，证监会宣布将股票印花税税率由 0.1% 降至 0.05%，当日生效。这是自 2008 年以来的首次下调。回测必须在此日期前后分别使用不同税率，否则 2023 年之后的成本会被高估 50%（相差 5bps）。

**为什么印花税只收卖出方向？**

印花税（stamp duty）是对"股权转让合同"的税，在中国股票市场由卖方缴纳，买方不缴。佣金（commission）则是给券商的服务费，买卖双方各自缴纳。

**各项成本换算（以 100 万元交易额为例）：**

| 成本项 | 参数 | 卖出100万 | 买入100万 | 合计 |
|--------|------|-----------|-----------|------|
| 印花税 | 0.1% | 1,000元 | 0 | 1,000元 |
| 佣金 | 0.025% | 250元 | 250元 | 500元 |
| 滑点 | 0.08% | 800元 | 800元 | 1,600元 |
| **合计** | | 2,050元 | 1,050元 | **3,100元** |

**`SLIPPAGE_RATE = 0.0008`（8bps）的依据：**

这是保守估计。中证500成分股流动性较好，实际滑点通常在3-5bps；但为了给回测结果留出安全边际（宁可低估收益），这里用了偏高的估计。

### 3.4 行业分类（L45-48）

```python
INDUSTRY_SRC = "SW2021"
INDUSTRY_UNCLASSIFIED_CODE = "999999.SI"
INDUSTRY_UNCLASSIFIED_NAME = "未分类"
```

**为什么用 SW2021（申万行业分类 2021 版）？**

申万（SWS）行业分类是 A 股最广泛使用的行业分类体系。2021 版相比旧版做了结构调整，共 31 个一级行业。中性化使用申万一级，31 个哑变量的维度适中（不会因维度过高引起过拟合）。

`INDUSTRY_UNCLASSIFIED_CODE`：少数股票（通常是极新上市或特殊情况）没有行业分类，用此代码标记，中性化时这类股票会缺失残差，因子值置 NaN。

### 3.5 股票过滤规则（L53）

```python
NEW_STOCK_DAYS = 180
```

**上市不足 180 天（约 6 个月）视为新股，排除原因：**

1. **新股效应**：IPO 后前几个月价格波动异常剧烈，因子对其没有预测能力
2. **数据不足**：量价因子（如 momentum_12m）需要 252 个交易日的历史，新股根本没有
3. **财务数据缺失**：上市不足一年的公司季报记录极少，财务因子无法计算

### 3.6 因子预处理参数（L59-63）

```python
FINANCIAL_SECTOR_CODES: frozenset[str] = frozenset({
    "801780.SI",  # 银行
    "801790.SI",  # 非银金融（券商、保险）
})
MIN_NEUTRALIZE_STOCKS: int = 30
```

**为什么银行和非银金融要特殊处理？**

财务因子假设"负债高 = 风险高"，但银行的"负债"就是存款，这是业务本质，不是风险信号。同理，银行的杠杆率（负债/资产通常 >90%）在普通企业中会是极端值，但在银行是正常状态。如果不排除，这两个行业会"污染"横截面的因子分布。

`MIN_NEUTRALIZE_STOCKS = 30`：做行业+市值中性化的 OLS 回归时，如果某个调仓日有效股票数不足 30 只（罕见情况，可能发生在极端熊市），跳过中性化，直接返回原始因子值，避免因样本过少导致回归不稳定。

### 3.7 信号合成参数（L77-81）

```python
SIGNAL_MIN_IC_HISTORY: int = 12      # IC_IR 加权所需最少 IC 期数
SIGNAL_WINDOW_MONTHS: int = 24       # 滚动 IC_IR 回看窗口
SIGNAL_DEFAULT_MIN_VALID: int = 8    # 冷启动保守值
SIGNAL_MIN_VALID_FACTORS: int = 5    # 每只股票最少有效因子数
```

**为什么需要 12 期才开始 IC_IR 加权？**

IC_IR 是 IC 序列的均值/标准差。样本数 < 12 时，标准差估计不稳定，IC_IR 的误差很大。用 12 期以下的 IC_IR 加权，权重本身比直接等权还不稳定，所以冷启动阶段（前 12 个月）用等权代替。

**`SIGNAL_MIN_VALID_FACTORS = 5`：**

每只股票至少需要 5 个因子有有效值，才会计算综合信号。如果有效因子不足，对该股票的综合分数可信度太低，置 NaN 使其不参与选股。

### 3.8 单因子评价参数（L86-93）

```python
EVAL_HIGH_CORR_THRESHOLD: float = 0.70
EVAL_SHARPE_LS_THRESHOLD: float = 0.50
EVAL_IC_EFFECTIVE_CRITERIA: dict = dict(
    min_ic_ir=0.30,
    min_ic_mean=0.02,
    max_p_bh=0.05,
    min_dir=0.55,
)
```

**四个准入条件的量化意义：**

| 参数 | 值 | 含义 |
|------|-----|------|
| `min_ic_ir` | 0.30 | IC序列的信息比率，类似Sharpe ratio；0.30意味着平均IC是波动性的30%，信号稳定性基本可用 |
| `min_ic_mean` | 0.02 | 平均IC绝对值至少2%；纯随机的IC期望为0，2%是实践中"有意义"的最低门槛 |
| `max_p_bh` | 0.05 | BH校正后的p值（多重检验校正），5%是统计显著性标准 |
| `min_dir` | 0.55 | IC为正（或为负，与预期方向一致）的月数比例；55%意味着多数时候方向是对的 |

**`EVAL_HIGH_CORR_THRESHOLD = 0.70`：去除冗余因子**

如果两个因子的横截面相关系数 >0.70，它们承载的信息高度重叠，保留两个没有意义（还会引入多重共线性）。保留 IC_IR 更高的那个，另一个剔除。

### 3.9 组合优化参数（L98-101）

```python
OPT_TE_TARGET_ANNUAL: float = 0.05   # 年化跟踪误差目标 5%
OPT_INDUSTRY_MAX_DEV: float = 0.02   # 行业权重最大偏离 2%
OPT_SINGLE_MAX_DEV: float = 0.01     # 单股权重最大偏离 1%
OPT_TOPN: int = 50                   # L3 兜底选股数量
```

**`OPT_TE_TARGET_ANNUAL = 5%` 的含义：**

跟踪误差（TE）是策略日收益率与基准日收益率之差的年化标准差。5% 意味着：
- 策略相对基准的超额收益率，有 68% 的概率落在 [-5%, +5%] 之间（1 个标准差范围）
- 有 95% 的概率落在 [-10%, +10%] 之间（2 个标准差范围）

换算到月频：`5% / sqrt(12) ≈ 1.44%`，即每个月策略与基准的偏差不会太大，属于"适度增强"而非"高弹性进攻"。

**`OPT_SINGLE_MAX_DEV = 1%` 的意义：**

中证500中单股基准权重约 0.2%（1/500），1% 的最大偏离意味着单股最多可以持有基准权重的 6 倍（1.2%），或者完全不持有（-0.2% 的偏差，即不持有时的情况）。这个约束控制了单股集中度风险。

**`OPT_TOPN = 50`（L3 兜底）：**

当优化器彻底失败时（L1和L2均无可行解），退化为"按综合信号排名取前50只等权持有"。实际代码中50只可能因约束被放大（见优化器文档）。

## 六、领域知识补充

**参数冻结 vs 超参数调优**

机器学习中的超参数调优通常在训练集上用交叉验证选择最优参数，然后在测试集上验证。量化策略也遵循同样的逻辑：

- 训练期（2016-2021）：确定所有参数
- 验证期（2022）：确认参数稳健（允许微调，但不能基于测试集结果反向调整）
- 测试期（2023-2025）：最终评估，最多跑 2 次，不允许任何参数修改

违反这个原则的后果：测试集实际上变成了另一个训练集，你不知道策略在真实未来的表现，只知道它在"历史未来"的表现。这是量化策略失效的最常见原因之一。
