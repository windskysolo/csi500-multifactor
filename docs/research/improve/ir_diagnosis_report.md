# IR 偏低诊断报告

> 生成时间：2026-05-23  
> 依据数据：`reports/analysis_v2_results.md`、`reports/factor_evaluation/factor_evaluation_report.md`、`final_factors.json`、`src/config.py`、`src/signal/combiner.py`、`src/portfolio/optimizer.py`  
> 当前结果：V1 IR=-0.074，V2 IR=0.017（目标 ≥ 0.5）

---

## 0. TL;DR（核心结论）

**你的流水线整体是对的，但在三个关键节点上累积了严重的信号损耗：**

1. **因子筛选标准过于严苛** → 只剩 6 个因子，将 IC_IR 最强的因子（turn_20d、max_ret、vol_60d）全部排除
2. **验证集样本量不足（n=22）** → 方向翻转判断统计检验力极弱，却据此排除了 q_roe、roe_delta、np_yoy 等高质量因子
3. **优化约束过紧** → 单股偏离 1%、TE 目标 5% 在 500 只股票的宇宙里几乎强制让组合趋近于指数

这三个问题叠加，使最终 alpha 信号弱到"接近等权指数"，从而 IR 接近 0。

## 2. IR 低的根本原因分析

### 原因 1（最重要）：因子筛选过于严苛，丢弃了最强的因子

**证据：**

```
turn_20d：IC_IR = -0.689（训练集最强因子），验证集 IC_IR = -0.706（进一步增强）
           但因 shift_warning=True，lead_reverse=True → final_include=False
           
max_ret：IC_IR = -0.501，验证集 IC_IR = -0.771（更强！）
          同样因 shift_warning → 排除
          
vol_60d：IC_IR = -0.480，验证集 IC_IR = -0.502（稳定）
          因与 ivol_60d 相关性 0.893 去冗余 → 排除
```

`turn_20d` 和 `max_ret` 在验证期表现比训练期更好，却因为时间错位测试警告被排除。**时间错位测试的 `lead_reverse=True` 并不等于存在未来函数**——它只是说"下一期信号比当期信号预测力更强"，这在动量/反转类因子中完全可能是噪音或因子自相关的结果。

`turn_20d` 是换手率因子，其 lead_reverse 可能源于"月末换手率提前反映下期成分股调整"的信息效应，而不是数据泄露。

**损失估算：** 仅 `turn_20d` 一个因子训练期 IC_IR=-0.689，保守估计如果纳入能将复合信号 IC_IR 从 ~0.4 提升到 ~0.5。

---

### 原因 2（重要）：验证集样本量太少，方向翻转判断不可靠

**证据（验证集只有 n=22 期）：**

```
验证集 IC_IR 95% 置信区间宽度 ≈ ±0.42（报告中已标注）

q_roe：训练 +0.486 → 验证 -0.098（看起来翻转，但置信区间含 0）
np_yoy：训练 +0.470 → 验证 -0.103（同上）
roe_delta：训练 +0.483 → 验证 -0.040（接近零）
rev_yoy：训练 +0.448 → 验证 -0.020（接近零，被保留但验证无效）
```

这几个因子在**训练集分段检验**中（2012-2014 / 2015-2017 / 2018-2020）均方向一致（`dir_consistent=True`），说明它们在整个 9 年训练期内稳定有效。验证集的"翻转"更可能是 2021-2022 特定宏观环境（中国价值股大幅跑输、成长股主导）造成的**样本外短期偏差**，而非因子本身失效。

用 n=22 期判断因子是否翻转，犯 Type II 错误（错误排除真实有效因子）的概率极高。

**损失估算：** q_roe、roe_delta 均是分段一致且训练集 IC_IR>0.48 的质量因子，如果降权（0.5）而非排除，可以保住一部分盈利信号。

---

### 原因 3（重要）：优化约束过紧，几乎强制复制指数

**证据：**

- 500 只股票，单股最大偏离 ±1%
- 基准权重中最大权重 ≈ 0.5-0.8%（中证 500 接近等权）
- 允许最大偏离后，最大持仓上限 = 0.8% + 1% = 1.8%，最小 = max(0, 0.5% - 1%) = 0%
- 有效偏离空间极小，组合主动风险几乎全来自风险预算，而非信号

这意味着即使信号质量良好，优化器的约束也会将大多数信号过滤掉。V2 跟踪误差仅 5.82%，说明约束确实在起作用，但方向上几乎没有超额。

**核心矛盾：** 你的信号 IC_IR 在验证期只有 0.2-0.4，同时约束要求组合不偏离指数超过 1%（单股），这两个条件加在一起，有效 IR 接近 0 是必然结果。

---

### 原因 4（中等）：2021-2022 是特殊市场环境，价值和波动率异常表现

**因子归因证据：**

```
价值因子贡献：-4.15%（ep_ttm、cfp、rev_yoy 均是价值/成长类）
波动率因子贡献：+5.23%（ivol_60d 做空高波动是这段时期有效的策略）
流动性因子贡献：-3.03%（amihud 非流动性溢价在 2021-2022 未能兑现）
```

2021 年 A 股以新能源、军工为主的高估值成长股主导，传统价值因子（低 PE/低 PB）普遍跑输；2022 年大幅下跌中低波动策略有效，但这已在 ivol_60d 上体现。

这是客观的市场风格周期问题，**不是策略本身的错误**，但说明最终 6 个因子的组合在 2021-2022 的 Sharpe 天花板本身不高。

---

### 原因 5（次要）：复合信号有效因子数不足，稀释合成效果

当前 6 个因子中：
- `hk_hold_ratio`：稳定性权重 0.5，因数据起点（2016+）被降权
- `rev_yoy`：验证期方向翻转，实际为负 IC，但依然参与合成（可能是在反向出力）
- `north_flow_5d`：注册了但有效期数为 0，不参与合成但仍占用评估资源

**有效贡献正向 α 的因子实际上只有 3-4 个**（ivol_60d、hk_hold_ratio、amihud，以及不稳定的 ep_ttm/cfp）。

---

### 原因 6（次要）：Brinson 选股效应为负

选股效应 -0.39% 说明复合信号在行业内的股票排序**整体是轻微反向的**（重仓的股票平均表现差于轻仓的股票）。这可能源于：
1. 信号本身在 2021-2022 期间正向预测力不足甚至反转
2. T+1 开盘执行 vs 月末收盘计算因子值之间的滑点（月末前几天调仓）
3. 成本侵蚀（V2 年化换手 745%，双边 5+2.5 bps 约 7.5 bps/次 → 年化成本约 745%×7.5bps×2 ≈ 1.1%）

### 行动 1（必做，影响最大）：重新审视因子筛选标准

**问题：** `shift_warning=True` 被用于硬排除因子（如 turn_20d、max_ret），但这是错误的使用方式。

**调整方案：**
1. `shift_warning` 只做标记，不做硬排除；改为降权（stability_weight=0.5 → 0.7，视情况）
2. 或者：仅当 `diagnosis='reverse'`（IC 完全反向，如 short_ratio、analyst_rating_chg）才排除；`weak_drop` 以下的 warning 只记录不过滤

**目标因子集（建议重新评估）：**

```
当前排除但应该重新纳入（候选）：
- turn_20d：IC_IR=-0.689，验证 -0.706，分段一致，降权到 0.7 纳入
- max_ret：IC_IR=-0.501，验证 -0.771，分段一致，降权到 0.7 纳入  
- q_roe：IC_IR=+0.486，分段一致，验证翻转但置信区间含0，降权 0.5 纳入
- roe_delta：IC_IR=+0.483，分段一致，同 q_roe，降权 0.5 纳入
- np_yoy：IC_IR=+0.470，分段一致，降权 0.5 纳入
- holder_chg：IC_IR=+0.379，验证 +0.319（稳定），未翻转，可直接纳入
- analyst_eps_revision：IC_IR=+0.352，验证 +0.332（稳定），可直接纳入
```

预期：最终因子池从 6 个扩展到 12-15 个，复合信号更鲁棒。

---

### 行动 2（必做）：放宽组合优化约束

**调整参数（在 `src/config.py` 中）：**

```python
# 当前值 → 建议值
OPT_TE_TARGET_ANNUAL: float = 0.05   → 0.08   # 5% → 8%（给信号留更多空间）
OPT_SINGLE_MAX_DEV: float = 0.01     → 0.02   # 1% → 2%（500只股票的合理范围）
OPT_INDUSTRY_MAX_DEV: float = 0.02   → 0.04   # 2% → 4%（允许一定行业观点）
```

**理由：**
- 中证 500 增强策略行业标杆约束通常 3-5%，单股 1.5-3%
- 5% TE 对应的信息比率最大值理论上是 `active_return / 5% = IR`，若主动收益只有 0.5% 则 IR=0.1——永远达不到 0.5 的目标
- 要实现 IR≥0.5，至少需要超额收益/TE ≥ 0.5，即 TE=8% 时超额 ≥ 4%，8% 时 ≥ 4%，这是可实现的目标

### 行动 3（必做）：修复信号合成中 rev_yoy 的问题

`rev_yoy` 在验证期 IC_IR=-0.020（极接近零，轻微翻转），但仍以正权重参与合成，实际效果接近随机噪声甚至反向。

**选项：**
- 将其 stability_weight 从 1.0 降至 0.3（接近零权重）
- 或在信号合成时对验证期方向翻转因子统一降权至 0.3 以下

## 5. 不建议做的事（风险警告）

| 操作 | 风险 |
|------|------|
| 对 final_factors.json 直接手改（不重跑评估） | 导致 IC 权重和实际因子特征不匹配，产生隐性 bug |
| 放宽太多约束（TE > 12%、单股 > 3%） | 跟踪误差过高，失去指数增强的意义 |
| 因为改了参数结果变好就进入测试集 | 违反测试集纪律，可能在 1 次测试名额上浪费 |
| 因子没有通过 PIT 测试就继续下游 | 结果将含有未来函数，不可靠 |
