# 实验设计：超额收益衰减归因
## Alpha Decay Attribution — 牛市效应 vs 因子时间衰减

**研究问题**：2021-2025 年超额收益从 9.7% 逐年降至 0.4%，衰减来源是什么？

**版本**：v1.0  2026-06-02

---

## 一、问题拆解

年度超额收益可以分解为：

```
超额收益(t) = f(市场环境_t) + g(因子预测力_t) + ε_t
```

两个对立假说：

| | 假说 H1：牛市效应 | 假说 H2：因子衰减 |
|---|---|---|
| **核心主张** | 超额收益下降是市场环境变化的结果；<br>在同等市场环境下策略表现如故 | 因子的预测力随时间下降；<br>即使在熊市中也更难跑赢了 |
| **可证伪预测** | IC 与市场涨跌显著负相关；<br>控制市场环境后无时间趋势 | IC 有显著的时间递减趋势；<br>控制市场后趋势仍然存在 |
| **政策含义** | 无需换因子，等待熊市验证 | 需要更新因子池，补充时效性信号 |

---

## 二、三组实验

### 实验 A：IC-市场环境相关性检验

**目的**：检验每月因子 IC 是否随基准涨跌而系统性下降

**方法**：
1. 获取 2012-2025 每月复合 IC（等权合成所有因子 IC 的均值）
2. 获取对应月的基准收益率（中证500全收益）
3. 对以下模型做 OLS 回归：

```
composite_IC(t) = α + β × benchmark_ret(t) + ε(t)
```

**判读规则**：
- `β < 0` 且显著（p < 0.05）→ 牛市环境压制 IC → 支持 H1
- `β` 不显著 → IC 与市场涨跌无关 → 反驳 H1
- R² → 市场解释 IC 变化的比例

---

### 实验 B：时间趋势检验（控制市场后）

**目的**：在剔除市场环境影响后，检验是否存在独立的时间衰减趋势

**方法**：
```
composite_IC(t) = α + β₁ × benchmark_ret(t) + β₂ × time_index(t) + ε(t)
```
其中 `time_index` 为从 2012-01 开始的月序号（0, 1, 2, ...）

**判读规则**：
- `β₂ < 0` 且显著 → 控制市场后仍有时间衰减 → 支持 H2
- `β₂` 不显著 → 纯牛市效应，无时间衰减 → 支持 H1
- 同时分析各因子（非仅合成 IC），识别哪些因子在衰减

**扩展检验（结构突变）**：
在 2022 年末做 Chow 检验，判断 IC 序列在训练/测试期交界处是否存在结构性断裂。

---

### 实验 C：市场环境分层回测对比

**目的**：同一市场环境下，2021-2022 年 vs 2023-2025 年策略是否存在系统性差异

**方法**：
1. 按基准月收益率将所有月份分为三组：
   - **熊市月**：基准月收益 < -2%
   - **震荡月**：基准月收益 ∈ [-2%, +2%]
   - **牛市月**：基准月收益 > +2%

2. 分别统计验证期和测试期在各环境下的**月均超额收益**和**IC 均值**

3. 如果两期在同一环境组的超额一致 → 纯牛市效应
   如果两期在同一环境组的超额也存在显著差距 → 因子衰减

**关键对比矩阵**：

```
           | 熊市月均超额 | 震荡月均超额 | 牛市月均超额
-----------|-------------|-------------|-------------
验证期      |     ?       |      ?      |      ?
测试期      |     ?       |      ?      |      ?
差值(衰减?) |     ?       |      ?      |      ?
```

若"差值"在各环境列均为负，且统计显著 → H2（因子衰减）
若"差值"在熊市/震荡列接近零，仅牛市列为负 → H1（牛市效应）

## 四、假说判定矩阵

| 实验结果 | β（市场）显著 | β₂（时间）显著 | 分层对比差异 | 判定 |
|---|---|---|---|---|
| 场景 1 | 是 | 否 | 集中在牛市月 | **纯牛市效应（H1）** |
| 场景 2 | 否 | 是 | 各市场环境均有 | **纯因子衰减（H2）** |
| 场景 3 | 是 | 是 | 两者均有 | **混合效应** |
| 场景 4 | 否 | 否 | 无显著差异 | **统计噪声，样本量不足** |
