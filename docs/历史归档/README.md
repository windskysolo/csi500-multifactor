## 使用限制

- 不得直接引用这里的测试集次数、IR、因子数量、主线模型或文件路径作为当前事实。
- 不得从历史计划中恢复参数并直接运行策略。
- 如需追溯某个结论，应回到当前代码、测试、机器账本和不可变运行产物重新核验。
- 当前有效入口为[当前文档总览](../当前文档/00_文档总览.md)。

- `过程记录/`：原 `current work/` 中按日期保存的计划、脚本、图表和结果。
- `旧文档集/`：原 `docs_new/` 与 `doc/`，保留迁移前原貌。
- `旧导航与结构说明/`：已失效的文件地图、进展快照和旧流水线图。
