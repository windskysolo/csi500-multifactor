# 中证500多因子增强项目：完整解读

> 写给项目负责人的技术说明。目标：读完这份文档，你能清楚回答三个问题——"这个项目在干什么"、"之前哪里错了、怎么修的"、"现在可不可信"。

---

## 第一章：项目在干什么

### 1.1 一句话目标

**用量化选股模型，让投资组合的收益长期跑赢中证500指数。**

这叫"指数增强"——不是随机押注，而是用数据找出"哪些股票在未来一个月大概率比指数平均表现更好"，然后超配这些股票、低配其他股票。

### 1.2 为什么选中证500

中证500是A股市值排名500-1000的股票，共500只。它的特点：

- 数量足够多，选股余地大
- 市值偏中小，因子有效性比沪深300更强
- 流动性尚可，不像小盘股那么难买卖

所以同类型的量化产品大多以中证500为基准。

### 1.3 整个流程是什么

把这个项目想象成一条**工厂流水线**：

```
原材料（原始数据）
    │
    ▼  【下载】从 Tushare 下载行情、财务、成分股等数据
    │
    ▼  【转换】把 CSV 文件变成 Parquet 格式（快、省空间）
    │
    ▼  【构建因子】把原始数据加工成"打分表"（27个因子）
    │
    ▼  【评价因子】测试每个因子是否真的有预测能力
    │
    ▼  【合成信号】把有效因子按权重组合成一个综合打分
    │
    ▼  【组合优化】用数学模型把综合打分转换成具体的持股权重
    │
    ▼  【回测】模拟2016-2022年按这些权重实际交易，看结果如何
    │
    ▼  【归因】分析超额收益/亏损从哪里来
    │
    ▼  成品：验证期回测报告 + 测试期评估
```

## 第二章：数据是如何组织的

### 2.1 时间划分（非常重要，违反就是作弊）

| 阶段 | 时间范围 | 用途 |
|---|---|---|
| 训练期 | 2016-01-01 ~ 2021-12-31 | 调参、筛选因子、决定权重 |
| 验证期 | 2022-01-01 ~ 2022-12-31 | 检验参数泛化能力 |
| 测试期 | 2023-01-01 ~ 2025-12-31 | 最终不可偏倚的评估（仅2次机会） |

**为什么要分？** 类比考试：你不能用答案来备考，否则高分没有意义。测试期的数据就是"考卷答案"——只有在所有模型决策都锁定之后，才能看它，而且最多只能看2次（防止反复调参直到测试集好看）。

### 2.2 PIT原则（Point-In-Time，时间节点原则）

**这是量化研究中最容易犯的错误之一。**

财务数据（比如公司的季报利润）有个问题：虽然2021年Q3的财报报告期是9月30日，但公司实际公布这个数据可能要等到2022年1月。

错误做法：用2021-09-30这个日期去调取数据，会拿到还没发布的财报 → **未来函数**，相当于开了上帝视角。

正确做法：只用"公告日期（Annodt）"来过滤，确保T日看到的数据都是T日前已经公开的。

本项目用 `financial_pit.parquet` 存储PIT安全的财务数据，字段 `_pit_inc/_pit_bal/_pit_cf` 分别记录利润表/资产负债表/现金流量表的最早可用日期。

## 第三章：27个因子是什么

因子 = 一种对股票未来收益的预测信号。

### 3.1 三大类因子

**价值类（5个）** — "便宜的比贵的好"
- BP（账面市值比）、EP（盈利收益率）、SP（销售收益率）、CFP（现金流收益率）、DY（股息率）

**质量类（6个）** — "基本面好的公司长期能跑赢"
- ROE、ROA、毛利率、净利润增长稳定性、资产负债率（反向）、应计项目

**成长类（4个）** — "业绩增速快的公司短期有超额"
- 营收增速、利润增速（单季度/同比）、ROE变化

**动量/反转（3个）** — "涨了一段时间的股票短期还会涨，涨太多了会反转"
- 1个月反转、3个月动量、12个月动量

**波动率（2个）** — "低波动率股票长期风险调整后收益更好"
- 历史波动率（20日/60日）

**流动性（2个）** — "流动性差的股票有溢价"
- 换手率、Amihud非流动性

**资金流（2个）** — "大单净流入代表机构在买"
- 大单净流入额、大单净流入比

成长类 = 4，总计 = 5+6+4+3+2+2+2 = **24个原始因子 + 3个合成/衍生 = 27个**

### 3.2 因子评价怎么判断有效

用 **IC值（Information Coefficient）** 衡量：IC = 因子值 排名 与 下个月收益 排名 的相关系数。

- IC均值 > 0.02：有效
- IC_IR（IC均值/IC标准差）> 0.3：显著且稳定
- Shift Test（时间错位测试）：把因子整体推迟一期，IC应该大幅下降 → 否则怀疑含未来信息

**最终筛选结果：6个因子入选最终组合**（value、quality、growth、momentum、volatility、liquidity）。

## 第四章：之前出了什么问题，具体修复了什么

这是本文档的核心部分。所有问题都编了代号（F0-F9），以下按"影响严重程度"从高到低解释。

---

### 4.1 最严重：收益率口径错误（F2-001）【已修复】

**问题是什么：** `daily_quote.ret`（每日收益率）这个字段原来的计算方式是错的，用的不是正确的后复权收益率，导致所有因子检验的"目标变量"都是假数据。

**打个比方：** 你研究"哪种饮食方式最健康"，但体重秤有系统性误差，量出来的数全都偏了10斤。这样得出的结论（"素食者比肉食者轻5公斤"）在真实体重数据下可能根本不成立。

**影响范围：**
- `data/processed/daily_quote.parquet` — 基础行情数据（已重建）
- 所有因子的IC检验结果（因为IC用这个ret计算）
- forward return面板（下期收益，用于回测）

**修复动作：** 重建了 `daily_quote.parquet`，验证了 `ret` 与 `close_adj`（后复权收盘价）的百分比变化完全一致（最大差异=0.0）。

---

### 4.2 严重：基准收益算错（隐含问题）【已修复】

**问题是什么：** 中证500有两个版本——**价格指数**（不含分红再投资）和**全收益指数**（含分红再投资）。

如果用价格指数做基准，每年会少算 2-3% 的股息收益。那么策略的"超额收益"就被人为虚增了同等量。

**打个比方：** 你和朋友比赛爬楼梯，他从1楼爬，你从-1楼爬，结果你说自己爬得更高——表面上两人都到了8楼，但他多走了2层。

**修复动作：** 基准统一使用中证500**全收益指数**，`config.py` 中明确标注。

---

### 4.3 严重：L3组合优化违反交易约束（F6-001）【本次修复】

**问题是什么：** 组合优化有三层退路（Fallback）：
- L1：正规的二次规划最优解
- L2：去掉跟踪误差约束的简化版
- L3：最后的保底方案，直接等权选前N只股票

问题出在L3：原来固定选50只股票，每只权重 = 1/50 = 2%。但是中证500的基准权重每只约0.2%，偏离上限是1%，所以每只最多持有 0.2% + 1% = 1.2%。2% 远超1.2%，**违反了单股偏离约束**。

**影响：** 30/84个调仓期（2016-2022年）使用L3时，权重不合规，被标记为 `constraint_compliant=False`，回测直接被系统拒绝运行。

**修复逻辑：**

```python
# 修复前：固定选50只
selected = ranked[:50]  # 每只2%，违规

# 修复后：动态计算最少需要多少只股票
n_min = ceil(free_budget / single_max_dev)  
# 例如 free_budget=1.0, single_max_dev=0.01 → n_min=100
effective_topn = max(topn=50, n_min=100) = 100
selected = ranked[:100]  # 每只约1%，合规
```

**修复结果：** L3非合规期从30降至15（剩余15期是候选股票数量真的不足100只，属于真实无可行解，已在报告中披露）。

---

### 4.4 严重：回测用了错误的净值计算时点（F7-001）【已修复】

**问题是什么：** 按规则，T日盘后生成权重 → **T+1日开盘价**成交。但原来的回测代码在算"调仓前组合价值"时，用的是**T日收盘价**而不是T+1日开盘价。

**为什么有差异？** 开盘价和收盘价可能相差1-3%（尤其遇到涨跌停或跳空），这个误差会让每期的成本计算偏差，积累下来使NAV（净值）曲线失真。

**修复动作：** `engine.py` 中 `pretrade_value` 改为用T+1开盘价计算组合初始价值，单元测试验证了极端场景（持仓股票开盘价翻倍时不应产生额外成本）。

---

### 4.5 严重：状态未知的股票被允许交易（F7-002）【已修复】

**问题是什么：** 如果某只股票在某天没有停牌/涨跌停等状态数据（比如数据本身有缺失），原来代码默认状态是 `FREE`（可自由交易）。

**保守原则应该是：** 状态不明 → 不得交易，锁定上期持仓。

**打个比方：** 一个人联系不上，不能假设他"没有问题"，应该假设有问题直到确认安全。

**修复动作：** 缺失状态从 `FREE` 改为 `LOCKED`，并增加了整日状态数据缺失时的全量LOCKED处理。

---

### 4.6 中等：测试集产物污染公共路径（F9-003）【已修复】

**问题是什么：** 运行测试期流水线时，生成的中间产物（forward return面板、协方差缓存）会写回公共的 `data/processed/` 目录，覆盖训练/验证期的产物。

**为什么有害：** 如果先跑了一次测试集，再重跑训练期，就会拿到被测试期数据"污染"的产物，破坏时间隔离。

**修复动作：** 测试期所有输出只写入 `data/processed/test_run_{N}/`，公共路径完全只读。

---

### 4.7 中等：印花税率硬编码（F2-002 相关）【已修复】

**问题是什么：** 2023年8月28日，中国证监会将A股印花税率从双边10bps（0.1%）调整为单边5bps（0.05%）卖出方向征收。

原来代码用固定常数，不会随日期自动切换。

**影响：** 2023年后的交易成本被高估（多扣了一个量级的税），导致测试期的换手成本分析失真。

**修复动作：** `transaction.py` 改为时间函数：

```python
def stamp_duty_rate(trade_date):
    if trade_date < pd.Timestamp("2023-08-28"):
        return 0.001  # 双边 10bps
    else:
        return 0.0005  # 单边 5bps（卖出）
```

---

### 4.8 工程问题：tracked pyc 文件污染 git（F0-001）【已修复】

**问题是什么：** Python编译后会在 `__pycache__/` 目录生成 `.pyc` 缓存文件，这些是机器生成产物，不应该进入版本管理。原来的 `.gitignore` 设置不当，导致27个 `.pyc` 文件被追踪。

**修复动作：** 更新 `.gitignore`，用 `git rm --cached` 从版本管理中移除这些文件。

---

### 4.9 工程问题：pipeline 关键产物缺失时仍报成功（F9-001）【已修复】

**问题是什么：** 原来的 `run_pipeline.py` 在某个阶段输出文件不存在时，只打一个 WARNING 日志，但仍然继续运行并最终报告"pipeline成功"。

**后果：** 可能出现"回测成功完成"但实际上用的是上一次的旧权重文件。

**修复动作：** 关键产物缺失时立即返回失败，整个pipeline终止，不写 `success=true` 的manifest。

## 第五章：当前实验流程是否严谨正确

### 5.1 已经严谨正确的部分

| 环节 | 严谨性证据 |
|---|---|
| **数据口径** | 后复权收益率、全收益基准、PIT财务数据，三个最核心的口径均已统一 |
| **防未来函数** | Shift Test、PIT日期校验、时间错位单元测试全部覆盖 |
| **交易约束** | 停牌锁定、涨停不加仓、跌停不减仓、单股偏离、L3动态约束 |
| **交易成本** | 印花税按日期切换、佣金2.5bps双边、滑点5-10bps，成本模型写实 |
| **T+1成交** | 权重T日生成，T+1开盘价成交，净值用T+1开盘前估值 |
| **测试集隔离** | 训练/验证/测试三期完全分离，产物写入独立目录 |
| **自动化测试** | 201个单元测试覆盖所有关键逻辑，包括边界条件和极端场景 |
| **可追溯性** | manifest记录输入/输出hash、git commit、配置hash |

### 5.2 已知限制（不是"错误"，是"披露了的约束"）

| 限制 | 原因 | 影响程度 |
|---|---|---|
| **L3期有15/84个constraint_compliant=False** | 可买入候选数量不足100只（真实无可行解） | 低，这15期的权重仍然使用但被标记为不合规 |
| **BHB归因V2偏差7.49e-4** | T+1开盘/收盘价差异导致归因与回测净值有0.07%偏差 | 低，在可接受范围内 |
| **验证期（2022年）指标差** | 2022年A股全年熊市，量化因子集体失效 | 不代表策略失效，需要看全样本 |
| **w_prev_source=目标权重近似** | 优化器用上期目标权重而非实际成交权重作为初始值 | 低，实际偏差很小 |
| **notebook未同步新API** | 部分notebook仍用旧的字段名 | 只影响探索分析，不影响生产流水线 |

### 5.3 现在还不能下结论的部分

**测试期（2023-2025）尚未评估（这是设计上故意的）**

- 修复前的Run #1使用了错误的收益率口径，已作废
- 目前还有**2次**测试集机会
- 在运行测试集之前，不能对策略2023年之后的表现作任何判断

**验证期（2022年）不是最终答案**

- 2022年是特殊的极端行情（A股全年下跌20%+）
- 验证期V2信息比率IR=-0.178，这主要反映2022年因子失效，不代表长期效果
- 要下最终结论，必须看训练期+验证期的全样本指标

## 第六章：最简化的流程图

```
【数据层】
  Tushare下载 → CSV → Parquet
  关键文件：daily_quote.parquet（含后复权ret）
           financial_pit.parquet（含PIT安全的财务数据）
           index_member.parquet（每月成分股快照）
           stock_status.parquet（停牌/涨跌停状态）

【因子层】
  financial_factors.py  → 财务因子（价值/质量/成长）
  price_factors.py      → 量价因子（动量/波动/流动性）
  preprocess.py         → 去极值 + 中性化 → 横截面标准化

【评价层】
  ic_analysis.py   → IC/IC_IR/IC_decay
  quintile_backtest.py → 5分组收益（不含成本，不扣基准）
  shift_test.py    → 时间错位测试（防未来函数）
  → 输出：factor_summary.csv（IC_IR加权因子清单）
  → 最终：6个因子入选

【信号层】
  combiner.py → 6因子 × IC_IR权重 → composite_signal
  
【优化层】
  covariance.py → LedoitWolf收缩估计（防病态）
  optimizer.py  → L1二次规划（失败→L2→L3等权）
  约束：跟踪误差<目标，行业偏离<3%，单股偏离<1%
  → 输出：portfolio_weights_optimized.parquet

【回测层】
  T日盘后生成权重 → T+1开盘成交
  成本：印花税(日期相关)+佣金2.5bps×2+滑点5-10bps
  → 输出：backtest_nav.parquet（日频净值）

【归因层】
  brinson.py     → 行业配置效应/选股效应
  factor_attr.py → 因子组收益分解（WLS回归）
  → 输出：analysis_v2_results.md（自动生成报告）
```

## 第七章：如何判断一个结论是否可信

**可信的前提条件（全部满足才算）：**

1. 数据口径：后复权价格、全收益基准、PIT财务数据
2. 时间隔离：因子参数/权重只用训练期数据调整
3. 未来函数：Shift Test通过，或风险已明确披露
4. 交易成本：包含印花税、佣金、滑点
5. 约束满足：停牌/涨跌停/单股偏离约束均检验
6. 产物可追溯：报告指标与当前parquet文件hash一致

**当前报告（2022验证期）的可信程度：** 满足所有前提，数据口径正确，约束基本满足（15期L3有偏离已披露）。

**测试期的可信程度：** 尚未运行，不能评价。
