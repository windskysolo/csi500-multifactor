## 1. 运行清单

### 文件位置

```
data/processed/run_manifests/run_YYYYMMDD_HHMMSS.json
```

### 这个文件是什么

每次运行 `scripts/run_pipeline.py` 后自动生成的"完工证明"。如果文件里 `"success": false`，说明中途出了问题。

### 关键字段含义

```json
{
  "success": true,                          // ← 整体是否成功
  "stages_executed": ["convert", "factors", "evaluate", "signal", "portfolio", "backtest", "attribution"],
  "train_end": "2021-12-31",               // ← 训练期截止（参数是否正确）
  "valid_end": "2022-12-31",               // ← 验证期截止
  "test_set_run_count": 0                  // ← 测试集已运行次数（上限2次）
}
```

### 当前实际结果

```
run_20260520_212950.json
success=True
stages_executed 包含全部 7 个阶段
test_set_run_count=0（剩余正式机会 2 次）
```

### 怎么判断正常

- `success=true`：所有阶段完成
- `stages_executed` 包含 `convert`、`factors`、`evaluate`、`signal`、`portfolio`、`backtest`、`attribution` 七步
- `test_set_run_count` 不超过 2：这是整个项目最重要的纪律之一，违反等于作弊

## 2. 因子面板

### 文件位置

```
data/processed/factor_panels/           ← 训练/验证期，每个调仓日一个 parquet 文件
data/processed/factor_panels_test_run_N/ ← 测试期（正式使用时才生成）
```

### 这个文件是什么

每个调仓日（月末交易日）对应一张表。行是股票，列是因子名称，值是**经过去极值 + 行业/市值中性化 + 标准化**后的因子暴露（z-score）。

### 典型结构

```
         amihud  rev_yoy  ep_ttm   cfp  gross_margin  mom_12_1
000001.SZ   0.82   -1.24    0.31  0.55          0.17     -0.63
000002.SZ  -0.45    0.78   -1.02 -0.21         -0.89      1.24
...
```

- 值域大约在 **-3 到 +3** 之间（z-score，正态分布，超出 ±3 的已被截断）
- 值为 `NaN`：该股票当天没有有效数据（如新股、停牌、金融股财务因子剔除）
- **正值 = "比中证500平均水平好"**（方向经过对齐：高值 = 预期收益更高）

### 当前实际结果

```
27 个因子，覆盖 2016-01-29 → 2022-12-30，共 84 期
每期平均有效股票数：amihud=487，财务类因子约 449-463，动量类因子约 408-441
有效率（有值的股票占全部成分股的比例）约 38-46%
```

有效率为什么不是 100%？正常现象。原因：
1. 新股（上市不足 6 个月）排除
2. 财务数据缺失（刚上市、特殊公司）
3. 金融股的财务因子被置 NaN
4. 动量因子需要历史价格，新进成分股历史不足

### 3.1 `ic_result.csv` — 每个因子的预测能力

#### 列含义

| 列名 | 含义 | 怎么判断好坏 |
|------|------|------------|
| `ic_mean` | IC 均值：因子排名 vs 下月收益排名的平均相关性 | 绝对值 > 0.02 算有信号 |
| `ic_std` | IC 标准差：因子预测力的波动性 | 越小越稳定，但不是越小越好 |
| `ic_ir` | IC_IR = ic_mean / ic_std（类夏普比率）| **绝对值 ≥ 0.30** 为有效阈值 |
| `t_stat` | t 统计量：IC_IR × √n | 绝对值 > 2 说明统计显著 |
| `p_value_bh` | BH 多重检验校正后的 p 值 | < 0.05 算通过 |
| `pct_consistent_dir` | 方向一致性：IC 与预期方向一致的期数占比 | > 60% 算稳定 |
| `effective` | 综合是否有效 | `True` = 进入候选池 |

#### IC 的直觉解释

IC = 0.05 意味着什么？—— 把因子值高的股票和因子值低的股票列出来，高分组的下月收益排名平均比低分组高 5 个百分点。听起来不大，但月度 IC_IR ≥ 0.3 在实际量化研究中已经算合格。

IC_IR = 0.5 意味着什么？—— 就像一个打字准确率 50% 的预言家，每个月预测对收益方向的概率大约 63%（超过随机猜的 50%）。

#### 当前实际结果（训练集，2016-2021，70 期）

| 因子 | IC 均值 | IC_IR | 含义 |
|------|---------|-------|------|
| `turn_20d`（换手率） | **-0.070** | **-0.636** | 最强因子，换手率高→超额收益低（负向） |
| `q_roe`（季度 ROE） | +0.063 | +0.611 | 第二强，盈利能力强→收益好（正向） |
| `amihud`（非流动性） | +0.035 | +0.508 | 流动性差的股票有溢价（正向） |
| `rev_yoy`（营收增速） | +0.033 | +0.508 | 收入增长好→收益好 |
| `ep_ttm`（市盈率倒数） | +0.043 | +0.467 | 便宜的股票好（价值因子） |
| `mom_12_1`（12 月动量） | +0.044 | +0.335 | 去年涨的今年还会涨 |
| `bp`（账面市值比） | +0.012 | +0.105 | ❌ 无效，p_bh=0.413 |

注意 `turn_20d`（-0.636）和 `q_roe`（+0.611）是训练集最强因子，但**它们没有进入最终合成**，原因见下文第 7 节。

### 3.2 `shift_result.csv` — 未来函数诊断

#### 列含义

| 列名 | 含义 |
|------|------|
| `orig_ic_ir` | 原始 IC_IR（基准） |
| `lag1_ic_ir` | 因子整体**滞后1期**的 IC_IR（模拟用"一期前的因子"预测当期收益） |
| `lead1_ic_ir` | 因子整体**提前1期**的 IC_IR（模拟用"一期后的因子"预测当期收益） |
| `ic_ir_drop` | `orig - lag1`，越大说明因子越依赖当期信息 |
| `diagnosis` | `strong_drop`=正常 / `weak_drop`=可接受 / `no_drop`=中性（不一定有问题） |
| `lead_reverse` | `True` = 下期因子比当期因子预测力更强，**疑似含未来信息** |

#### 怎么读这张表

- `diagnosis = no_drop` 但 `lead_reverse = False`：不含未来信息，正常
- `lead_reverse = True`：⚠️ 需排查，但不是确诊。月频慢变因子（如 ROE、毛利率）天然有持续性，shift 1 期 IC_IR 差异可能很小，不一定是未来函数
- 真正确诊未来函数：需配合 `tests/test_pit.py` 单元测试（用真实财报公告日验证）

#### 当前结果解读

27 个因子中，大多数 `diagnosis = no_drop`，原因是月频因子本来就变化慢（一个公司的盈利质量不会每月剧变）。`lead_reverse = True` 的因子有 14 个，但经 `test_pit.py` 验证 PIT 约束均已满足。最终 6 个入选因子均无 `lead_reverse` 告警或已通过单元测试确认。

### 3.3 `quintile_summary.csv` — 5 分组回测

#### 列含义

| 列名 | 含义 |
|------|------|
| `q1_ann_ret` | 因子值最低的 20% 股票的年化等权收益（**不含成本，不对比基准**） |
| `q5_ann_ret` | 因子值最高的 20% 股票的年化等权收益 |
| `ls_ann_ret` | Q5 - Q1（多空价差，正为做多高分组有效） |
| `directional_ls_ann_ret` | 按因子方向调整后的多空收益（负向因子取 Q1 - Q5） |
| `directional_sharpe_ls` | 方向化多空组合的夏普比率（**越高越好**） |

#### 当前结果解读（训练集，不含成本）

```
最强分组分离度：
  q_roe: Q1=+0.7%/年 vs Q5=+17.6%/年，多空价差+16.9%，Sharpe=1.62
  roe_delta: Q1=+1.1% vs Q5=+14.4%，多空+13.2%，Sharpe=1.48
  mom_12_1: Q1=-2.2% vs Q5=+14.4%，多空+16.7%，Sharpe=1.22

最终入选的 6 个因子在分组回测中：
  rev_yoy: Sharpe=1.36，ep_ttm: 0.94，mom_12_1: 1.22
  cfp: 0.84，gross_margin: 0.82，amihud: 0.68
```

**重要口径说明**：这里的收益是"个股等权原始收益"，不是超额收益，不扣成本，不代表真实可交易利润。只用来验证因子方向性。

### 3.4 `factor_correlation.csv` — 去冗余

因子之间如果高度相关（Spearman 相关系数 |r| > 0.7），加入它们对组合无益反而增加噪声。

#### 当前发现的高相关对

| 因子对 | 相关系数 | 保留哪个 | 理由 |
|--------|---------|---------|------|
| `ivol_60d` vs `vol_60d` | **+0.934** | `ivol_60d` | 特异波动率比总波动率信息更纯 |
| `roa` vs `roe` | **+0.909** | 两个都排除 | 被 `q_roe` 覆盖了 |
| `q_roe` vs `roa` | +0.802 | — | `q_roe` 最强但验证期方向翻转 |
| `np_yoy` vs `roe_delta` | +0.805 | — | 均被排除 |
| `accrual` vs `cfp` | -0.701 | `cfp` | 两个都反映现金流质量，`cfp` 方向更清晰 |

### 3.5 `final_factors.json` — 最终 6 个因子

```json
{
  "final_factors": ["amihud", "rev_yoy", "ep_ttm", "cfp", "gross_margin", "mom_12_1"],
  "_metadata": {
    "n_final": 6,
    "generated_at": "2026-05-20T13:36:14Z"
  }
}
```

**为什么是这 6 个，而不是训练集最强的 `turn_20d` 和 `q_roe`？**

筛选有四道关卡，全过才入选：

| 关卡 | 条件 | 排除原因 |
|------|------|---------|
| IC 有效性 | IC_IR 绝对值 ≥ 0.30 且 p_bh < 0.05 | 排除 8 个弱因子 |
| 去冗余 | 相关 > 0.7 的同组只留最强的 | 排除 4 个（roa、roe、vol_60d、roe_delta） |
| 验证集稳健性 | 2022 年方向翻转的因子降权 0.5 | 影响 turn_20d（另有 shift_warning）、q_roe（方向翻转） |
| Shift 警告综合判断 | shift_warning + 方向翻转 → 排除 | turn_20d、q_roe 均因此排除 |

`turn_20d` 和 `q_roe` 虽然训练集最强，但 2022 年验证集 `q_roe` 的 IC_IR 从 +0.611 变成 -0.217（方向翻转），加上时间错位测试异常，所以保守排除。

## 4. 合成信号

### 文件位置

```
data/processed/composite_signal_ic_ir.parquet   ← IC_IR 加权合成信号（主版本）
```

### 结构

行 = 调仓日（84 期），列 = 股票代码，值 = 综合因子 z-score（各期重新标准化为均值 0，方差 1）。

### 怎么读

- 正值越大 → 该股票综合"打分"越高 → 预期超额收益越大 → 优化器会给它更高超配
- 负值越小 → 打分越低 → 优化器会低配甚至不配置
- 合成后再次进行了 MAD 去极值 + z-score，所以值域也在 ±3 附近

### 合成权重是怎么计算的

IC_IR 加权：每个调仓日 T，用 T 日之前所有期的 IC 历史估计每个因子的 IC_IR，然后：

```
weight_i = IC_IR_i / sum(|IC_IR_j| for j in all factors)
```

比如，2022 年某期的权重大约是：

```
amihud:       22%（IC_IR=0.508）
rev_yoy:      22%（IC_IR=0.508）
ep_ttm:       20%（IC_IR=0.467）
cfp:          17%（IC_IR=0.389）
gross_margin: 16%（IC_IR=0.377）
mom_12_1:     14%（IC_IR=0.335）
  总计:       111%（归一化后各项减少约 2%）
```

前 12 个月历史不足时，自动退为等权合成。

## 5. 组合权重

### 文件位置

```
data/processed/portfolio_weights_optimized.parquet   ← 优化后的持仓权重（主版本）
data/processed/portfolio_weights_baseline.parquet    ← TopN 等权 baseline（V1 版本）
data/processed/portfolio_weights_meta.parquet        ← 每期优化的元信息
```

---

### 5.1 权重文件结构

行 = 调仓日，列 = 股票代码，值 = 持仓权重（小数，如 0.0030 = 持 0.3%）。

#### 中证500的基准权重是多少？

每只股票大约 `1/500 = 0.2%`（但实际按市值加权，头部股票稍高，小市值稍低）。

**超配/低配的判断**：如果你的策略持有某股票 0.5%，而基准权重是 0.2%，则超配 0.3%（恰好在单股偏离约束 ±1% 之内）。

---

### 5.2 `portfolio_weights_meta.parquet` — 优化质量监控

这是"每期到底用了哪条路"的日志，非常重要。

| 列名 | 含义 |
|------|------|
| `date` | 调仓日 |
| `fallback_level` | 0=L1（正规优化），1=L2（去掉协方差约束），2=L3（TopN 等权） |
| `constraint_compliant` | `True`=满足所有约束，`False`=有约束违反 |
| `n_stocks` | 本期持有股票数 |
| `solver_status` | cvxpy 求解状态（`optimal` / `infeasible` 等） |

#### 当前实际分布（训练/验证，84 期）

```
L1（严格优化）= 67 期（79.8%）   ← 绝大多数正常
L2（线性简化）=  2 期（ 2.4%）   ← 极少数协方差有问题
L3（TopN等权）= 15 期（17.9%）   ← 约 1/6 期无法满足所有约束

constraint_compliant = False 的期数：15 期
（均为 L3 期，候选股票数不足 100 只导致单股偏离超限）
```

**怎么理解 L3 的 15 期不合规**：

当候选股票少于 100 只时（L3 的动态计算结果），等权分配后每只权重高于 1%，违反单股偏离约束。这是"真实无可行解"——不是程序 bug，而是市场实际约束导致的。报告中必须披露，但不应因此否定策略。

## 6. 回测净值

### 文件位置

```
data/processed/backtest_nav.parquet
```

### 结构

行 = 交易日（日频），列 = `nav_strategy`（策略净值）、`nav_benchmark`（基准净值）、`nav_baseline`（V1 等权净值）。

初始值均为 1.0，每日复利滚动。

### 怎么读净值曲线

```
date        nav_strategy  nav_benchmark  nav_baseline
2022-01-04  1.0000        1.0000         1.0000
2022-01-05  0.9978        0.9982         0.9980
...
2022-12-30  0.7959        0.8045         0.8172
```

- 验证期（2022 全年）三条线都从 1 跌到 0.8 左右，这是因为 **2022 年是 A 股全年下跌超 20% 的极端熊市**
- `nav_benchmark = 0.8045`：中证500全收益指数跌了约 -19.5%
- `nav_strategy = 0.7959`：策略跌了约 -20.4%，比基准还多跌了 0.9%
- `nav_baseline = 0.8172`：V1 等权 baseline 跌了约 -18.3%，小幅跑赢基准

**关键警示**：验证期结果差（策略跑输基准）不等于策略失败，原因：
1. 2022 年是量化因子集体失效的极端年份（价值、质量、成长均亏损）
2. 项目完成标准基于测试集（2023-2025），不是验证集
3. 训练期（2016-2021）的因子有效性已经统计显著，验证期是压力测试

## 7. 回测指标

### 文件位置

```
data/processed/backtest_metrics.parquet     ← 汇总指标（parquet 格式）
reports/analysis_v2_results.md              ← 可读报告（含 Brinson 归因）
```

### `analysis_v2_results.md` 第一节：核心回测指标

```
| 版本 | 年化超额 | IR       | 超额最大回撤 | 跟踪误差 | 月胜率 |
|------|---------|----------|------------|---------|-------|
| V1   | +1.26%  | 0.173 ❌ | 11.40% ❌  | 7.32%   | 45.5% |
| V2   | -0.86%  | -0.191 ❌| 7.32% ✅   | 4.50%   | 54.5% |
```

#### 逐指标解读

**年化超额收益**（年化超额 = 策略年化收益 - 基准年化收益）

- V2 的 -0.86% 意味着 2022 年策略平均每年比基准差 0.86 个百分点
- 这是验证集（1 年）的结果，样本量极小，统计误差大

**信息比率 IR**（= 年化超额 / 年化跟踪误差）

- 项目目标：IR ≥ 0.5（完成线），IR ≥ 0.7（优秀）
- 当前 V2 IR = -0.191：未达标
- **怎么解读 IR < 0**：超额为负时，IR 自然为负，不代表"更差的选股"——只代表 2022 年选出的股票整体跑输基准
- IR 的统计意义：在 1 年（12 个月观测）里，IR 的 95% 置信区间宽度约 ±0.60，所以 -0.191 与 0 没有统计差异

**超额最大回撤**（= 策略相对基准的净值最大跌幅）

- V2 = 7.32% ✅（目标 ≤ 10%）：这个指标合格，说明策略没有出现极端单边踏空
- V1 = 11.40% ❌：等权 baseline 的行业暴露没有约束，某些时段大幅偏离基准

**跟踪误差**（= 超额收益的年化标准差，事后实测）

- V2 = 4.50%：在目标范围 4-8% 之内，说明组合约束起作用了
- V1 = 7.32%：没有协方差约束，自然更高

**月胜率**（= 每月超额为正的月数 / 总月数）

## 8. 归因报告

归因 = 解释"策略相对于基准的那部分超额收益（或亏损），到底是从哪里来的"

### 文件位置

```
reports/analysis_v2_results.md     ← 自动生成的完整报告，包含 Brinson + 因子归因
```

---

### 8.1 Brinson BHB 行业归因（报告第 2 节）

```
| 效应           | 全期累计 |
|---------------|---------|
| 配置效应        | +2.66%  |
| 选股效应        | -3.48%  |
| 交叉效应        | +0.01%  |
| 总超额收益（汇总）| -0.83%  |
```

**三个效应的含义**

| 效应 | 问的问题 | 正值代表 |
|------|---------|---------|
| **配置效应** | 超配了好行业、低配了差行业吗？ | 行业配置决策带来超额 |
| **选股效应** | 在每个行业内，选出的股票比该行业整体好吗？ | 行业内选股创造超额 |
| **交叉效应** | 超配了好行业且选中了好股票（双重正确）？ | 微小协同效应 |

**当前结果解读**

- **配置效应 +2.66%**：策略在 2022 年的行业配置是对的——超配了跌得少的行业、低配了跌得多的行业
- **选股效应 -3.48%**：但是在每个行业内，选出的个股比行业平均表现更差
- **合计 -0.83%**：行业配置赚的钱，被个股选择的亏损抵消后还多亏了 0.83%

这告诉我们：**2022 年问题出在个股选择，而不是行业判断**。6 个因子（价值、质量、成长、动量）在 2022 年熊市中，无法区分同行业内的优劣个股。

### 8.2 因子收益归因（报告第 3 节）

```
| 因子组    | 全期累计贡献 |
|---------|-----------|
| 价值因子  | -1.74%    |
| 质量因子  | -0.59%    |
| 成长因子  | -0.92%    |
| 动量因子  | +0.07%    |
| 波动率因子 |  0.00%    |
| 流动性因子 | -0.91%    |
| 资金流向  |  0.00%    |
| 残差     | +3.14%    |
| R²（平均） | 0.048    |
```

**怎么读这张表**

每一行 = 策略对该因子的总暴露 × 该因子在 2022 年的实际因子收益。

- **价值 -1.74%**：策略超配了 EP（市盈率倒数高）的股票，但 2022 年"便宜股"反而跑输市场（价值陷阱）
- **成长 -0.92%**：策略超配了营收增速高的股票，但 2022 年成长股大跌
- **动量 +0.07%**：12 个月动量因子几乎没有贡献（2022 年动量效应失效）
- **残差 +3.14%**：所有因子解释不了的部分。这里是正的，说明**因子之外的特异选股贡献了正收益**，但被因子的集体亏损淹没了

**R² = 0.048 是什么意思**：用 6 个因子解释个股收益的截面回归，平均 R² 只有 4.8%。这说明 2022 年大多数个股收益由市场整体（系统风险）驱动，因子暴露能解释的不到 5%。正常年份 R² 通常在 10-20%。
