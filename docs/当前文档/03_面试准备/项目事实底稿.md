### 3.2 PIT：已实现什么、尚未证明什么

确认的查询逻辑：[pit_loader.py](../../../src/data/pit_loader.py)、[loader.py](../../../src/data/loader.py)。

1. 首先过滤 `pit_date <= T` 与 `end_date < T`，再按可见报告期和版本取快照。当前代码允许 `pit_date == T`，没有盘中时间戳。
2. TTM 对流量字段使用“上年年报 + 本期累计 − 上年同期累计”，最新为年报时直接用年报；上一年年报年份不匹配或关键项缺失时返回 NaN。
3. `make_ttm/get_pit_latest` 默认陈旧阈值 9 个月；`get_roe_delta/get_field_yoy_delta` 没有统一应用该阈值。
4. `get_quarterly_history` 按已有报告期排序取最近 N 条，但没有证明报告期连续；q0、q4 只有在报告期连续时才可靠代表同比位置。
5. 转换阶段保留不同 `pit_date` 的记录，而不是将所有历史仅压成最新一条。但同日去重使用 `groupby.last()`，可能按列跳过缺失值；三表按股票和报告期外连接不同版本，再按最大可用日归并。保留版本的意图不能代替逐字段版本一致性验证。

重要术语纠正：源码注释把 `f_ann_date` 写作“首次披露日”，官方文档定义是“实际公告日期”。`report_type=1` 是合并报表；官方还区分调整合并表、调整前合并表等类型。当前只保留 type=1，不能据此宣称保留了供应商的全部原始修订版本。[Tushare 利润表及报表类型](https://tushare.pro/document/2?doc_id=33)

三表 `pit_date=max(...)` 仅取存在记录的最大日期；缺表时跳过 NaT。因此“等待三张表全部披露才可用”不是所有行都满足的严格契约。

**可用于面试的事实表述：**“实现公告日期驱动的历史可见快照和 TTM 构造，并通过合成案例验证边界；真实公告、修订版本与供应商字段的人工核对仍未全部完成。”

**不能写：**“已完全消除未来函数”“所有财务历史版本都已准确还原”“公告过滤通过就证明 PIT 数据正确”。

### 3.3 成分股、状态与数据质量

[universe.py](../../../src/data/universe.py) 将因子计算域与交易约束域分开：因子使用 `tradable=True`；优化使用全体当期成分及状态。新股阈值实际是 180 日历天，不是严格六个自然月。金融行业排除代码为银行 `801780.SI`、非银金融 `801790.SI`，由财务因子预处理应用。

官方 `index_weight` 文档将 `trade_date` 标作交易日期，数据为月度成分权重；它本身没有证明每条日期就是成分调整生效日。当前不能写“已与正式生效公告完成核对”。[Tushare 指数成分和权重](https://tushare.pro/document/2?doc_id=96)

本轮确认下载函数重试耗尽后返回空表，空表可以写为文件；`_done()` 仅检查文件存在。这意味着失败可能被后续断点续传永久跳过。转换模块存在先写正式 Parquet、再断言质量的顺序问题。

## 5. 预处理与因子准入

### 5.1 当前预处理顺序

`财务因子金融行业置NaN → 当日MAD截尾 → Z-score → 行业+log自由流通市值OLS残差 → 再Z-score`。

MAD 默认边界为 `median ± 3×1.4826×MAD`；MAD 为零有标准差退化路径。中性化回归只在三个输入均有效的子样本进行。但样本少于 30 或回归异常时，当前函数返回原因子并继续标准化，不能保证所有输出已中性化。[preprocess.py](../../../src/factors/preprocess.py)

因子构建层还有已登记的失败放行风险：异常转全 NaN、完整性只按日期判断、resume 只向后追加、诊断路径隔离不完整。未因本次事实盘点而修复。[历史因子审计](../02_学习材料/阶段04_因子构建与预处理.md)

### 5.2 当前筛选规则

来源：[run_factor_evaluation.py](../../../scripts/run_factor_evaluation.py)、[ic_analysis.py](../../../src/evaluation/ic_analysis.py)、[config.py](../../../src/config.py)。

- 单月 Rank IC 是截面 Spearman 相关；IC_IR 是月度 IC 均值除以样本标准差，**此处没有乘 √12**。
- t 统计量为 `mean/(std/sqrt(n))`，p 值用双尾 t 分布；批量用 BH 校正。代码不是 HAC/Newey–West 检验。
- 有效性门槛：`abs(IC_IR)>=0.30`、`abs(IC_mean)>=0.02`、BH p<0.05、方向一致期占比至少 0.55。
- 再结合时间错位警告、高相关去冗余（阈值 0.70）、`abs(directional_sharpe_ls)>=0.50`、IC decay gate 得到 final_include。
- 注意代码对方向化 Sharpe 取了绝对值，因此“必须正向多空 Sharpe≥0.5”不是准确复述。
- 训练内三段稳定性决定 1.0/0.5 权重；验证期方向翻转字段目前只用于报告，没有直接进入 final_include 表达式。
- 训练收益按标签退出日过滤，避免跨越训练末端。五分组检验直接聚合前向收益，不能当作带完整执行约束与交易成本的可交易多空策略。

历史 18 因子的训练统计均在附件中。展示值中有 p=0.0，是保存前舍入造成，不能表述为“零概率假阳性”。验证期部分因子方向翻转，例如 `piotroski_f` 历史训练 IC_IR=0.6146、验证=-0.2002；这只能说明该份旧产物的跨期差异，不能单凭它断言因子无效或应删除。

时间错位测试的边界：慢变量滞后后仍有预测力不自动等于泄露；未来因子与当前收益相关也不自动证明原始因子泄露。正式代码包含 lead/lag 诊断，但其阈值和部分注释不应被当成“无未来函数证明”。逐因子截断未来输入、公告样本核对和标签可见性测试仍有必要。

## 6. 信号合成与模型选择

### 6.1 主线 Ridge 的实际算法

证据：[Ridge 阶段调用](../../../src/pipeline/stages.py)、[Ridge 基类](../../../src/signal/ridge_combiner.py)、[滚动子类](../../../src/signal/ridge_rolling.py)、[衰减子类](../../../src/signal/ridge_decay.py)。

| 项目 | 当前实现 |
|---|---|
| 训练矩阵 | 将历史月份×股票观测合并，每列一个因子；不是每个因子单独回归再平均 |
| 目标 | 构造器默认 `use_excess_return=False`，stage 未传 True，也未传基准收益序列 |
| 标签来源 | 共享 `fwd_ret_panel.parquet`；当前生成入口默认个股后复权开盘到开盘原始收益 |
| 配置矛盾 | Spec `target="excess_return"` 未实际驱动该分支；共享缓存未锁定，历史标签内容不能只由当前代码推断 |
| 缺失处理 | 单股至少8个有效因子且标签有效；其余因子补0；单月不足10只跳过 |
| 最低训练规模 | 至少24个训练日期、合并后500个观测 |
| 正则化目标 | sklearn Ridge 带截距；平方误差加 L2 系数惩罚 |
| alpha选择 | 默认2015、2016、2017、2018、2019五个年份的时间序列CV，以各折预测Rank IC的IC_IR平均评分 |
| 网格 | 0.1、1、10、100、500、2000、5000；该run记录选5000 |
| 月度训练 | alpha先选一次；每个T重新拟合系数，不是每月重新选择alpha |
| 输出 | 模型预测再次MAD去极值与Z-score；成为截面得分，不能直接当预期收益百分点 |
| 稳定性权重 | 当前Ridge stage没有将final_factors.json的0.5/1.0权重传入模型；IC_IR分支有使用 |

滚动区间精确定义：令 `cutoff=T−2个日历月`，保留 `(cutoff−48个月, cutoff]` 的实际调仓日期。不是注释中的 `(T−48个月,T−2个月]`，也不是“48减2，最多46期”。合成月末日历案例复现了48个日期；真实交易月末日期要按同一不等式判断，不能仅凭月份编号。

前向标签当前公式为 `open_adj(T下一交易日之后的下一调仓执行日) / open_adj(T下一交易日) − 1`，即从本次 T+1 开盘到下一次 T′+1 开盘。purge 是日历月截止近似；本轮未逐个历史标签核对退出时间。

缓存抽查：以2021-01-29为信号日，读取5只股票2021-02-01与2021-03-01后复权开盘价，当前缓存标签与原始开盘到开盘收益全部精确一致（绝对差0）。股票及数值见附件`current_label_sample`。这支持“当前缓存该样本是原始收益”这一结论，不证明全部缓存或2026-06运行当时使用的标签完全相同。

还有两项统计纪律边界：

1. alpha在2015—2019折上先选，再回填2014开始的历史信号，因此2014等早期训练段不是当时可实施的完全嵌套样本外结果。不能拿整段训练信号宣称“每个历史T的全部决策只用T前信息”。验证2021—2022时这些CV年份已过去，但仍有下项限制。
2. 18因子是训练全期筛出的清单，再用于训练内部CV；因子选择没有在每个CV折内部重新进行。CV评分不等于包含因子筛选在内的嵌套无偏评价。滚动长度、TopN等又有验证期比较历史，所以“alpha只用训练集”不等于“验证集完全未参与研究选择”。

### 6.2 其他合成分支

[combiner.py](../../../src/signal/combiner.py) 实现 IC_IR 加权：取T之前的历史IC再丢掉最近一期，默认回看24期，历史不足退回等权；生产stage最低有效因子数为5，与Ridge默认8不同。规则应与标签退出日对齐，稀疏日期下“删最后一行”不能替代完整时间审计。

另有 expanding Ridge 与指数衰减 expanding Ridge 实现；它们是已实现研究分支。树模型、Lasso/Elastic Net、神经网络不应写成已完成的模型比较成果。后续面试文档可以讨论选择条件，但本步不新增模型或依赖。

## 7. 从信号到持仓：TopN 与 QP 的真实边界

### 7.1 主线 TopN

来源：[optimizer.py](../../../src/portfolio/optimizer.py)，`_topn_equal_weight` 与 `optimize_topn_equal_weight_all_periods`。

主线会锁定停牌、保留跌停持仓、排除不可新买入候选，在剩余预算内分配高排名股票。它复用了L3辅助函数，包含 `single_max_dev` 相关的最少股票数、强制持有较大基准成分、上限截断与再分配。

**对上一轮概括的修正：**TopN 不执行 TE 二次约束、行业偏离约束和换手惩罚，但 `single_max_dev` 并非完全不生效。不能写“主线是无任何约束的纯等权”，也不能反过来说“主线运行了完整QP风险约束”。

主线106期元数据均为 `solver_status=topn_ew_forced`，`fallback_level=2`，`w_prev_source=target_weight`，`constraint_compliant=True`。数字编码是0/1/2对应L1/L2/L3；强制TopN记录为2不表示QP失败了106次。合规标记仅是当前函数检查结果，不能证明所有交易和风险规则均通过。

两个关键限制：

- 上期输入是目标权重，不是执行后漂移到本次调仓时的实际持仓；成分移除、不能成交和价格漂移会使两者不同。
- 排名把NaN放末尾，没有彻底排除。最小案例三只股票全部NaN、请求N=2，返回 `[0.5,0.5,0]` 且合规标记True。它没有经济上的有效选股依据；本轮没有断言历史主线发生过同样全空场景。

### 7.2 QP 候选分支

日频协方差默认使用252交易日回看，LedoitWolf收缩，检查并修复正定性。收益矩阵按代码顺序对齐；缺失收益全部填零属于尚需细化的近似。[covariance.py](../../../src/portfolio/covariance.py)

L1目标为 `max alpha'w − lambda·||w−w_prev||₁`，加权重、单股、行业、交易状态和主动风险二次约束；L2去掉TE二次约束；L3退到TopN。严格术语上，L1带二次约束与L1范数项，不宜在面试里只笼统说“标准二次目标QP”。项目内部沿用QP命名。

TE使用日协方差，方差阈值为 `annual_TE²/252`。约束股、持仓漂移、求解容差与未来风险变化都会影响事后TE，因此事前约束不等于事后跟踪误差保证。

历史实验曾固定同一信号比较TopN与QP、调整TE及行业约束。可以写“做过控制变量实验”，但本轮尚未逐run重建公平可比性；不能把“观察到TopN更好”写成“证明所有QP不适用”或“已经确定收益差来自某个单一原因”。

## 8. 回测、成本和实际绩效

### 8.1 交易实现

[engine.py](../../../src/backtest/engine.py) 使用T日目标，映射下一交易日开盘执行，持有后复权份额并按后复权收盘估值。执行时先确定卖出，再用现金和卖出所得按比例分配买入。它是研究级份额模拟，不等于真实整数股、整手、集合竞价撮合或实盘订单系统。

当前成本函数：[transaction.py](../../../src/backtest/transaction.py)。配置为买卖各2.5bps佣金、各8bps滑点；卖出印花税按配置在2023-08-28切换10→5bps。本主线验证2021—2022段适用10bps。滑点在代码中体现为按成交额计算的成本，不是独立撮合出的成交价。费用字段的实现确认不代表费用假设对任意资金规模都真实。

当前状态包括LOCKED、NO_BUY、NO_SELL、BUY_LIMIT、FREE；缺失状态有保守转换路径，但开盘执行使用日级涨跌停/开板信息的可见性、未成交是否持续追单、非整手和容量约束仍需专项审计，不能笼统宣称“严格还原全部A股交易制度”。

### 8.2 已复现：交易成本改变锁定份额

合成案例：总资产200元，A持有1份、开盘100元且LOCKED；另有100元现金买B，B开盘100元，目标各50%。2021年日期买入费用0.105元。

当前函数将全部新份额乘 `1−0.105/200=0.999475`，返回A份额0.999475，虽然A被记录为锁定且没有卖出。**资金价值近似对账不代表不可交易份额守恒。**即便现金足够支付费用，该统一缩放方法也不是严格从现金扣费。

本轮现有锁仓测试通过，是因为对应测试没有覆盖“别的股票交易产生费用、锁仓股同时存在”的联合场景。问题已在合成输入复现，未修改引擎，也未测算收益偏差。后续修复方向应是预留费用、按可用现金缩减可交易买单、费用扣现金且锁定份额不变；这里没有代用户选定新的费率或风控阈值。

## 9. 归因能力与结论边界

实现确认：[brinson.py](../../../src/attribution/brinson.py)、[factor_attr.py](../../../src/attribution/factor_attr.py)、[run_attribution.py](../../../scripts/run_attribution.py)。

- 行业归因拆配置、选股、交互效应，使用期间起始实际股票权重与月末基准权重。当前配置项公式是 `(Wp−Wb)×(Rb行业−Rb整体)`；应按公式解释，不能只背代码里的BHB名称。
- 因子归因先合成因子组，横截面WLS拟合期间个股收益；权重是基准权重。贡献为因子收益×主动暴露差。
- 回归所得因子收益不等于Ridge训练系数；因子暴露不等于贡献；会计归因不是因果识别。
- 因子残差定义为“重构超额−已解释贡献”。因此“贡献+残差=超额”由构造保证，不能单独证明解释充分或对账正确。仍要核对独立回测NAV、费用、现金和基准差异。
- 行业归因如果股票权重和不足1且未把现金完整纳入，去基准收益的配置项会留下现金相关差额；归因收益缺失填0也会影响解释。
- 本主线没有完整归因产物，本轮未执行归因。不能写“9.35%超额主要来自某某因子／行业，已经定量证实”。

现有信号到持仓诊断中的TC是权重与信号的Spearman代理；`ir_actual` 使用权重×原始前向收益构造的月度指标，不是扣费、扣基准后的正式组合IR。`ir_loss_pct` 来自简化理论式与该代理比较，**45.77%不能称为优化器吞掉45.77%的真实超额收益**。[signal_quality.py](../../../src/evaluation/signal_quality.py)

1. IC=0.047不代表47%排序正确，也不代表剩余53%是噪声。
2. 多元Ridge系数与单因子IC异号不自动证明“系数方向学错”；需考虑相关特征、条件效应、标准化与样本变化。
