## 一、从哪里开始

1. AI 新会话先完整读取项目根目录 `AGENTS.md` 第 0 节；人工阅读先用根目录 `README.md` 了解项目和真实目录结构。
2. 再读[学习与审计主线](01_项目治理/学习与审计主线.md)，确定当前阶段、完成门槛和未决问题。
3. 涉及业务参数和项目决策时，查[项目规则与决策](01_项目治理/项目规则与决策.md)。
4. 学习具体模块时，按“阶段教学材料”阅读；需要逐文件理解源码时再查“源码精读”。任务到文档、代码和测试的详细映射见根目录 `AGENTS.md` 第 0.3 节。
5. 准备简历和面试时，先查[项目事实底稿](03_面试准备/项目事实底稿.md)，再阅读其他表达材料。
6. 历史计划、旧教学材料和过程记录统一位于[历史归档](../历史归档/README.md)。
