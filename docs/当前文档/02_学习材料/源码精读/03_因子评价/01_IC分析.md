## 二、时间对齐与 PIT 假设

### Forward Return 对齐约定（关键）

```
fwd_ret[T, stock] = open_adj[T'+1] / open_adj[T+1] - 1
```

- **T**：因子观测日（调仓日，盘后生成信号）
- **T+1**：T 之后第一个实际交易日（**买入执行**）
- **T'**：下一个调仓日
- **T'+1**：T' 之后第一个实际交易日（**卖出执行**）

> 这比"T 收盘→T' 收盘"更准确：T 盘后才能生成信号，T 收盘价对 T 盘后成交无法保证。

### 样本切分的时间边界（build_exit_date_map 的意义）

IC 的 `index` 是调仓日 T，但该 IC 对应的 forward return 的**卖出时点**是 `T'+1`（约一个月后）。如果直接按 T 切分训练集，会把"T 日因子对应的收益延伸到 T'+1"的观测错误地纳入训练集，造成微妙的前视偏差。

`build_exit_date_map()` 的用途：让调用方按 `exit_date < 训练集结束日` 过滤 IC 矩阵，而非按 T < 训练集结束日过滤。

```python
# 典型用法（在 run_factor_evaluation.py 中）
exit_map = build_exit_date_map(rebalance_dates)
train_mask = exit_map.values < TRAIN_END_DATE   # 按 exit_date 切分，不按 T 切分
```

### IC 权重的时间约束

`combiner.py::compute_rolling_ic_ir()` 要求 IC 权重只用 `index < before_date` 的历史，且还需丢弃最近一期（因为 IC(T-1) 的 exit_date ≈ T+1，T 盘后不可得）。IC 计算本身不带这个约束，由调用方（combiner）保证。

## 四、核心函数逐一解析

### 4.1 `compute_rank_ic` — 单截面 Rank IC

```python
# L57–73
def compute_rank_ic(factor: pd.Series, fwd_ret: pd.Series) -> float:
```

**参数**：
- `factor`：当期截面因子值（index = ts_code），可含 NaN
- `fwd_ret`：对应下期收益率（index = ts_code），可含 NaN

**执行逻辑**：
1. 取 factor 和 fwd_ret **均非 NaN** 的股票交集（`common`）
2. 若 `len(common) < 10`，返回 NaN（样本太少，Spearman 相关无统计意义）
3. 对 `common` 中的股票计算 **Spearman（秩）相关系数**

**为什么用 Rank IC 而非 Pearson IC？**
- Rank IC（Spearman）对异常值不敏感：极端因子值（如 st 股票超大 PE）不会扭曲相关系数
- A 股截面偏斜严重，Pearson IC 的统计性质较差
- 行业惯例：量化研究中"IC"默认指 Rank IC

**注意**：函数不做去极值或标准化，这是调用方（factor_panel 已预处理）的职责。

### 4.2 `compute_ic_series` — 跨所有调仓日的 IC 时序

```python
# L76–108
def compute_ic_series(
    factor_panel: pd.DataFrame,
    fwd_ret_panel: pd.DataFrame,
    min_coverage: float = 0.0,
) -> pd.Series:
```

**参数**：
- `factor_panel`：行=调仓日，列=ts_code 的因子值矩阵
- `fwd_ret_panel`：行=调仓日，列=ts_code 的下期收益矩阵
- `min_coverage`：**新增参数**（v1 无此参数）。覆盖率过滤阈值，默认 0.0（不过滤，向后兼容）

**min_coverage 的设计细节**（L93–103）：

```python
# L93–103  — 覆盖率过滤逻辑
if min_coverage > 0.0:
    notna_per_date = factor_panel.notna().sum(axis=1)
    max_notna = notna_per_date.max()           # 以最大有效数为分母
    if max_notna > 0:
        dates = [d for d in dates
                 if notna_per_date.get(d, 0) / max_notna >= min_coverage]
```

> **重要设计决策**：分母用 `max_notna`（历史最大有效股票数），而不是 `len(columns)`（panel 的总列数）。
>
> 原因：`factor_panel` 的列是所有期成分股的并集（可能有 2000+ 列），每期实际可投资只有约 500 只。用列数做分母会使每期覆盖率永远 < 25%，导致所有期被过滤。

**返回值**：以调仓日为 index 的 IC Series，**已 dropna**（有效样本 < 10 或覆盖不足的期返回 NaN 并被丢弃）。

### 4.4 `ic_summary` — IC 统计量

```python
# L162–212
def ic_summary(ic_series: pd.Series) -> dict:
```

**返回字段**：

| 字段 | 计算方式 | 含义 |
|------|---------|------|
| `n` | `len(valid)` | 有效 IC 观测数 |
| `ic_mean` | `valid.mean()` | IC 均值（正负表示方向） |
| `ic_std` | `valid.std(ddof=1)` | IC 标准差（使用无偏估计） |
| `ic_ir` | `ic_mean / ic_std` | IC 信息比率 |
| `t_stat` | `ic_mean / (ic_std / sqrt(n))` | t 统计量 |
| `p_value` | 双尾 t 分布 p 值 | 统计显著性 |
| `pct_positive` | `(valid > 0).mean()` | IC > 0 的月份占比 |

**边界保护**（L186–196）：`ic_std < 1e-12` 时（所有 IC 完全相同，极端异常），`ic_ir/t_stat/p_value` 返回 NaN，但 `ic_mean/ic_std` 仍如实返回。

**注意**：`pct_positive` 不能直接用来判断负向因子的有效性（详见 4.5 节）。

### 4.6 `compute_forward_returns` — 月度收益率面板

```python
# L255–361
def compute_forward_returns(
    rebalance_dates: list[pd.Timestamp],
    codes: list[str],
    codes_by_date: Optional[dict[pd.Timestamp, list[str]]] = None,
    benchmark_code: Optional[str] = None,
) -> pd.DataFrame:
```

**参数**：
- `rebalance_dates`：调仓日列表
- `codes`：股票代码（兜底参数）
- `codes_by_date`：每期动态可投资股票字典（推荐，解决成分股动态变动问题）
- `benchmark_code`：基准指数代码（如 `"000905.SH"` 中证 500 全收益），提供时返回**超额收益**

**执行流程**（L288–361）：

```
步骤 1: 确定加载的股票代码集合
  codes_by_date 非空 → 取所有期成分股并集
  否则 → 使用静态 codes 列表

步骤 2: 为每个调仓日确定 (T, T+1, T'+1) 三元组

步骤 3: 一次性批量加载 open_adj（避免 N 次 I/O）
  加载范围：min(entry_dates) ~ max(exit_dates)

步骤 4: 若提供 benchmark_code，加载 index_quote.parquet 的 nav 列
  bm_ret[T] = nav[T'+1] / nav[T+1] - 1

步骤 5: 对每个 T 计算截面 forward return
  fwd = open_pivot[exit] / open_pivot[entry] - 1
  若有基准: fwd = fwd - bm_ret[T]
```

**codes_by_date 的必要性**：若只用静态 `codes`（首期成分股列表），后期新进指数的股票无法获得 forward return，会导致 IC 样本越来越稀疏。动态 `codes_by_date` 确保每期成分股变动都能被 IC 捕捉。

**基准数据来源**：`cfg.DATA_PROC / "index_quote.parquet"` 的 `nav` 列（全收益指数，含分红再投资）。若 `nav` 列缺失，自动回退为不扣减基准（记录 warning）。

### 4.7 `batch_ic_test` — 批量因子 IC 检验（含 BH 校正）

```python
# L368–436
def batch_ic_test(
    factor_panels: dict[str, pd.DataFrame],
    fwd_ret_panel: pd.DataFrame,
    alpha: float = PVALUE_ALPHA,
    min_coverage: float = 0.0,
) -> pd.DataFrame:
```

**这是因子筛选的核心入口**，一次性对所有候选因子计算 IC 并做多重检验校正。

**BH 多重检验校正**（L407–417）：

```python
# L407–417 — BH (Benjamini-Hochberg) 校正
_, p_corrected, _, _ = multipletests(p_raw, method="fdr_bh", alpha=alpha)
result.loc[valid_mask, "p_value_bh"]    = p_corrected
result.loc[valid_mask, "significant_bh"] = p_corrected < alpha
```

> **为什么用 BH 而非 Bonferroni？**
> Bonferroni 控制 FWER（任意一次假阳性的概率），适合要求极严的场景。
> BH 控制 FDR（假阳性在所有"发现"中的比例），更适合因子筛选这种需要在**显著性与因子数量**之间取得平衡的场景。
> 若 30 个因子中有 5 个真实有效，Bonferroni 会漏掉大多数，BH 能以可控的假阳性率识别出有效因子。

**`pct_consistent_dir` 的设计**（L422–424）：

```python
# L422–424 — 方向一致性（处理负向因子）
result["pct_consistent_dir"] = result["pct_positive"].apply(
    lambda p: max(p, 1.0 - p) if pd.notna(p) else np.nan
)
```

> **为什么不直接用 pct_positive？**
> 对于负向因子（如 `vol_60d`、`accrual`），IC 稳定为负是**有效信号**，但 pct_positive < 0.45。
> 若用 `pct_positive >= 0.55` 作为有效标准，所有负向因子都会被错误排除。
> `pct_consistent_dir = max(pct_positive, 1 - pct_positive)` 衡量"IC 方向是否稳定"，与方向本身无关。

**综合有效性判断**（L427–432）：

```python
# L427–432 — effective 判断（4 个条件同时满足）
result["effective"] = (
    (result["ic_ir"].abs()              >= IC_IR_THRESHOLD)   # |IC_IR| >= 0.30
    & (result["ic_mean"].abs()          >= IC_MEAN_THRESHOLD) # |IC均值| >= 0.02
    & result["significant_bh"]                                # BH p < 0.05
    & (result["pct_consistent_dir"]     >= IC_POS_THRESHOLD)  # 方向稳定性 >= 0.55
)
```

这四个条件的逻辑：
1. IC_IR 衡量信号**强度与稳定性**的综合（不只看均值，也看标准差）
2. IC 均值兜底：防止 IC_IR 高但均值接近零（高 IC_IR 可能是 IC_std 很小，即极其稳定但幅度极小）
3. BH 显著性：统计上是否真实存在预测力
4. 方向稳定性：排除"偶然一期极大值拉高均值"的幸存者偏差

**输出**：按 `|IC_IR|` 降序排列的 DataFrame，包含 `n/ic_mean/ic_std/ic_ir/t_stat/p_value/p_value_bh/significant_bh/pct_positive/pct_consistent_dir/effective`。

**方法**：对每个调仓日 T 独立计算截面 Spearman 相关矩阵，再在时间轴上取均值。

**关键实现细节**（L475–489）：

corr_sum = pd.DataFrame(0.0, ...)

### 4.10 `compute_ic_decay` 与 `batch_ic_decay` — IC 衰减分析（v2 新增）

```python
# L561–648
def compute_ic_decay(factor_panel, fwd_ret_panel, max_lag=3, ...) -> dict
def batch_ic_decay(factor_panels, fwd_ret_panel, max_lag=3, ...) -> pd.DataFrame
```

**IC Decay 的含义**：测量"当期因子预测 k 期后单期收益"的能力。

```
lag=1: IC(factor_T, fwd_ret[T])          原始 IC（与 batch_ic_test 一致）
lag=2: IC(factor_T, fwd_ret[T+1 period]) 1 期后收益
lag=3: IC(factor_T, fwd_ret[T+2 period]) 2 期后收益
```

> **注意**：这里测量的是"当期因子对未来第 k 期的单期预测力"，而不是累积收益。  
> lag 2 的 fwd_ret 使用 `fwd_ret_panel.shift(-1)`，即将收益序列向前移一期与 factor_T 对齐。

**ic_decay_pass 判断**（L633–642）：

```python
# L633–642
df["ic_decay_pass"] = (
    lag1.notna() & lag3.notna() & ((lag1 * lag3) > 0)
)
```

`ic_decay_pass = True` ← lag3 IC_IR 与 lag1 IC_IR **同号**。

**月频可用性标准**（来自 `docs/历史归档/旧教学体系/通用指南_旧版/improvement_guide.md` 阶段 3.5）：
- lag3 与 lag1 同号 → 信号在第 3 个月仍保持方向，月频换仓可以有效捕捉
- lag2 方向已反转 → 信号寿命不足 2 个月，月频换仓时信号已消失

`ic_decay_pass=False` 的因子会被 `run_factor_evaluation.py` 标记为潜在排除候选（但不是 Gate，而是辅助参考）。

## 八、失败与降级路径

| 失败场景 | 行为 |
|---------|------|
| 有效股票数 < 10 | `compute_rank_ic` 返回 NaN，IC 时序中该期被 dropna 丢弃 |
| 因子面板无公共调仓日 | `compute_factor_correlation` 返回全 NaN 矩阵，并输出 warning |
| `factor_names` 含不存在因子 | `build_ic_history` 抛 KeyError（快速失败） |
| `index_quote.parquet` 缺 nav 列 | `compute_forward_returns` 降级为不扣减基准，记录 warning |
| IC 序列有效期 < 2 | `ic_summary` 返回全 NaN 统计量，`n` 字段如实记录 |

## 十、领域知识补充

### IC_IR 与 Sharpe 的类比

IC_IR（Information Coefficient Information Ratio）的计算形式与 Sharpe 比率完全一致：
```
IC_IR = IC_mean / IC_std
Sharpe = Excess_Return_mean / Excess_Return_std
```

**含义**：IC_IR 衡量因子在截面上**一致性地**预测下期收益的能力。IC_IR = 0.30 对应「因子在 12 期中有 10 期同向，另 2 期有轻微反向」这一水平，是量化研究中常用的有效因子入门门槛。

### BH vs Bonferroni 多重检验校正

同时检验 N 个假设时，若对每个假设用同一显著性水平 α，则"至少 1 次假阳性"的概率接近 `1 - (1-α)^N`：

| N 个假设 | α=0.05 | 至少 1 次假阳性概率 |
|---------|--------|-------------------|
| 10 | 0.05 | 40% |
| 30 | 0.05 | 79% |

- **Bonferroni**：将 α 除以 N，极其保守（`α_adj = 0.05/30 ≈ 0.0017`），会漏掉真实有效因子
- **BH（Benjamini-Hochberg）**：对排序后的 p 值做线性校正，控制 FDR（False Discovery Rate）≤ α，而不是 FWER（Family-Wise Error Rate）。在因子筛选场景中，"发现 30 个候选因子中最终有 1.5 个是假阳性"比"必须 99.9% 确信每个因子都是真阳性"更实用。

### Spearman vs Pearson 相关系数

| 特性 | Spearman（Rank IC） | Pearson（线性 IC） |
|------|-------------------|-----------------|
| 对异常值敏感性 | 不敏感（先排名再计算）| 高度敏感 |
| 衡量关系类型 | 单调关系（非线性也能捕捉）| 仅线性关系 |
| 计算复杂度 | 同 Pearson（对秩序列）| 低 |
| A 股适用性 | 更高（PE 等因子有极端值）| 较低 |

Rank IC 等价于：先对截面因子值和收益率分别排名，再对排名序列计算 Pearson 相关系数。
