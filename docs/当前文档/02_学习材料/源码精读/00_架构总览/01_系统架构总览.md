## 四、信号路径详解（Layer 3 三条路径对比）

| 维度 | 路径 A：IC_IR 加权 | 路径 B：Ridge | 路径 C：Decay Ridge |
|---|---|---|---|
| 参数 | `method="icir"` | `method="ridge"` + `training_mode="expanding"/"rolling"` | `method="ridge"` + `training_mode="decay_weighted_expanding"` |
| 核心逻辑 | 每个调仓日，用历史 IC_IR 作为因子权重加权合成 | 用因子值矩阵作特征回归未来收益，Ridge 正则化防过拟合 | 与路径 B 相同，但训练样本使用指数衰减权重 |
| 训练窗口 | 滚动，`SIGNAL_WINDOW_MONTHS=24` 期 IC 历史 | expanding（全历史）或 rolling（固定窗口） | expanding（全历史），衰减参数 `half_life_months` |
| 关键参数 | `SIGNAL_MIN_IC_HISTORY=12`（冷启动门槛）| `purge_months=2`（防数据泄露间隔）| `half_life_months`（衰减半衰期，单位月）|
| 代码入口 | `combiner.py: SignalCombiner.combine()` | `combiner.py` → `RidgeCombiner` / `RidgeRollingCombiner` | `ridge_decay.py: RidgeDecayCombiner` |
| 验证期代表实验 | `frozen_baseline_icir_topn50_ew`（IR=0.924，冻结）| `rolling48_ridge_topn50_ew`（IR=1.771）| `decay_hl24_ridge_topn50_ew`（IR=0.626，hl36/48 IR FAIL）|

**注意**：`stages.py` 模块 docstring（约 L38）仍写"decay_weighted_expanding — 尚未实现，抛出 NotImplementedError"，但实际 L175-184 已接入 `RidgeDecayCombiner`。该 docstring 是过时残留，撰写 ../07_实验流水线/02_阶段编排.md 时需标注并建议修复。

## 五、组合构建路径详解（Layer 4 两条路径对比）

| 维度 | 路径 QP | 路径 EW |
|---|---|---|
| 参数 | `optimizer_mode="qp"` | `optimizer_mode="topn_ew"` |
| 协方差 | 需要（LedoitWolf，24 个月日频收益率）| **不需要** |
| 求解器 | cvxpy（CLARABEL → SCS → ECOS）| 无 |
| 约束 | TE ≤ 6%（年化）+ 行业偏离 ≤ 3% + 单股偏离 ≤ 1.5% | 仅停牌/涨跌停感知 |
| Fallback | L1 → L2 → L3（TopN等权）| 无 Fallback（本身就是 L3）|
| 用途 | 正式生产方案 | 隔离优化器噪声的对照实验工具 |
| 关键发现 | QP 对所有 Ridge 信号均造成 IR 损耗（-0.166 ~ -0.431）| 验证期表现优于 QP，根因待诊断 |

## 六、runs/ 目录结构

每次 `run_experiment.py` 完成后生成不可变 run 目录：

```
runs/
├── train_valid/                    ← allow_test_set=False 的所有 run
│   └── 20260527_142056__challenger_rolling48_te6_lam0050/
│       ├── run_config.json         ← spec 快照 + 运行参数
│       ├── inputs_lock.json        ← 上游信号文件的 SHA256 锁
│       ├── signal/
│       │   ├── composite.parquet   ← 合成信号面板（调仓日 × 股票）
│       │   ├── coef_history.parquet← Ridge 系数历史（仅 Ridge 路径）
│       │   └── weight_history.parquet ← IC_IR 权重历史（仅 ICIR 路径）
│       ├── portfolio/
│       │   └── weights.parquet     ← 目标权重面板（调仓日 × 股票）
│       ├── backtest/
│       │   ├── nav.parquet         ← 日频 NAV 序列
│       │   └── performance.json    ← 六项绩效指标 + 三项 PASS/FAIL
│       ├── reports/
│       │   ├── self_check.md       ← 自检报告
│       │   ├── brinson_*.parquet   ← Brinson 归因结果
│       │   └── factor_attr_*.parquet
│       ├── MANIFEST.json           ← 所有 .parquet 文件的 SHA256
│       └── RUN_FINISHED.json       ← 完成标志（存在 = run 正常结束）
│           （或 RUN_FAILED.json ← 失败标志，含错误堆栈）
│
└── test/                           ← allow_test_set=True 的 run
    └── （结构相同，含 RUN_STARTED.json 防重入锁）
```

**不可变性保证**：`run_experiment.py` 启动时检查 `RUN_FINISHED.json` 是否已存在；若存在则拒绝覆盖（时间戳不同会自动生成新 run_id）。这保证历史 run 结果不会被静默改写。

## 七、关键设计决策

### 7.1 为何将 Stage 编排与业务逻辑分离

`src/pipeline/stages.py` 只做两件事：
1. 根据 `ExperimentSpec` 选择正确的实现（路径分发）
2. 把输入/输出路径对齐到 artifact 约定

**不**包含任何金融计算逻辑。这样做的好处：
- 底层模块（如 `combiner.py`）可以被独立测试，不依赖 Pipeline 层
- 修改某个算法只改 `src/signal/`，不改 `stages.py`
- 新增路径（如新的信号方法）只加分支，不改现有代码

### 7.2 为何用 Python 文件（而非 JSON/YAML）定义 ExperimentSpec

`configs/pipelines/` 里的每个 `.py` 文件通过 `importlib` 动态加载为 Python 对象。好处：
- IDE 可以检查类型（dataclass 的字段名和类型在加载时验证）
- 可以写注释说明实验目的
- `ExperimentSpec.__post_init__()` 在加载时立即执行校验逻辑（如测试集保护锁）

### 7.3 为何 TopN EW 路径不经过协方差估计

LedoitWolf 估计需要 24 个月 × 500 只股票的日频收益率矩阵（约 12000 × 500），计算开销较大。TopN EW 路径的设计目标是**隔离优化器影响**，用来诊断"QP 是在帮忙还是在拖后腿"。如果 TopN EW 的 IR 更高，说明 QP 在损耗信号（已在验证期实验中观测到这个现象）。

### 7.4 PIT 正确性在数据流中的保证位置

```
raw CSV（无保证）
    ↓ csv_to_parquet.py（计算 pit_date，按 f_ann_date 或 ann_date 赋值）
financial_pit.parquet（有 pit_date 列）
    ↓ loader._pit_snapshot()（双重过滤：pit_date ≤ T AND end_date < T）
因子层输入（PIT 安全）
```

**关键约束**：因子层函数接收到的数据已经是 PIT 安全的，不需要再次过滤。`pit_loader.py` 的 `_filter_visible()` 是这条保证的中央执行点。

## 八、数据约定

| 约定 | 细节 |
|---|---|
| 股票代码格式 | `ts_code`（如 `000001.SZ`），不使用 6 位裸代码 |
| 日期对象 | `pd.Timestamp`，不使用裸字符串 |
| 价格口径 | 全程**后复权**（`close_adj`、`open_adj`、`ret`） |
| 基准 | 中证500**全收益指数**（含分红再投资），非价格指数 |
| 市值字段 | 中性化用 `daily_basic.log_free_float_mv`（自由流通市值对数），不用总市值 |
| 行业分类 | 申万一级 SW2021（31 个行业），代码格式 `801xxx.SI` |
| 财务数据货币单位 | `financial_pit` 字段单位为**元**；`daily_basic.total_mv` 单位为**万元**（需 ×10000） |
| 空值处理 | 因子层输出 NaN，不填充；信号合成前才统一填充为 0（横截面均值） |
