# 为什么组合优化反而不如 TopN 等权：项目证据复核与专家诊断

> 诊断日期：2026-09-15  
> 诊断范围：仅使用训练/验证目录中的既有产物，重点观察 2021—2022 验证期  
> 未执行新策略回测，未读取测试期绩效，未修改优化、回测或交易逻辑

## 一、先给结论

目前最有证据支持的解释不是“求解器失败”，也不是“交易成本太高”，更不是“只要放宽 TE 就会变好”。

更准确的结论是：

> 当前 QP 把一个主要适合排序的横截面分数，当成了可以精确比较大小的预期收益。线性目标会偏爱分值最极端的股票，并把有限的主动风险预算集中到这些股票上；但验证期中，信号头部的收益关系并不单调，最极端的前 25 名反而表现较差。TopN 等权只使用排序、不使用分值间距，并通过等权分散个股误差，因此在这段验证期更稳健。

这个判断有四条直接证据：

1. Rolling-48 Ridge 的 QP 在验证期 24 个调仓月全部正常得到 L1 最优解，没有发生 fallback。
2. QP 的预测 alpha 暴露高于 TopN150，但实际超额收益和 IR 更低，说明问题不在于“alpha 用得不够”，而在于分值幅度没有可靠地转化为收益幅度。
3. QP 比 TopN75、TopN150 更集中，且实现 TE、超额回撤并未更优；优化器没有在该样本中兑现预期的风险收益交换。
4. 验证期的排序分桶显示，前 1—25 名的后续原始等权月收益均值约为 -0.09%，第 51—75 名约为 +1.87%。这不是严格的可交易收益比较，但清楚表明头部信号并非单调，极端分值不值得被机械重仓。

不过，现有历史实验还不能给出完全严格的因果结论。早期 QP 与后来强制 TopN 路径使用了不同版本的组合构造代码，TopN 参数也在同一验证期上被反复比较。因此，下面的数值适合用于定位问题，不应包装成已经完成的最终样本外证明。

---

## 二、“等权”到底指什么

项目里的“等权”不是把中证500全部成分股等权，而是：

1. 按合成信号从高到低选择 TopN；
2. 对选中的股票近似等权；
3. 后期版本还会处理停牌、涨跌停和单股偏离约束。

这里存在一个容易忽视的口径差异：

- 2026-05-27 QP run 内附带的旧 baseline 是朴素 Top50 等权，每期恰好 50 只；
- 2026-05-29 以后新增的强制 `topn_ew` 路径会为满足单股偏离上限自动提高有效持仓数；所谓 TopN50 实际平均持仓约 66 只；
- 因此，“QP 1.489 对 TopN50 1.771”不是旧 run 内完全一致的 V1/V2 对比，而是跨代码版本的历史比较。

在 2026-05-27 原始 run 内，QP 的 IR 为 1.489，反而高于当时朴素 Top50 baseline 的 0.924。这足以否定“优化器在任何同口径比较中都不如等权”的笼统说法。

正确说法应当是：

> 在后来新增的约束感知 TopN 构造和一系列 N 值实验中，TopN 组合的历史验证期表现高于早期 QP；但这既包含组合方法差异，也包含代码版本差异和验证集选择效应。

## 三、核心数值证据

以下组合均使用 Rolling-48 Ridge 信号历史产物进行诊断。QP 与后期 TopN 并非完整的同代码实验，因此表格用于机制判断，而非正式排名。

| 验证期指标 | QP | TopN75 | TopN150 | TopN250 |
|---|---:|---:|---:|---:|
| 年化超额收益 | 8.63% | 12.40% | 10.11% | 9.30% |
| 实现 TE | 5.80% | 5.51% | 4.44% | 4.01% |
| IR | 1.489 | 2.248 | 2.274 | 2.321 |
| 超额最大回撤 | 5.82% | 4.91% | 3.55% | 2.71% |
| 月胜率 | 56.52% | 65.22% | 78.26% | 78.26% |
| 平均持仓数 | 87.7 | 75.2 | 150.3 | 250.5 |
| 有效持仓数 | 58.7 | 75.2 | 149.8 | 248.5 |
| 最大单股权重 | 2.28% | 1.40% | 0.87% | 0.66% |
| Top10 权重 | 20.04% | 13.36% | 6.85% | 4.25% |
| 主动份额 | 85.97% | 83.27% | 68.88% | 52.12% |
| 原始 alpha 暴露 | 1.594 | 1.476 | 1.082 | 0.726 |
| 主动 alpha 暴露 | 1.568 | 1.450 | 1.056 | 0.700 |
| 年化单边换手 | 5.01 倍 | 4.70 倍 | 3.82 倍 | 2.84 倍 |
| 两年累计成本/调仓前组合价值 | 3.06% | 2.86% | 2.32% | 1.71% |

### 3.1 最重要的反常现象

QP 的原始 alpha 暴露比 TopN150 高约 47%，主动 alpha 暴露也高约 49%，但其年化超额收益低约 1.47 个百分点，IR 低约 0.785。

这意味着：

- 如果模型分值真能近似预期收益，QP 更高的 alpha 暴露理应带来更高的实现收益；
- 实际没有发生，说明分值的横截面顺序有一定信息，但分值的绝对大小或极端尾部并不可靠；
- QP 最大化的是“模型眼中的 alpha”，不是事后真实 alpha。优化器越精确地利用错误的幅度信息，组合反而可能越差。

这类现象在组合研究中常被称为估计误差放大：优化器不会自动知道预测哪里最不可靠，它只会忠实地放大输入中的微小差异和极端值。

### 3.2 QP 实际比 TopN150 更集中

不能仅看“持仓 88 只”就认为 QP 很分散。有效持仓数约为：

\[
N_{eff}=\frac{1}{\sum_i w_i^2}
\]

QP 虽平均持有约 88 只，但有效持仓只有约 59 只，Top10 合计约 20%。TopN150 的有效持仓接近 150 只，Top10 仅约 6.85%。

因此，QP 的真实经济特征是：持股数量不少，但风险预算和资本权重集中在少数高分股票；TopN150 则更接近真正的分散化。

### 3.3 信号头部不是单调的

用现有 `fwd_ret_panel.parquet` 对 2021—2022 的 23 个可对齐月份做描述性分桶，得到：

| 当期信号排名 | 下期原始等权收益均值 |
|---|---:|
| 1—25 | -0.09% |
| 26—50 | +0.73% |
| 51—75 | +1.87% |
| 76—100 | +0.70% |
| 101—150 | +0.82% |
| 151—250 | +0.75% |
| 251—500 | +0.32% |

同期平均 Rank IC 约为 0.034，说明总体排序仍有正信息；但头部 1—25 并不优于 26—75，信号在最极端区域明显不单调。

这恰好解释了为何 TopN75、TopN150 能优于 QP：

- TopN 只判断“是否进入较高排名区间”，不假设第 1 名一定远好于第 50 名；
- 等权限制了错误极端分值对组合的影响；
- 扩大到 75—150 只还能纳入验证期内表现较好的中高排名股票。

注意：该分桶使用原始未来收益，不含完整 T+1 成交、成本和基准扣除，只能作为信号形状证据，不能替代正式回测。

## 四、从优化目标看，为什么会出现这种结果

当前 L1 目标近似为：

\[
\max_w \quad \alpha^T w-\lambda_{TC}\lVert w-w_{prev}\rVert_1
\]

并施加全仓、纯多头、单股偏离、行业偏离、停牌/涨跌停和 TE 上限等约束。

### 4.1 它依赖 alpha 的“基数含义”，TopN 只依赖排序

TopN 等权只关心股票 A 的分数是否高于股票 B。只要顺序不变，对分数做任何单调变换，TopN 结果基本不变。

QP 不仅关心顺序，还关心分数差：`2.5` 与 `0.5` 的差距会被理解为比 `1.0` 与 `0.8` 更值得配置。若合成分数只是 z-score 或机器学习打分，而不是经过样本外校准的预期收益，这种解释就过强。

### 4.2 线性 alpha 目标会把解推向可行域边界

在没有平滑风险惩罚时，最大化线性 alpha 会倾向于：

- 给最高分股票尽可能高的权重；
- 给低分股票尽可能低的权重；
- 直到单股、行业或 TE 约束阻止其继续移动。

硬 TE 只规定“不能超过多少风险”，并不会奖励在上限以内进一步降低风险。因而该设计可能得到一个位于约束边界、对 alpha 估计误差敏感的组合。

TopN150 虽没有显式求解协方差优化，却通过简单等权获得了更低的实现 TE 和更小的超额回撤。这并不证明协方差模型无效，只说明当前“预测输入 + 目标函数 + 约束”的组合没有战胜朴素分散化。

### 4.3 “z-score 与 TE 单位不同”不是最准确的批评

旧报告说无量纲 z-score 与有收益单位的 TE 约束“量纲不匹配”。这个说法抓到了校准问题，但数学表述不严谨：

- 目标函数与约束并不要求具有相同单位；
- 若没有换手惩罚，把所有 alpha 乘以同一个正常数并不会改变最优权重；
- 但加入固定的换手惩罚后，alpha 的尺度会改变“追逐信号”和“保持持仓”的相对权衡；
- 更核心的问题不是量纲本身，而是横截面分值间距没有被证明能代表预期收益差距。

所以更专业的说法是：

> 当前 alpha 的排序有效性强于幅度校准能力，而优化器要求幅度具有经济含义，导致输入假设与配置方法不匹配。

### 5.1 判断表

| 旧结论 | 本次判断 | 理由 |
|---|---|---|
| 优化器显著降低 alpha 暴露，因此不如等权 | **只对旧 ICIR/2022 案例部分成立；不适用于当前 Rolling-48 对比** | Rolling-48 QP 的预测 alpha 暴露反而高于 TopN75/150，却没有转化成更高收益。 |
| TE 太宽或被其他约束架空，放宽约束会改善 IR | **证据不支持** | 固定其他参数的 TE 6%/7%/8% 实验中，IR 为 0.422/0.408/0.408；更宽 TE 没有改善。另一组同时改变多个约束的网格也出现约束越松、IR 越低。 |
| solver 或 fallback 导致表现差 | **对相关 QP run 不成立** | Rolling-48 QP 验证期 24/24 均为 L1 `optimal`，约束合规。 |
| 没有换手惩罚是主因 | **已经过时** | 后续代码和相关 run 已使用 `turnover_lambda=0.005`。 |
| 换手和成本是 QP 落后的主因 | **次要，不是主因** | QP 成本确实更高，但与 TopN75 的两年累计成本差约 0.20 个百分点，远小于组合收益差异；与 TopN150 的累计成本差约 0.74 个百分点，也不足以解释全部差距。 |
| alpha 没有收益尺度校准 | **方向正确，但应改写** | 真问题是分值间距和尾部没有可靠的收益含义，不是简单的“目标与约束单位必须一致”。 |
| 对 alpha 做 rank transform 就能修复 | **未被验证，已有一次反例** | 在另一条 ICIR 信号上，rank-QP IR 约 0.299，低于原 QP 约 0.402。该实验不能直接外推到 Rolling-48，但至少不能说 rank 变换必然有效。 |
| NaN 填 0 会自动占用大量权重、稀释有效 alpha | **逻辑和实证都不足** | alpha=0 表示目标函数对该股票中性，并不自动强迫配置。Top50 预筛后 `zero_alpha` 的 QP IR 从 1.489 降至 1.231；锁定非 Top50 到基准的方案 IR 仅 0.137，且 15/24 期 fallback。 |
| LedoitWolf 是主要问题 | **尚无证据** | 没有同信号、同约束、只替换风险模型的干净消融。现阶段最多能说风险模型未带来优于简单分散化的结果，不能据此归因于 LedoitWolf。 |
| `w_prev` 使用目标权重而非实际持仓存在问题 | **成立，是 P0 工程风险** | 它会影响换手惩罚和涨跌停/停牌状态约束，但现有实验没有量化它对 QP 与 TopN 相对表现的影响。 |

### 5.2 对早期“约束压制 alpha”结论的修正

早期针对另一条 ICIR 信号和 2022 年的诊断发现，QP 保留约 79% 的 alpha 暴露，同时降低 TE 和回撤。这个结论在那个限定案例里是合理的：优化器用部分 alpha 换取风险控制。

但 Rolling-48 的新证据不同：QP 的 alpha 暴露高于 TopN，风险却也更高。因此不能继续把“约束稀释”当成统一解释。更一般的结论应是：

> 优化器输出取决于信号分布、风险模型和约束几何。旧 ICIR 案例体现了约束压低主动暴露；Rolling-48 案例更像是优化器过度相信高分尾部，并形成隐性集中。

## 六、哪些因素不是当前主因

### 6.1 不是 fallback

相关 QP 在验证期全部 L1 正常求解。fallback 机制仍需保留，但不能用它解释这次差距。

### 6.2 不是单纯的 TE 太紧

放宽 TE 的历史消融没有改善 IR。并且 Rolling-48 QP 的实现 TE 为 5.80%，高于 TopN150 的 4.44%；如果 TE 太紧是核心矛盾，通常不会观察到简单组合同时取得更低风险和更高 IR。

### 6.3 不是单纯的成本侵蚀

成本会降低所有策略的净收益，QP 的换手和成本也略高，但数量级不足以解释大部分差距。成本应列为二级贡献项，而不是根因。

### 6.4 暂时不能怪协方差模型

当前没有风险模型消融，也没有完成 ex-ante TE 与 realized TE 的逐期校准检查。直接从“QP 不如等权”跳到“LedoitWolf 不行”属于证据越级。

## 七、为什么当前结论仍然需要保留审计意见

### 7.1 历史 run 不是严格的同版本实验

早期 QP run 内的 baseline 是朴素 Top50；后来的强制 TopN 路径复用了新的状态约束逻辑，且 TopN50 实际约为 66 只。早期 `inputs.lock.json` 只记录时间，没有完整输入 hash 与代码 commit，无法百分之百重建当时环境。

所以现有结果能够说明“哪种机制可疑”，不能精确声称“优化器本身造成了多少百分点损失”。

### 7.2 TopN 的 N 值存在验证集选择偏差

同一验证期至少比较了 25、50、75、100、150、200、250、300 等多个 N。结果并不单调：TopN250 的 IR 约 2.321，甚至高于当前常用的 TopN150 约 2.274。

这不代表应该改用 250。相反，它说明 24 个月验证样本较短，最优 N 很容易受偶然路径影响。若根据同一验证期不断挑最高 IR，会产生 winner's curse。

### 7.3 项目主审计尚未为这些绩效背书

`docs/当前文档/01_项目治理/学习与审计主线.md` 当前仍将数据转换、PIT/成分股/状态、因子预处理阶段标为 FAIL，优化、回测和归因阶段尚未正式审计；其中 C-004 明确记录了 `w_prev` 使用目标权重近似实际持仓的问题。

因此本报告对历史产物采取“诊断可用、最终业绩不可认证”的口径。

## 八、下一步怎样做出真正干净的结论

下面是建议的实验顺序。它们都应只在训练/验证期完成，研究冻结前不要读取测试期。

### 第一步：先建立完全可比的基线

固定以下所有内容：

- 同一份 Rolling-48 信号文件及 hash；
- 同一份成分股、状态、行业和协方差输入；
- 同一代码 commit；
- 同一 T+1 成交和成本引擎；
- 同一实际持仓反馈规则；
- 同一验证期指标计算。

只改变“权重如何从信号生成”。至少保留：

1. TopN 等权；
2. 当前 raw-score QP；
3. 排名分数 QP；
4. 将 TopN 目标投影到风险约束可行域的组合。

其中第 4 个非常重要。它不是重新最大化未经校准的 alpha，而是先得到稳健的 TopN 目标，再求一个满足 TE、行业、单股和交易状态约束、同时尽量接近该目标的组合。这样可以把“信号配置”与“风险合规”拆开。

### 第二步：检验头部信号是否稳定单调

在训练期滚动计算：

- 1—25、26—50、51—75、76—100、101—150 等排名段收益；
- 各排名段的均值、t 值、胜率和不同年份稳定性；
- 极端分值与下一期收益的局部关系；
- 去掉头部 1%、截尾、rank-normalize 后的变化。

如果训练期也反复出现“第 1—25 名不如 26—75 名”，就说明应主动收缩头部幅度，而不是继续让 QP追逐极值。

### 第三步：只用训练期校准 alpha 幅度

可采用简单、可解释、低自由度的方法：

- 用滚动训练期估计 `future_excess_return ~ score` 的斜率；
- 对预测收益做截尾和 shrinkage，防止极端值；
- 或按训练期排名分桶估计单调收益映射；
- 若分桶不单调，不要强行保留精细幅度，退回 rank/TopN 更诚实。

这里的目标不是让训练拟合更高，而是让“分值差多少”具有可验证的收益含义。

### 第四步：单独审计风险模型

逐月比较：

- ex-ante TE 与后续 realized TE；
- 预测/实现比值的均值、分位数和稳定性；
- TE 约束是否 binding；
- 边际风险贡献是否集中；
- LedoitWolf 窗口变化是否只改变预测风险，还是确实改善实现风险。

只有完成这个消融，才能判断问题是否来自协方差估计。

### 第五步：做相对收益的配对显著性检验

验证期只有约 24 个月，单看 IR 排名非常不稳。应对 `TopN - QP` 的月度收益差做：

- 均值及 Newey-West t 统计；
- 分年度和滚动窗口稳定性；
- block bootstrap 置信区间；
- 对多个 N 和多个优化版本的试验数量做完整披露。

如果差异没有统计稳定性，最专业的结论不是“TopN 一定更好”，而是“复杂优化尚未证明有增量，因此暂用简单基线”。

## 九、我建议的项目决策

在完成干净消融前，建议维持以下定位：

1. TopN 等权作为当前研究主线或强基线，因为它更稳健、可解释，且历史验证期表现较好；
2. QP 保留为候选风险覆盖层，不应删除，因为它能表达 TE、行业、单股和交易状态约束；
3. 不再以“直接最大化 raw z-score”作为唯一优化方向；优先测试 alpha 幅度收缩或 TopN 目标投影；
4. 不依据 TopN250 的最高验证 IR 改参数，N 必须通过训练期稳定性和经济约束确定；
5. 先修复或明确 `w_prev=actual holdings` 的闭环，再做最终组合比较；
6. 在数据、PIT、预处理和回测审计通过前，不把 1.489、2.274 等数字写成已认证业绩。

一句话概括：

> 这不是“优化理论不如等权”，而是当前预测分数更适合做稳健排序，不足以支持精细的基数型权重优化；复杂优化放大了头部估计误差，而 TopN 等权通过舍弃幅度信息和增加分散度，获得了更好的验证期结果。

## 十、面试中可以怎样回答

如果面试官问“为什么优化器反而不如等权”，可以这样回答：

> 我最初怀疑过 TE 过紧、fallback 和交易成本，但消融后发现这些都不是主因。相关 QP 在验证期 24 期全部正常求解，放宽 TE 也没有提升 IR，成本差异只能解释小部分。进一步看组合结构，QP 的预测 alpha 暴露比 TopN150 高约 47%，有效持仓却只有约 59 只，说明它在更集中地使用高分尾部；但验证期信号前 1—25 名的后续收益并不比 26—75 名好，分值幅度没有稳定的收益含义。TopN 等权只利用排名，并通过等权降低个股预测误差，所以反而更稳健。我因此没有简单否定优化器，而是把问题定位为 alpha 校准与目标函数不匹配，并计划用同代码、同信号的消融比较 raw-score QP、rank-QP 和 TopN 目标投影，同时修复实际持仓反馈，避免把历史版本差异误判为优化器效果。

这个回答的优点是：既能说明数学机制，也能说明你如何排除错误假设，并主动承认现有实验的证据边界。
