# 中证500指数增强：最终业绩诊断与改进实施方案

> 版本：v1.0  
> 日期：2026-09-17  
> 状态：方案已制定，尚未实施  
> 适用范围：训练集 2012—2020、验证集 2021—2022  
> 测试集纪律：2023—2025 只保留为最终评价；本方案不得使用测试集选择因子、模型或参数，也不授权新增测试集运行。

## 1. 结论与推荐方向

当前策略的主要问题不是“合成信号完全失效”，而是最终超额收益中混入了较强的等权／偏小市值风格贡献，且信号到实际持仓之间还存在目标语义、持仓反馈、交易成本和不可交易状态处理方面的缺口。

最终推荐的研究主线是：

```text
严格 PIT 因子
  → 明确的未来超额收益标签合同
  → 以排序稳定性为主的合成信号
  → TopN 或“基准 + 主动袖套”目标组合
  → 风险约束投影优化
  → T+1 实际成交与现金记账
  → 实际持仓反馈到下一期优化
  → 毛收益、成本、实施偏差和风格贡献归因
```

这一方向不承诺提高历史 IR。它首先解决结论可信度和样本外稳定性，然后才判断是否存在真正的净业绩增量。

## 2. 当前业绩事实与诊断边界

### 2.1 正式测试结果

当前唯一有效的正式测试集运行覆盖 2023—2025，实际组合模式为 Rolling-48 Ridge + TopN150 近似等权，而不是 QP 优化器。

| 指标 | 测试集结果 |
|---|---:|
| 策略年化收益 | 13.26% |
| 中证500全收益基准年化收益 | 10.15% |
| 年化超额收益 | 3.11% |
| 信息比率 | 0.645 |
| 实现跟踪误差 | 4.83% |
| 超额最大回撤 | -5.70% |
| 月度胜率 | 60.0% |
| 年化双边换手 | 约 7.28 倍 |

以上结果满足项目的三个完成门槛，但年度超额从 2023 年的 4.43% 下降至 2025 年的 0.38%，说明收益稳定性仍然不足。

### 2.2 当前最有证据支持的解释

使用现有产物进行的只读分解表明：

| 代理收益来源 | 验证集 | 测试集 |
|---|---:|---:|
| TopN 选股相对成分股等权 | +2.53% | +3.42% |
| 成分股等权相对市值加权基准 | +5.81% | +0.20% |
| 合计代理超额 | +8.34% | +3.52% |

该分解支持以下判断：

1. 测试期合成信号的整体排序能力没有证据显示显著恶化；
2. 验证期的大部分高超额来自等权／偏小市值风格顺风；
3. 测试期这一风格收益接近消失，是业绩下降的主要解释；
4. 测试期还存在交易成本、T+1 成交、不可交易状态和目标／实际持仓偏离造成的实施损耗；
5. 上述分解是诊断证据，不是严格的因果证明，实施影响仍需在训练／验证范围内重建。

### 2.3 已确认问题与待验证问题

| 类别 | 问题 | 当前状态 |
|---|---|---|
| 标签 | Spec 声明 `target="excess_return"`，Ridge stage 未显式启用超额收益标签 | 已定位，未修复 |
| 持仓反馈 | 优化器使用上期目标权重近似实际持仓 | 已定位，未修复 |
| 信号门禁 | TopN 未严格排除 NaN；全 NaN 时仍可能形成“合规”持仓 | 已通过最小案例复现，未修复 |
| 交易记账 | 扣费后的统一份额缩放可能改变锁定证券份额 | 已通过最小案例复现，未修复 |
| 优化目标 | raw z-score 被当作具有收益幅度含义的 alpha | 机制诊断成立，改进效果待实验 |
| 风格来源 | TopN 等权存在隐含规模风格暴露 | 有收益分解支持，完整风格归因待补 |
| 风险模型 | ex-ante TE 与 realized TE 尚未系统校准 | 待验证 |
| 成本来源 | 测试期实施损耗可能主要由成本贡献 | 合理假设，尚未逐月精确桥接 |

## 3. 改进原则

1. **先修正确性，再比较收益。** 标签、持仓和交易记账未闭环前，不用 IR 判断模型优劣。
2. **先使用简单强基线，再证明复杂模型有增量。** TopN 是基线，QP 是候选风险覆盖层。
3. **只在训练期选择。** 因子、窗口、TopN 数量、主动比例和优化参数都只能在训练期内部确定。
4. **验证期只确认一次。** 冻结方案后才进入 2021—2022 验证，不根据验证结果循环试错。
5. **测试集只用于最终评价和缺陷排查。** 不根据 2023—2025 表现修改因子和参数。
6. **每次实验只改变一个主要机制。** 避免同时改标签、因子、模型和优化器后无法归因。
7. **净收益优先。** 所有模型比较必须同时报告毛收益、费用、换手和实施偏差。

## 4. 阶段一：修复标签合同与信号训练语义

### 4.1 目标

确保配置中的 `target` 真正决定 Ridge 使用的标签，并且标签能够被唯一识别、复算和冻结。

### 4.2 修改内容

1. 在信号合同中明确允许的标签类型：
   - `raw_return`：个股 T+1 开盘至下一调仓期 T+1 开盘收益；
   - `benchmark_excess_return`：个股收益减同期中证500全收益；
   - `cross_section_demeaned_return`：当期个股收益减当期可投资域横截面均值，仅作为训练期研究对照。
2. `run_signal_stage` 必须根据 `SignalSpec.target` 显式构造标签或传递 `use_excess_return` 与基准收益；未知目标立即失败。
3. 标签元数据必须记录：价格口径、起止时点、基准、生成版本、投资域、文件哈希。
4. 原始收益和超额收益不得共享没有版本标识的缓存文件。
5. run manifest 冻结标签合同和标签文件哈希。

### 4.3 预计涉及文件

- `src/pipeline/contracts.py`
- `src/pipeline/stages.py`
- `src/signal/ridge_combiner.py`
- `src/signal/ridge_rolling.py`
- `src/signal/ridge_decay.py`
- 标签生成模块及 run manifest 写入逻辑
- `tests/test_signal_combiner.py`
- `tests/test_pipeline_contracts.py`

### 4.4 必须增加的测试

- 非零基准收益样本下，切换 `target` 必须改变标签数值；
- `benchmark_excess_return = raw_return - benchmark_return` 逐期成立；
- 标签起止时点严格符合 T 日信号、T+1 开盘成交合同；
- 未知 `target` 立即抛错，不允许静默回退；
- 不同标签合同生成不同缓存身份或内容哈希；
- Ridge 的 CV、最终拟合和预测使用同一种标签合同。

### 4.5 验收标准

- 配置、实际调用、缓存内容和 metadata 四者一致；
- 任意 run 都能回答“使用了什么标签、怎样生成、文件哈希是什么”；
- 尚不以 IR 是否提高作为本阶段通过条件。

## 5. 阶段二：建立目标—成交—实际持仓闭环

### 5.1 目标

让换手惩罚、停牌和涨跌停约束作用于真实账户状态，而不是上一期目标权重。

### 5.2 正确状态链

```text
T 日目标权重
  → T+1 开盘订单
  → 状态限制后的实际成交
  → 佣金、滑点、印花税和现金变化
  → 实际证券份额
  → 价格变化后的调仓日前漂移权重
  → 下一期优化器 w_prev_actual
```

### 5.3 修改内容

1. 回测引擎显式保存证券份额、现金、实际成交和未成交原因。
2. 锁定证券份额不得因其他证券的交易费用发生变化。
3. 现金不足时只缩减允许成交的买单，不修改锁定证券或已完成卖出的份额。
4. 优化器接口接收 `w_prev_actual`，并记录其来源。
5. 如果优化和回测暂时不能在一个逐期循环中闭环，应先实现统一的 portfolio-execution state runner，不使用事后覆盖权重的方式模拟闭环。

### 5.4 预计涉及文件

- `src/backtest/engine.py`
- `src/backtest/transaction.py`
- `src/portfolio/optimizer.py`
- `src/pipeline/stages.py`
- `scripts/run_experiment.py`
- `tests/test_backtest_engine.py`
- `tests/test_transaction.py`
- `tests/test_optimizer.py`

### 5.5 必须增加的测试

- 锁定股票 + 其他股票交易付费时，锁定份额严格不变；
- 现金充足／不足、同时买卖、全部锁定、零费用等账户不变量；
- 涨停不得增加实际份额，跌停不得减少实际份额；
- 下一期 `w_prev_actual` 与上期执行后持仓及价格漂移一致；
- 2023-08-28 前后印花税切换正确；
- 目标权重、订单、成交、实际持仓和现金可以逐期对账。

### 5.6 验收标准

- 证券份额、现金、费用和净资产分别守恒；
- optimizer metadata 中 `w_prev_source="actual_holding"`；
- 不可交易约束以实际份额为基础生效；
- 修复前后影响只在训练／验证范围内评估。

## 6. 阶段三：修复信号有效性门禁

### 6.1 修改内容

1. TopN 排序前严格过滤非有限值，NaN 不得凭列顺序进入组合。
2. 区分以下状态：
   - 有效股票数不少于 N；
   - 有效股票数少于 N；
   - 全部信号缺失；
   - 当期投资域为空。
3. 有效股票数不足时不得悄悄补入缺失股票。
4. 全缺失时返回明确故障状态，由上层执行经批准的退化规则。

### 6.2 需要用户确认的业务规则

全缺失或有效数量不足时，需要在以下行为中选择一种并写入配置：

- 保持实际持仓并停止新增交易；
- 回到基准目标；
- 降低实际持股数量；
- 使用明确配置的基准补位。

在规则获批前，不由底层排序函数自行决定。

### 6.3 验收标准

- 全 NaN 不再返回普通“合规”组合；
- 每期记录有效信号数、实际持股数和退化原因；
- 历史训练／验证期统计退化触发次数。

## 7. 阶段四：重新设计组合构建

本阶段只在前三个正确性阶段通过后开始。

### 7.1 保留 TopN150 作为强基线

TopN 等权继续作为可解释基线，但不直接认定为最终最优方案。TopN 数量不得根据已查看的验证集和测试集最高 IR 重新选择。

### 7.2 候选一：TopN 内按基准权重分配

对进入 TopN 的股票按基准权重重新归一化：

$$
w_i^{target}=
\frac{w_{b,i}}{\sum_{j\in TopN}w_{b,j}}
$$

目的：保留选股，同时降低纯等权带来的规模风格暴露。

### 7.3 候选二：基准 + 主动袖套

$$
w^{target}=(1-\rho)w_b+\rho w_{TopN}
$$

其中 $\rho$ 表示主动风险预算。其候选范围和最终数值需要在训练期预注册，当前不指定经验默认值。

### 7.4 候选三：TopN 目标投影优化器（优先推荐）

先由稳健排序形成目标组合，再求最接近该目标的可执行组合：

$$
\min_w
\frac{1}{2}\lVert w-w^{target}\rVert_2^2
+\lambda_{TC}\lVert w-w_{prev}^{actual}\rVert_1
$$

约束包括：

- 权重和为 1、纯多头；
- 年化 TE 上限；
- 行业主动偏离；
- 单股主动偏离；
- 经批准的规模／风格暴露约束；
- 停牌、涨停、跌停和一字板状态约束。

该方法把“选什么”与“怎样满足风险和交易约束”分离，避免优化器直接放大未经校准的极端分数。

### 7.5 候选四：校准预期收益后的主动 QP

只有在训练期证明信号分值具有稳定的收益幅度含义后，才使用：

$$
\max_w
\hat\mu^\top(w-w_b)
-\frac{\gamma}{2}(w-w_b)^\top\Sigma(w-w_b)
-\lambda_{TC}\lVert w-w_{prev}^{actual}\rVert_1
$$

$\hat\mu$ 不得直接等于 raw z-score。训练期校准可比较：

- rank-normalize；
- 分桶平均未来超额收益；
- 单调映射；
- 线性斜率加尾部收缩。

如果头部收益不单调或校准不稳定，应退回 rank／TopN 目标投影，不强行保留基数型 alpha。

## 8. 阶段五：控制隐含风格和集中度

### 8.1 必须新增的诊断

每个调仓期至少输出：

- `log(free_float_mcap)` 主动暴露；
- 行业主动暴露；
- 基准前十大成分股低配程度；
- Top10 组合权重；
- 有效持股数 $1/\sum_i w_i^2$；
- 组合与基准的 size beta；
- 等权风格贡献；
- ex-ante TE 与 realized TE。

### 8.2 风控阈值

行业偏离、单股偏离、规模暴露和 TE 的具体阈值属于风险偏好决策，按项目规范需由用户确认。本方案不预设未经验证的经验数值。

### 8.3 风险模型审计

继续保留 LedoitWolf 作为默认协方差估计，但必须验证：

- 历史收益窗口严格小于 T；
- 股票顺序与协方差矩阵严格对齐；
- 每期正定性及对角修复记录；
- 预测 TE／实现 TE 比值的均值、中位数和分布；
- TE 约束是否长期 binding；
- 风险贡献是否集中在少数股票或行业。

在这些检查完成前，不以更换商业求解器或引入完整 BARRA 模型作为主要改进方向。

## 9. 阶段六：降低交易实施损耗

### 9.1 成本桥接归因

每期输出以下桥接：

```text
目标组合理论毛超额
  - 信号日至 T+1 开盘价格变化
  - 不可交易／部分成交偏差
  - 佣金
  - 滑点
  - 印花税
  - 现金拖累
  = 实际组合净超额
```

### 9.2 候选改进

- 基于实际持仓的换手惩罚；
- 进入阈值与退出阈值不同的持仓滞后带；
- 仅在预计边际收益覆盖预计交易成本时换仓；
- 低置信度信号使用较小主动预算；
- 记录因涨跌停、停牌和现金不足产生的未完成交易。

具体阈值不得直接使用未经验证的经验值，应在训练期预注册有限候选，并使用净收益而不是毛收益选择。

## 10. 受控实验矩阵

所有实验必须使用相同的数据快照、因子文件、标签合同、代码 commit、成交规则和指标口径。

| 实验 | 唯一主要变化 | 回答的问题 |
|---|---|---|
| E0 | 修复正确性后的 TopN150 等权 | 建立新的可信基线 |
| E1 | 原始收益 vs 基准超额 vs 横截面去均值标签 | 标签语义对信号和净组合的影响 |
| E2 | TopN 等权 vs TopN 基准权重 | 等权风格暴露的影响 |
| E3 | 基准 + 主动袖套 | 是否提高跨阶段稳定性 |
| E4 | TopN 目标投影 | 风险覆盖层是否产生增量 |
| E5 | raw-score QP vs rank-QP vs 校准 QP | alpha 幅度校准是否有效 |
| E6 | 目标权重反馈 vs 实际持仓反馈 | 持仓闭环对换手和约束的影响 |
| E7 | 无成本控制 vs 成本感知调仓 | 净收益是否得到改善 |

禁止将全部实验一次性组合运行后选择最高 IR。每一阶段应先确定研究问题和停止条件，再执行有限对照。

## 11. 时间验证与模型选择规则

### 11.1 训练期内部验证

在 2012—2020 内进行扩展窗或滚动窗 walk-forward：

- 所有训练样本严格早于预测月；
- purge 窗口严格执行；
- 因子选择、alpha、TopN／主动比例和优化参数仅用当时以前的数据；
- 保存每个 fold 的候选、选择理由、系数和指标。

### 11.2 验证期使用

只有训练期决策冻结后，才在 2021—2022 做一次确认。若验证失败，应记录失败并回到研究阶段，但不得通过反复查看验证结果形成大规模网格搜索。

### 11.3 选择指标

不得只按最高 IR 选择。至少联合评价：

- 年化净超额收益；
- IR 与其不确定性；
- realized TE；
- 超额最大回撤；
- 月度胜率；
- 年化双边换手；
- 成本前后收益差；
- 不同训练子区间稳定性；
- 行业和规模主动暴露；
- 有效持股数和集中度；
- fallback／退化触发频率；
- 收益是否由少数月份主导。

比较 TopN 与优化版本时，对月度主动收益差报告：

- 均值与中位数；
- Newey-West/HAC t 统计量；
- block bootstrap 置信区间；
- 牛市、熊市和震荡期的方向稳定性；
- 多候选比较带来的选择偏差。

如果复杂方法没有稳定增量，应保留简单基线，而不是继续扩大参数搜索。

## 12. 发布门禁

### 12.1 正确性门禁

- [ ] 后复权价格和收益口径一致；
- [ ] 中证500全收益指数作为唯一绩效基准；
- [ ] 财务数据满足 `Annodt <= T`；
- [ ] 成分股按生效日对齐；
- [ ] 标签合同与 T+1 成交时间轴一致；
- [ ] 横截面预处理只使用 T 日截面；
- [ ] 实际持仓反馈进入下一期优化；
- [ ] 印花税日期切换正确；
- [ ] 停牌和涨跌停约束作用于实际份额；
- [ ] 全 NaN 和有效股票不足有明确退化状态；
- [ ] manifest 冻结关键输入哈希和行为参数。

### 12.2 业绩门禁

- [ ] IR 达到项目完成线，但同时报告统计不确定性；
- [ ] 超额最大回撤不超过项目上限；
- [ ] 年化双边换手处于目标范围；
- [ ] realized TE 处于批准范围；
- [ ] 收益不依赖单一风格、单一行业或少数月份；
- [ ] 毛收益、费用和实施偏差可以完整对账；
- [ ] 复杂方案相对简单基线的增量具有跨时期稳定性。

### 12.3 测试集门禁

在 `docs/当前文档/01_项目治理/学习与审计主线.md` 阶段 0—9 全部通过前：

- 不运行新的正式测试集；
- 不读取测试期数据选择参数；
- 不根据现有测试结果删因子或新增“牛市因子”；
- 不将测试期诊断包装为独立样本外调参依据。

## 13. 推荐实施顺序

### P0：必须先完成

1. 修复并测试标签合同；
2. 修复全 NaN 信号门禁；
3. 修复锁定份额与费用记账；
4. 建立实际持仓反馈闭环；
5. 冻结完整输入和行为 manifest。

### P1：形成新的可信主线

6. 在训练期重建 TopN150 基线；
7. 完成等权风格、行业、规模和实施损耗归因；
8. 比较 TopN 等权、TopN 基准权重和基准 + 主动袖套；
9. 实现 TopN 目标投影优化器；
10. 校准 ex-ante TE 与 realized TE。

### P2：只有在 P0/P1 完成后考虑

11. 训练期校准 alpha 幅度；
12. 比较 rank-QP 与校准 QP；
13. 实施成本感知调仓和持仓滞后带；
14. 在现有因子体系仍不足时，再研究低相关的新因子维度；
15. 只有简单模型已形成可信基线后，再判断机器学习模型是否有必要。

## 14. 本方案暂不建议的做法

- 不根据 2025 年表现直接增加价格动量或“牛市因子”；
- 不根据测试期 IC 删除 `hk_hold`、`amihud` 等因子；
- 不把 TopN250 的历史验证期最高 IR 当作新的 N；
- 不通过无限扩大 TE、行业偏离和单股偏离网格追求更高 IR；
- 不先引入 XGBoost、LightGBM、神经网络或 Black-Litterman；
- 不删除 LedoitWolf 并退回高维样本协方差；
- 不把 solver 更换当作主要业绩改进；
- 不把任何尚未实施的修复写成已经提高了收益。

## 15. 预期交付物

每个阶段完成后应留下：

1. 失败测试和修复后的单元测试；
2. 修改前后行为对照；
3. 训练期受控实验配置；
4. 输入与输出哈希 manifest；
5. 目标权重、订单、成交、实际持仓和现金对账表；
6. 信号、风格、风险、成本和净收益归因；
7. 实验选择日志及未采用方案的原因；
8. 按 `.claude/templates/self_check.md` 生成的自检记录；
9. 对 `docs/当前文档/01_项目治理/学习与审计主线.md` 对应阶段状态的更新。

## 16. 最终决策标准

项目最终不应以“历史 IR 最高”作为唯一成功标准，而应回答以下问题：

1. 当时使用的信息是否真实可见？
2. 模型训练目标是否与配置和研究目的相同？
3. 信号是否在不同训练阶段保持方向和局部单调性？
4. 主动收益来自选股，还是来自未声明的规模和行业暴露？
5. 优化器是否改善了净风险收益，而不只是提高预测分数暴露？
6. 目标组合是否能够在真实状态和成本下执行？
7. 实际持仓是否正确反馈到下一期决策？
8. 复杂方法的增量是否足以补偿额外自由度和过拟合风险？

如果复杂优化没有稳定增量，最终采用 TopN 或“基准 + 主动袖套 + 风险投影”并不是失败，而是基于证据选择更稳健、可解释和可复现的方案。
