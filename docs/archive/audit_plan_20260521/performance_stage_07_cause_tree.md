# 阶段 7：原因树汇总

生成日期：2026-05-21

本阶段汇总阶段 0-6 的审查结论，只使用训练/验证公共产物，样本截止 2022-12-31；未运行正式测试集 Run #2，未使用 2023-2025 结果。

## 总体判断

当前 V2 未达标的主线不是安全性、交易成本、fallback 或行业配置，而是：

`入模因子在 2022 分化/失效` -> `IC_IR 加权没有优于等权并放大衰减因子` -> `合成信号验证期几乎失效` -> `优化层进一步压低 alpha 暴露` -> `最终体现为行业内选股失败`

这条链路的证据比“成本太高”“约束成交失败”“fallback 拖累”更强。下一步应围绕信号合成、因子稳定性和优化后 alpha exposure 设计实验，而不是调低成本假设或直接碰正式测试集。

## 证据链

### 1. 因子层

6 个入模因子在训练期有统计证据，但 2022 验证期分化明显：

- 稳定正贡献：`amihud`、`mom_12_1`、`cfp`。
- 明显衰减：`rev_yoy`。
- 方向翻转：`ep_ttm`、`gross_margin`。

最终因子相关性不高，因此“因子高度冗余导致合成失败”证据不足。更合理的解释是训练期整体 IC 选择没有充分惩罚训练内后半段变弱和验证期风格切换风险。

### 2. 信号层

IC_IR 加权是明确拖累点：

- 等权合成训练期 IC_IR 0.796，2022 验证期 0.146。
- IC_IR 加权训练期 IC_IR 0.712，2022 验证期 0.046。
- 2022 平均约 46.3% 的绝对权重落在衰减/翻转因子组上。
- 2022-05 `ep_ttm` 权重约 30.8%，自身 IC 为 -0.269，对当月合成 IC 形成明显拖累。

这说明当前 IC_IR 加权没有带来训练内或验证期增益，反而可能把滚动历史噪声转化成过高权重。

### 3. 组合层

V2 优化有效降低风险，但以 alpha 暴露为代价：

- 事后 TE 从 V1 的 7.32% 降到 V2 的 4.50%。
- 超额最大回撤从 V1 的 11.40% 降到 V2 的 7.32%。
- V2 raw alpha 暴露比 V1 低约 21.2%。
- V2 active alpha 暴露比 V1 低约 21.4%。
- V2 实质持仓约 116-117 只，V1 为 50 只。

因此 V2 不是“优化无效”，而是“风控有效但收益端被压低”。在信号本身已经弱的情况下，这种压低会放大收益失败。

### 4. 回测成本层

成本不是相对失败主因：

- V2 年化双边换手 863.2%，低于 V1 的 898.9%。
- V2 成本 1.089%，低于 V1 的 1.159%。
- V2 相对 V1 少赚约 2.1 个 NAV 点，而成本差异方向相反。
- V2 相对 V1 最差的 2022-03 持仓期没有成交约束触发，成本只有 8.72 bps。

成本会影响绝对收益，但当前最不该做的是通过调低成本参数让结果变好看。

### 5. 归因层

Brinson 是原因树的结果层验证：

- 行业配置 +2.66%，不是问题主线。
- 行业内选股 -3.48%，是总超额为负的直接表现。
- 最大负贡献月份 2022-06 的选股效应为 -3.67%，几乎解释全部负超额。

因子归因提示价值、成长、流动性、质量为负，但 R2 只有约 0.048，因此只能作为线索，不能作为强因果结论。

## 排除项

以下解释当前证据不支持，后续不应优先投入：

| 假设 | 是否支持 | 原因 |
|---|---|---|
| V2 因为交易成本过高而弱于 V1 | 不支持 | V2 换手和成本均低于 V1 |
| V2 因为 L3 fallback 而失败 | 不支持 | 2022 全部 L1 optimal |
| V2 因为协方差缺失而失败 | 不支持 | 2022 `cov_available=True` |
| V2 因为行业配置错误而失败 | 不支持 | Brinson 配置效应为正 |
| 直接把 2022 表现好的未入模因子加回 | 不允许 | 会使用验证期挑因子，违反样本外纪律 |
| 直接运行 Run #2 看测试期是否好转 | 不允许 | 当前仍未完成原因闭环，Run #2 是最后一次正式测试机会 |

## 对阶段 8 的输入

原因树导向的实验顺序应是：

1. 等权合成 vs 当前 IC_IR 合成。通过标准：训练期滚动不劣化，2022 只做一次复核；不能用 2022 反复挑参数。
2. IC_IR 权重收缩到等权，例如 `0.5 * equal + 0.5 * ic_ir`，先作为诊断对照，不直接采纳。
3. 因子稳定性惩罚，只使用训练期内部切分，例如 2016-2018 与 2019-2021 的一致性。
4. TopN 50 / TopN 100 / 优化组合对比，记录 active alpha、TE、超额回撤、换手和 Brinson 选股效应。
5. 优化组合增加 alpha exposure 诊断门禁，而不是马上新增复杂约束。
6. TE 目标敏感性只在训练期内部做，不用 2022 挑 TE。

## 发布前口径

当前不建议进入正式测试集 Run #2。原因不是工程链路没跑通，而是验证期原因还没有通过非测试集实验闭环。若现在运行 Run #2，即使测试集结果好，也难以判断是策略有效、偶然风格适配，还是测试期污染/过拟合残留。

Run #2 前至少应完成：

1. 阶段 8 的等权与 IC_IR 对照实验。
2. 因子稳定性筛选或降权实验。
3. TopN 与优化组合 alpha exposure 对照。
4. attribution metadata 的 `NaN` 与疑似空 hash 修复。
5. 最终实验规则冻结并记录，不再用 2022 反复调参。
