# 阶段 6：归因诊断

生成日期：2026-05-21

本阶段只审查训练/验证公共产物，样本截止 2022-12-31；未运行正式测试集 Run #2，未使用 2023-2025 结果。

## 结论

Brinson 归因给出的解释较清楚：V2 在 2022 年不是输在行业配置，而是输在行业内选股。全年 Brinson 总超额为 -0.83%，其中行业配置 +2.66%，选股 -3.48%，交互 +0.01%。也就是说，行业偏离总体没有拖累，真正的问题是选中的股票在各自行业内没有跑赢行业基准。

因子归因只能作为弱参考。价值、成长、流动性、质量累计为负，动量基本持平，但平均横截面回归 R2 只有 0.048，说明这些风格组对月度个股收益解释力很弱。不能把 V2 失败强行归因成“某一个风格因子拖累”，更稳妥的表述是：可观测风格解释不足，行业内选股残差和信号失效更关键。

## NAV 对账与产品风险

`attribution_nav_reconciliation.parquet` 显示 Brinson 与 NAV 月度口径基本可用，但仍有产品化风险：

- 首个持仓期 NAV 对账为 NaN，原因是 NAV 起点在 2022-01-04，无法直接取 2021-12-31 的 NAV。
- 有效 11 个月中，`excess_discrepancy` 最大绝对值为 0.42%，未超过 0.5% 的宽松警戒线。
- `strategy_discrepancy` 最大为 +0.91%，且 11 个月中有 4 个月为正，说明 NAV-Brinson 差异不只是成本/现金拖累，还混有期间端点、几何链接和估值口径差异。
- `attribution_metadata.json` 中 `reconciliation_max_excess_discrepancy` 为 `NaN`，严格 JSON 语义不佳。
- `attribution_metadata.json` 中 `backtest_weights_v2` hash 为 `e3b0c442`，疑似空输入 hash 或 hash 生成路径问题。

这些问题不推翻 Brinson“选股拖累”的方向，但发布前应修复 metadata 与对账说明，避免报告把归因解释得过满。

## 产品化判断

阶段 6 支持以下结论：

1. 可以把 2022 V2 的直接业绩失败描述为“行业内选股失败”，证据强。
2. 不应把失败描述为“行业配置错误”，因为配置效应累计为正。
3. 不应把失败描述为“某单一风格因子拖累”，因为因子归因 R2 很低。
4. 归因结果更像是阶段 2-4 的结果层验证：因子/信号衰减后，优化组合在行业内没有选出足够强的股票。

## 下一步建议

1. 在最终报告中优先展示 Brinson 累计和月度负贡献，不优先展示低 R2 的风格归因图。
2. 修复 attribution metadata 的 `NaN` 和疑似空 hash。
3. 对“未分类”行业选股负贡献做轻量复查，确认行业映射覆盖是否有系统问题。
4. 后续改进实验必须同时记录行业内选股效应，不能只看总 NAV。
