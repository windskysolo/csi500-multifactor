## 第一节　摘要

**最终方案**：Rolling 48 个月 Ridge 回归信号合成，TopN150 等权组合构建，叠加北向持仓季度因子（hk_hold）。

本项目形成三个关键工程发现：

1. **QP 优化器系统性 IR 损耗**：二次规划（QP）优化器对所有信号类型均造成 16%–56% 的 IR 衰减，根因为"序数 vs 基数"信号错配——QP 使用 alpha 绝对量级分配权重（对噪声敏感），而 TopN 等权仅依赖排名序数（对噪声鲁棒）。

3. **验证期→测试期 IR 衰减**：IR 从 2.150 降至 0.645（衰减约 70%），三项硬指标仍全 PASS，策略具备基本样本外有效性，但衰减根因是后续改进的核心方向。

## 第二节　项目背景与目标

### 2.1　为什么做指数增强

指数增强（Index Enhancement）是量化 alpha 的一种典型落地形式：策略以目标指数为基准，在控制跟踪误差的约束下，通过系统性的股票选择在基准之上获取超额收益。之所以选择这一范式作为系统化研究的落地形式，在于它同时满足了研究严谨性和工程可操作性两方面的要求。跟踪误差作为主动风险的量化上界，将"产生了多少超额"与"承受了多少主动风险"同时量化，使超额收益的来源从模糊的主观判断变为可测量、可归因的系统性偏离；Brinson 归因框架进一步将超额拆解为行业配置与个股选择两个层次，当策略出现失效时，研究者可以直接定位问题所在的层次，而不是面对一条无法拆解的 P&L 曲线。另一方面，以宽基指数成分股为可投资域意味着相对充裕的市场流动性——500 只中盘股的日均成交额足以支持月频调仓的换手量，冲击成本可控。

相比**纯被动指数投资**，指数增强在跟踪误差预算内挖掘 alpha，成本增量有限；相比**纯主动管理**，风险来源透明，回撤边界可提前量化。对于一个以系统化研究为目标的量化工程项目，这一范式在研究严谨性和实际可操作性之间提供了最优平衡。

### 2.2　为什么选中证 500

中证 500 指数由 A 股市值排名第 301 至第 800 位的股票构成，代表 A 股中盘市值层。从量化研究角度，这一层级具备以下特点：

- **信息不对称程度较高**：相比大盘蓝筹（沪深 300），中盘股的卖方研究覆盖较少，财务数据和替代数据中蕴含的定价偏差更明显，为多因子策略提供了更大的 alpha 挖掘空间。
- **成分股数量适中**：500 只股票在"因子信号覆盖充分"与"组合优化规模可计算"之间取得平衡。对于二次规划（QP）优化器而言，500 维协方差矩阵在 LedoitWolf 收缩估计下仍可稳定求解。
- **流动性相对充裕**：中证 500 成分股的日均成交额足以支持月频调仓所产生的换手量，在本项目 722%–728% 年化换手率水平下，滑点成本可控。

### 2.3　量化目标

衡量一套指数增强策略的表现，最常见的错误是依赖单一数字。只看 IR 会忽略极端下行风险——一个平均超额亮眼的策略，完全可能在某个季度经历 15% 的超额回撤，这样的风险敞口在实际运营中难以接受。只控制回撤，又可能错误保留信号微弱、超额偶然累积的策略。换手率则独立于收益端，过低意味着有效信号的利用不足，过高则意味着交易成本正在持续侵蚀 alpha。三项指标分别从收益质量（IR）、极端风险（超额最大回撤）和成本可行性（换手率）三个维度施加约束，缺任何一项都会留下评估盲区。以下三项被设为晋升主线的**硬性必要条件**，任一未达标的方案均不进入主线竞争，无论其他指标表现如何：

| 指标 | 硬指标阈值 | 设定依据 |
|------|-----------|---------|
| 信息比率（IR） | **≥ 0.5** | 超额收益稳定性的基准下限；IR<0.5 意味着月度超额收益基本不显著 |
| 超额最大回撤 | **≤ 10%** | 最差情景下行保护；即使 IR 达标，若曾出现 15%+ 的超额回撤，实际运营中将承受极大压力 |
| 年化双边换手率 | **500%–1500%** | 成本与 alpha 捕捉的平衡区间；换手过低意味着信号利用不足，换手过高则交易成本侵蚀 alpha |

其余三项指标（年化超额收益、跟踪误差、月度胜率）作为横向比较和深度分析的辅助维度，在方案晋升后用于区分不同实验的质量差异。

## 第三节　系统整体架构

### 3.1　九层架构设计

整个量化研究系统按数据流方向分为九个层次，每层只能调用同层或下层模块，**依赖关系严格单向向上**，任何模块不得反向依赖上层逻辑：

```
L8  Pipeline 编排层     run_experiment.py / ExperimentSpec / stage 调度
L7  实验脚本层          scripts/*.py（run_portfolio_optimization, run_backtest 等）
L6  归因层              src/attribution/（Brinson 归因 + 因子收益归因）
L5  回测层              src/backtest/（NAV 计算、成本建模、指标汇总）
L4  组合构建层          src/portfolio/（优化器 QP / TopN EW / Fallback 机制）
L3  信号合成层          src/signal/（IC_IR 合成 / Ridge Combiner / Decay Ridge）
L2  单因子评估层        src/evaluation/（IC 序列、Gate 评估、相关性剔除）
L1  因子构建层          src/factors/（各类因子的构建函数，调用 L0 读取数据）
L0  数据基础层          src/data/（PIT 加载器、数据缓存、原始 Parquet 管理）
```

这一架构强制了研究代码与生产代码的边界：L7–L8 负责把单次实验从配置文件驱动到产物落盘，L0–L6 实现具体的金融计算逻辑。修改任何一个金融算法，只需改动对应层的模块，不触及编排层。

### 3.2　三个核心设计决策

#### 决策一：Stage 编排与业务逻辑分离

`src/pipeline/stages.py` 作为编排包装层，只做三件事：根据 ExperimentSpec 选择正确的实现、将输入/输出路径对齐到产物契约（artifact contract）、捕获失败并抛出带上下文的异常。它**不包含任何金融计算逻辑**。

```python
# stages.py 的典型逻辑——只做路由，不做计算
def run_signal_stage(spec, run_dir, data_proc=None):
    if spec.signal.method == "icir":
        return _run_signal_icir(sig, signal_dir, ...)   # 转发给 src/signal/
    elif spec.signal.method == "ridge":
        return _run_signal_ridge(sig, signal_dir, ...)  # 转发给 src/signal/
```

这一分离带来的工程收益：底层模块（如 `src/signal/ridge_combiner.py`）可以脱离 pipeline 独立单元测试；算法改进时只需修改对应的 `src/` 模块，编排层和产物路径契约无需变动。在本项目中，IC_IR 合成、expanding Ridge、rolling Ridge、decay Ridge 四种信号方法共享同一个 stage 函数，得益于这一分离，每次添加新方法只需在 `src/signal/` 新增实现，stages.py 只增加一个 `elif` 分支。

#### 决策二：Python dataclass 定义实验配置（ExperimentSpec）

实验配置不使用 YAML 或 JSON，而是通过 `src/pipeline/contracts.py` 中的 Python dataclass 定义：

```python
@dataclass
class ExperimentSpec:
    experiment_id: str
    description: str
    period_scope: str        # "train_valid" | "test_run_N"
    signal: SignalSpec
    optimizer: OptimizerSpec
    backtest: BacktestSpec
    allow_test_set: bool = False
    
    def __post_init__(self) -> None:
        # 测试集保护锁：period_scope="test_run_N" 时
        # 必须 allow_test_set=True 才允许运行，否则抛出异常
        ...
```

每个实验对应一个独立的 Python 配置文件（`configs/pipelines/*.py`），如已晋升主线的配置：

```python
# configs/pipelines/rolling48_topn150_ew_hk_quarterly.py
SPEC = ExperimentSpec(
    experiment_id="rolling48_topn150_ew_hk_quarterly",
    signal=SignalSpec(method="ridge", training_mode="rolling", window_months=48, purge_months=2),
    optimizer=OptimizerSpec(optimizer_mode="topn_ew", topn=150),
    backtest=BacktestSpec(execution="tplus1_open", benchmark="CSI500_TOTAL_RETURN"),
)
```

选择 Python dataclass 而非 YAML/JSON 的原因有三：①加载时进行类型校验，传入错误类型立即报错而非运行到一半才崩溃；②IDE（PyCharm/VS Code）可以检查字段名拼写，YAML 文件则不行；③`__post_init__()` 可以执行测试集保护锁——当 `period_scope` 以 `"test_run_"` 开头时，若 `allow_test_set=False`（默认值），运行即抛出异常，从架构层面阻止误触测试集。这是整个测试集纪律体系的核心保障机制。

#### 决策三：PIT 正确性集中保证

所有财务数据经由 `src/data/pit_loader.py` 中的 `_filter_visible()` 函数统一过滤，实施双重 PIT 约束：

```python
def _filter_visible(pit_raw, rebalance_date, codes=None):
    """
    双重 PIT 过滤：
      pit_date <= rebalance_date   仅使用已披露数据（公告日约束）
      end_date  < rebalance_date   报告期早于调仓日（不使用未来报告期）
    """
    mask = (
        (pit_raw["pit_date"] <= rebalance_date)   # 公告日 ≤ T
        & (pit_raw["end_date"] < rebalance_date)  # 报告期 < T
    )
    return pit_raw[mask]
```

这一设计的核心思想是：**因子层接收到的数据已经是 PIT 安全的，无需在每个因子函数里重复校验**。`_filter_visible()` 是整个项目唯一的 PIT 入口，所有财务因子（`ep_ttm`、`roe_delta`、`cfp` 等）都通过调用上层封装函数（`make_ttm`、`get_pit_latest`、`get_roe_delta` 等）间接走这一过滤逻辑。

**不做 PIT 的代价**：若直接用报告期（`Accper`）而非公告日（`f_ann_date`/`ann_date`）作为数据可用日期，A 股季报存在 1–4 个月的披露滞后，意味着 T 日用到了 T+30 至 T+120 天的未来财务数据。在历史回测中这会显著虚高 IC 和 IR，是财务因子策略最常见的未来函数来源之一。本项目通过集中化的 `_filter_visible()` 在架构层面消除这一风险，而非依赖每位开发者在因子层自行检查。

### 4.1　七类核心数据

所有数据来自 **Tushare Pro**，通过分步下载脚本缓存为 Parquet 文件。

### 4.2　PIT 机制

PIT（Point-in-Time）是本项目最重要的数据质量保证机制，其目标是：**T 日因子计算只能使用 T 日盘后实际已可知的信息**。

**错误做法（常见未来函数来源）**：直接用报告期（`Accper`/`end_date`）作为财务数据可用日期。A 股财报存在强制披露滞后：季报最晚披露截止日为季末后 30–45 天，年报最晚 4 月 30 日。若以 2023-06-30（Q2 报告期）为数据可用日，而实际公告日为 2023-08-25，则相当于 T=2023-07-31 时用了 T+25 天后才披露的数据，引入约 1–4 个月的未来函数。

**正确做法（本项目实现）**：以公告日期（`f_ann_date` / `ann_date`）为 PIT 锚点，在 `src/data/pit_loader.py` 的 `_filter_visible()` 函数中实施**双重约束**：

```python
def _filter_visible(pit_raw, rebalance_date, codes=None):
    """
    双重 PIT 过滤：
      pit_date <= rebalance_date   仅使用已披露数据（公告日约束）
      end_date  < rebalance_date   报告期早于调仓日（排除未来报告期）
    """
    mask = (
        (pit_raw["pit_date"] <= rebalance_date)   # 公告日 ≤ T
        & (pit_raw["end_date"] < rebalance_date)  # 报告期 < T
    )
    return pit_raw[mask]
```

第一重约束（`pit_date ≤ T`）确保公告未发布的数据不可用；第二重约束（`end_date < T`）剔除报告期本身在 T 之后的数据，防止 "T 日刚好是季末，季报尚未公告" 这类边界情况。

**集中化保证**：`_filter_visible()` 是整个项目唯一的 PIT 入口，所有财务因子计算函数（`make_ttm`、`get_pit_latest`、`get_roe_delta`、`get_quarterly_history` 等）均通过调用这一工具函数间接完成过滤。因子层接收到的数据已经 PIT 安全，无需在每个因子内部重复校验，这从设计上消除了遗漏 PIT 检查的风险。

此外，财报陈旧度阈值设为 9 个月（`STALE_THRESHOLD_MONTHS = 9`）：若某只股票最新可见报告期距调仓日超过 9 个月，相关财务指标置 NaN，视为数据过期。该阈值基于 A 股季报间隔最大 6 个月保留 3 个月安全边际确定。

### 4.3　时间切分

| 时段 | 区间 | 用途 |
|------|------|------|
| 训练期 | 2012-01-01 — 2020-12-31 | 因子评估（Gate 检验）、超参数调优（Ridge α、TopN、TE 目标）、IC_IR 权重基础期 |

### 4.4　关键口径约定

口径不统一是回测中最隐蔽的偏差来源，以下约定在整个项目中严格执行，集中定义在 `src/config.py`：

| 维度 | 规则 | 错误后果 |
|------|------|---------|
| 价格口径 | 全程**后复权**（`open_adj`/`close_adj`/`ret`） | 前复权会使历史价格随复权因子变化，无法直接比较同一时点的横截面 |
| 基准指数 | 中证 500 **全收益指数**（`CSI500_TOTAL_RETURN`，含分红再投资） | 使用价格指数会虚增超额收益约 2–3%/年（分红未计入基准） |
| 市值中性化 | **自由流通市值**（`free_float_mv`），取对数：`log_free_float_mv` | 总市值含非流通股，对选股约束无实际意义 |
| 行业分类 | 申万一级 **SW2021**，31 个行业 | 旧版 SW2021 前行业与新版对照关系混乱，统一 SW2021 |
| 股票代码 | Tushare `ts_code` 格式（如 `000001.SZ`） | 裸 6 位代码无法区分深沪，拼接查找时会产生重复匹配 |
| 财务字段量纲 | `financial_pit` 字段为**元**；`daily_basic.total_mv` 为**万元** | 量纲混用会使市值中性化系数偏差 10000 倍 |

## 第五节　因子体系

### 5.1　因子库构成

经过完整的 Gate 筛选流程（见 §5.3），最终入选 **18 个因子**（`reports/factor_evaluation/final_factors.json`，生成于 2026-05-29，git: `79db3f0`）。从候选池的 55 个因子中筛选出 18 个，37 个被淘汰。

最终 18 个因子的格局，既反映了各维度因子信号强度的差异，也体现了因子池在维度覆盖上的刻意平衡。波动率和流动性类因子在 A 股历史上表现出最强的截面预测稳定性，5 个量价因子全部通过 Gate 筛选；财务类因子中，盈利改善动能（`roe_delta`、`roe_delta_3q`）和估值类（`ep_ttm`、`cfp`）的训练期 IC_IR 最高，是财务维度的核心支柱。成长类因子（`rev_acceleration`、`rev_yoy`）在全训练期 IC_IR 排名靠前，同样全部入选。被淘汰的 37 个候选因子大多在 Gate 1（IC_IR 绝对值 < 0.30）或 Gate 3（五分组收益单调性不显著）处出局，部分财务因子还因金融行业财务结构特殊、有效股票覆盖不足而在 Gate 0 阶段筛除。

### 5.2　五步预处理流水线

每个调仓日 T，对每个因子独立执行五步预处理（`src/factors/preprocess.py`）。五步的顺序不可互换，每步解决特定问题：

**Step 1 — 金融股财务因子过滤**

银行（`801780.SI`）和非银金融（`801790.SI`）的财务报表结构与非金融行业根本不同（如杠杆率含义迥异、营收口径不同），其财务因子值会系统性失真。量价因子不受此影响（`fin_sector_codes=None` 跳过此步）。

```python
if fin_sector_codes:
    fin_mask = industry.isin(fin_sector_codes)
    processed[fin_mask] = np.nan   # 金融股财务因子置 NaN，不参与后续计算
```

**Step 2 — MAD 去极值**

截断边界 = 横截面中位数 ± 3 × 1.4826 × MAD。关键约束：**边界只用 T 日横截面的非 NaN 值计算，不用历史全样本**。使用全样本统计量会让 T 日未来信息（未来时点的分布特征）渗入当期截断边界，是去极值中最常见的未来函数形式。系数 1.4826 是 MAD 与正态分布标准差的一致性修正系数（`σ ≈ 1.4826 × MAD`）。

**Step 3 — Z-score 标准化**

横截面均值=0、标准差=1，使不同量纲的因子（如换手率的 % 单位 vs Amihud 的价格-成交量比率）可直接加权合成。NaN 位置保持 NaN，不参与均值/标准差计算。

**Step 4 — 行业 + 市值中性化**

在有效股票子集上做 OLS 回归：

```
factor ~ C(industry_SW2021) + log(free_float_mv)
```

取残差作为中性化后的因子值。此步的作用是剥离系统性风格暴露：若某因子与"中小盘"或"银行板块"高度相关，纯 alpha 信号被风格驱动；中性化后残差代表排除了行业配置效应和市值效应之后的纯选股信号。有效股票数 < 30（`MIN_NEUTRALIZE_STOCKS`）时跳过中性化，返回 Step 3 输出，并记录警告。

**Step 5 — 残差再标准化**

OLS 残差的量纲仍依赖因子本身的分布，不同因子残差方差不一致。再次 Z-score 标准化后，所有因子进入信号合成时均值≈0、标准差≈1，合成权重具有可比性。

整个流水线的贯穿性约定：**NaN 全程保持 NaN，不做任何填充**。填充操作在组合优化层（`src/portfolio/optimizer.py`）统一完成，在传入 cvxpy 前将 NaN 替换为 0（视为该股票对该因子无观点）。这一边界隔离确保因子层和优化层的职责清晰。

### 5.3　四道 Gate 筛选标准

单因子从候选到入选因子池需依次通过四道量化检验（训练集 2012-2020），任一失败则淘汰：

| Gate | 检验维度 | 失败判定 | 代码来源 |
|------|---------|---------|---------|
| Gate 0 | 横截面有效值**覆盖率** | 可投资域覆盖率过低（修复前 hk_hold 早期全为 NaN 即属此类） | `factor_health.py` 覆盖检查 |
| Gate 1 | **IC_IR**（信息比率） | IC_IR 绝对值 < 0.30 | `config.EVAL_IC_EFFECTIVE_CRITERIA["min_ic_ir"] = 0.30` |
| Gate 2 | **IC 均值与方向一致性** | IC 均值绝对值 < 0.02，或方向一致期数比例 < 55%，或 BH 校正后 p > 0.05 | `ic_analysis.batch_ic_test()` |
| Gate 3 | **五分组单调性** | Q1–Q5 收益无单调递增/递减趋势，多空 Sharpe < 0.50 | `quintile_backtest.py` + `config.EVAL_SHARPE_LS_THRESHOLD = 0.50` |

四道 Gate 设计了递进的严格程度：Gate 0–1 快速排除无信号因子（低成本），Gate 2 检验统计显著性（含多重检验校正防止 p-hacking），Gate 3 从实际交易维度验证选股能力（考虑换手和单调性）。

**近期 Gate 评估结论（2026-05-29）**：
- `accrual`：IC_IR=−0.144（Gate 1 失败），且与 `cfp` 高度负相关（r=−0.741），存在冗余，已淘汰
- `asset_growth`：IC_IR=−0.198（Gate 1+3 双重失败），A 股成长溢价方向相反（高资产增速 → 负超额），已淘汰
- `share_issuance`：IC_IR=−0.113（Gate 1+2+3 三重失败），已淘汰
- `mf_flow_ratio`（资金流向）：Gate 0 覆盖率 72%（低于期望）+ Gate 1+2 失败，但两期方向一致，逆向信号待进一步研究

### 5.4　两个需要特别说明的因子

**hk_hold 因子的 P0 修复（2026-06-02）**

北向持仓因子（`hk_hold_ratio` / `hk_hold_chg`）的原始实现存在 P0 级数据问题：2024-08-19 起北向资金持股改为季度披露（每季末后约 5 个交易日公布），但原实现仍使用 30 交易日滑动窗口，导致 2024 年后所有月末截面读到的数据全为 NaN——即策略每月对这两个因子的 500 只股票全无观测值，相当于整个北向维度在 2024 年后静默失效。

修复方案：将两个因子重新定义为**季度 PIT 快照因子**，回看窗口改为 270 日历天（约 3 个自然季度），叠加 10 日历天的 PIT 偏移（季末后约 5 个交易日为公告延迟）和 120 天的最大陈旧度保护：

```python
WINDOW_HK_HOLD_QUARTERLY   = 270   # 季度快照回看窗口（日历天）
HK_HOLD_QUARTERLY_OFFSET_DAYS = 10 # PIT 偏移：季末后约5个交易日
MAX_HK_HOLD_STALENESS_DAYS = 120   # 最大允许披露滞后（约1个季度）
```

修复后验证期 2021-2022 全空月归零，IR 从 1.771 提升至 **2.150**（+0.379）。`stability_weight` 维持 0.5（较低），以反映季度数据频率低于月频调仓、时效性相对弱的特点。

**piotroski_f 的 REMOVE_CANDIDATE 状态**

Piotroski F-Score 是一个 9 项财务健康评分的综合指标，在 A 股历史上有一定理论支撑，因此进入了初始候选池并通过了 Gate 评估。然而，消融实验（ablation）在 expanding Ridge + QP 基线（IR=0.408）上显示：**剔除 piotroski_f 后 IR 从 0.408 升至 0.524（+0.116）**，说明该因子在当前信号合成中对其他因子存在干扰。

需要注意的是，消融实验的基线是旧有的 expanding+QP 配置，并非当前已晋升主线（rolling48+TopN150）。该因子在 rolling Ridge 信号下的影响尚未通过独立实验验证，因此标记为 REMOVE_CANDIDATE 而非直接淘汰，待后续在主线配置上重新消融确认。

## 第六节　信号合成方法

### 6.1　三条演进路径总览

信号合成是将 18 个预处理后的横截面因子转化为单一截面排名信号的过程。项目经历了三条路径的演进，每次转变都由实验数据驱动：

| 路径 | 方法 | 训练窗口 | 组合方式 | 验证期 IR | 地位 |
|------|------|---------|---------|---------|------|
| A | IC_IR 加权 | 滚动 24 个月历史 IC | TopN50 EW | **0.924** | 冻结基线，永不重跑 |
| B-1 | Ridge expanding | 全历史 | QP | 0.408 | 已淘汰 |
| B-2 | Ridge rolling 36m | 36 个月 | QP | 0.966 | 已淘汰 |
| B-3 | Ridge rolling 48m | 48 个月 | QP | 1.489 | 最优 QP 配置 |
| B-4 | Ridge rolling 60m | 60 个月 | QP | 1.176 | 已淘汰 |
| C-1 | Decay Ridge hl24 | expanding+衰减 | QP | 0.626 | 已淘汰 |
| C-2 | Decay Ridge hl36 | expanding+衰减 | QP | 0.295 | 已淘汰 |
| C-3 | Decay Ridge hl48 | expanding+衰减 | QP | 0.289 | 已淘汰 |
| **B-3+EW** | **Ridge rolling 48m** | **48 个月** | **TopN150 EW** | **2.150** | **已晋升主线** |

### 6.2　路径 A：IC_IR 加权（冻结基线）

**机制**：每个调仓日 T，计算每个因子在过去 24 个月的历史 IC 序列，用 IC_IR（IC 均值 / IC 标准差）作为权重线性合成截面信号：

```
composite[i] = Σ_k(IC_IR_k × f_k[i]) / Σ_k(|IC_IR_k|)
```

其中 k 遍历当期有效因子（IC_IR 非 NaN），i 为股票。分母是权重绝对值之和，保证合成信号的量纲稳定。

**关键时间约束（防信号泄露）**：IC 权重计算窗口严格使用 `before_date < T` 的历史 IC，且额外**丢弃最近一期**（`ic_series[:-1]`）。原因是：IC(T−1) = corr(factor[T-1], fwd_ret[T-1])，而 fwd_ret[T-1] 的退出时点是 T 后第一个交易日，在 T 盘后生成信号时该收益尚未实现。丢弃最近一期确保 IC 权重只依赖 exit_date < T 的历史收益。

**冷启动处理**：若因子有效 IC 历史不足 12 期（`SIGNAL_MIN_IC_HISTORY = 12`），该因子当期权重置 NaN，不参与合成；若所有因子均处于冷启动期，退化为等权合成。

**地位说明**：该方案被设立为**冻结基线**（`frozen_baseline_icir_topn50_ew`，IR=0.924）。"冻结"意指永不重跑、永不晋升、数据区间不延长，使其成为所有后续实验的固定参照锚。任何新方案若无法超越 IR=0.924，在设计上就存在不可接受的倒退。

### 6.3　路径 B：Ridge 回归（最终采用方向）

**为什么要从 IC_IR 加权转向 Ridge**：IC_IR 加权假设每个因子独立贡献，权重只反映单因子历史有效性，无法捕捉**因子间的交叉效应**（如某两个因子联合预测能力高于各自单独预测之和）。Ridge 回归将多因子联合拟合为预测目标（下月超额收益），在正则化约束下学习因子间的线性组合关系，理论上能提取 IC_IR 加权遗漏的交叉信息。

**Walk-forward 训练框架（防数据泄露）**

Rolling Ridge 在每个调仓日 T 使用以下训练窗口：

```
训练样本日期 ∈ (T − window_months,  T − purge_months]
```

以 window_months=48、purge_months=2 为例，T=2022-12-31 时，训练集是 2018-12-31 至 2022-10-31 之间的调仓日，最近 2 个月（2022-11 和 2022-12）被清除（purge）。设置 `purge_months=2` 的原因：从因子计算日到收益实现日，存在约 1–2 个月的时间重叠（T 月因子 → T+1 开盘买入 → T+1 月末卖出），清除最近期可消除训练标签与预测特征之间的时序污染。

Ridge 正则化系数 α 通过 walk-forward 交叉验证在训练集内部选取，候选值为 `[0.1, 1.0, 10.0, 100.0, 500.0, 2000.0, 5000.0]`，评估指标为训练折内的样本外 IC，选取方式为 `cv_train_only`（仅在训练期内做交叉验证，验证期数据绝对不接触）。

**Rolling 窗口长度选择（实验依据）**

窗口长度的选择实质上是在"模型能否感知近期市场环境"和"训练样本是否足够稳定"之间做权衡。Expanding 窗口是最直接的起点：随着时间推进，历史数据不断累积，模型从 2012 年起的全部样本中估计系数。问题在于 A 股市场在 2012 至 2025 年间经历了多轮风格轮换，早期的价值溢价特征到近年出现明显弱化，早期样本的"历史经验"在 2020 年代之后可能已成为噪声而非信号——验证期 IR 仅 0.408 证实了这一直觉。将窗口缩短至 36 个月后，IR 跳升至 0.966：硬截断近 3 年以前的历史数据，使模型聚焦近期市场格局，效果立竿见影；但 36 个月的样本量下，部分调仓日训练集仅有约 300 条月度截面记录，正则化估计的稳定性仍受限制。将窗口延伸至 48 个月，IR 进一步升至 1.489，这是在"足够的历史样本保证估计稳健"与"不引入过于陈旧的市场信息"之间的最优点；继续延伸至 60 个月，IR 反而降至 1.176，印证了样本量超出某个阈值后，时效性损失开始主导。四种配置均以 QP 优化器为受控变量，保证差异来自训练窗口而非优化路径：

| 训练模式 | 验证期 IR（+QP） | 对比 expanding IR=0.408 |
|--------|--------------|----------------------|
| Expanding | 0.408 | 基线 |
| Rolling 36m | 0.966 | +0.558（↑137%）|
| **Rolling 48m** | **1.489** | **+1.081（↑265%）** |
| Rolling 60m | 1.176 | +0.768（↑188%）|

48 个月（约 4 年）是近期适应性与训练样本充足性的最优平衡点，经此系统实验选定为主线窗口参数。

**Ridge 系数历史**：每次运行产物中保存 `signal/coef_history.parquet`，记录每个调仓日各因子的 Ridge 系数，可用于事后分析因子贡献的时序变化。

### 6.4　路径 C：Decay Ridge（探索结论）

**机制**：在 expanding 窗口基础上，对不同时期的训练样本施加指数衰减权重，近期样本权重高（`exp(-λ × age)`），远期样本权重低。半衰期（`half_life_months`）控制衰减速度。从直觉上，这是在 expanding 与 rolling 之间的一种折中：保留全部历史信息，但让模型更关注近期模式。

**实验结果**：

- hl24（半衰期 24 个月）：IR=0.626，略优于 expanding（0.408），但远低于 rolling 48（1.489）
- hl36（半衰期 36 个月）：IR=0.295，低于冻结基线（0.924），三项硬指标中 IR 不达标
- hl48（半衰期 48 个月）：IR=0.289，同样 IR FAIL

**失败原因分析**：

- hl36/hl48 的衰减程度接近 expanding（半衰期长 → 衰减几乎消失），但没有 rolling 的"边界截断"效果，等效于加权较差的 expanding
- hl24 效果好于 hl36/hl48，但仍不如 rolling 48：rolling 窗口对近期环境的"专注度"（硬截断）比指数衰减（软截断）更有效

**结论**：Decay Ridge 路径整体不及 rolling 窗口，不纳入主线。后续若要继续改进信号合成，优先方向是在 rolling 48 框架上探索非线性方法（如 LightGBM），而非进一步调试 Decay 参数。

## 第七节　组合构建与优化

### 7.1　两条组合路径

完成信号合成后，复合信号（composite.parquet）需要转化为实际持仓权重。本项目实现了两条路径：

**路径一：二次规划（QP）**

优化目标为最大化 alpha 收益，减去换手惩罚项，同时约束主动风险和集中度：

```
max  α^T · w  − λ_TC · ‖w − w_prev‖₁
s.t.
  (w − w_b)^T · Σ_daily · (w − w_b) ≤ TE²_target / 252   # 年化 TE ≤ 6%
  |Σ_ind(w_i − w_b_i)| ≤ industry_max_dev   ∀ industry    # 行业偏离 ≤ ±3%
  |w_i − w_b_i| ≤ single_max_dev            ∀ stock        # 单股偏离 ≤ ±1.5%
  w_i ≥ 0,  Σ w_i = 1                                      # 纯多头、全仓
```

其中 `w_b` 为基准权重（中证500成分股权重），`Σ_daily` 为每日协方差矩阵（见 §7.3）。换手惩罚系数 `λ_TC = 0.005`，由验证期网格实验确定，用于隐性控制调仓频率。求解器按 `CLARABEL → SCS` 顺序尝试，单期求解超时（30 秒）触发 Fallback。

停牌和涨跌停的处理内置于约束层：
- **停牌**：`w_i = w_prev_i`（等式约束，强制锁定上期权重）
- **涨停**：`w_i ≤ w_prev_i`（不可买入）
- **跌停**：`w_i ≥ w_prev_i`（不可卖出）

**路径二：TopN 等权（EW）**

按复合信号排名取前 N 只等权持有，N=150 为当前主线配置。逻辑极简：

```python
top_indices = alpha.nlargest(topn).index    # 按信号排名取前 N
weights = pd.Series(1.0 / topn, index=top_indices)  # 等权
```

TopN EW 的设计初衷是**隔离优化器的影响**：若信号相同但 TopN EW 比 QP 有更高 IR，差值即为优化器的损耗，是诊断工具。实验证明 TopN EW 在所有信号类型上均优于 QP，从诊断工具晋升为正式主线路径。

**三层 Fallback 机制**

QP 求解失败（约束不可行或超时）时，按如下顺序退化：

| 层级 | 路径 | 触发条件 |
|------|------|---------|
| L1（默认）| 完整 QP（含 TE 二次约束）| 正常求解 |
| L2 | 线性约束 QP（去掉 TE 二次项）| L1 求解失败或 `optimal_inaccurate` 且负权重 > 0.5% |
| L3 | TopN 等权（`topn=50`）| L2 失败 |

主线的 rolling48+TopN150 EW 完全绕过 L1/L2，直接走 L3 路径（experiment_board 确认：`fallback_L0_cnt=0, L1_cnt=0, L2_cnt=106`；106 次"L2"实为验证期的每月 TopN EW 执行次数，对于 TopN EW 模式，L2 即为正常路径）。

### 7.2　协方差估计

500 维样本协方差矩阵存在严重的维度诅咒：500 只股票的协方差矩阵有 $\binom{500}{2} \approx 125000$ 个待估参数，而 24 个月的月频样本仅有 24 个观测，矩阵几乎必然是奇异的（条件数极大），直接用于 QP 会导致求解不稳定。

本项目采用 **LedoitWolf 收缩估计**（`sklearn.covariance.LedoitWolf`）：将样本协方差矩阵向等比例单位矩阵收缩，收缩强度由解析公式自动确定（无需手动调参）：

```
Σ_shrunk = (1 - α) · Σ_sample + α · μ · I
```

其中 α 为最优收缩系数，μ 为样本协方差迹的平均值。LedoitWolf 的数学保证是：在均方误差意义下，该收缩强度渐近最优。每期产物写入 `data/processed/cov_cache/`，复用时跳过重新估计。正定性校验在每期估计后自动执行，不正定时追加 `ε·I`（`ε=1e-6`）微小对角扰动修复。

### 7.3　关键发现：QP 对 IR 的系统性损耗

在通过信号演进将 IC_IR 加权升级为 Ridge 回归时，发现了一个贯穿所有信号类型的异常：使用 QP 优化器的 IR 始终显著低于 TopN EW。以下为跨四种信号类型的完整对比（均以验证期 2021-2022 为准，TopN EW 均取 N=50 作为受控对比）：

| 信号类型 | TopN50 EW IR | QP IR | IR 损耗 | 损耗比例 |
|---------|------------|-------|--------|--------|
| IC_IR 加权（复合信号）| 0.924 | 0.402 | −0.522 | **−56%** |
| Expanding Ridge | 0.574 | 0.408 | −0.166 | **−29%** |
| Rolling48 Ridge | 1.771 | 1.489 | −0.282 | **−16%** |
| Rank-transform QP（实验）| — | 0.299 | — | — |

两个关键观察：①损耗**覆盖所有信号类型**，说明问题在优化器，而非特定信号；②IC_IR 信号损耗最大（56%），而信号质量更高的 Rolling48 Ridge 损耗最小（16%）——这说明信号越强，QP 的"基数权重"越偏离最优，损耗越大。

**信号实现质量量化**：通过 Transfer Coefficient（TC）进一步诊断。TC 定义为 `Spearman corr(h_actual, h_optimal)`，衡量实际持仓排名与理想信号排名的吻合程度：
- 冻结基线（IC_IR+TopN50）：TC=0.585，N_eff=66.0，ir_loss=61.4%
- 已晋升主线（Rolling48+TopN150）：TC=0.806，N_eff=149.9，ir_loss=45.8%

注意：TopN EW 的权重为二值向量（持有股票为 1/N，其余为 0），TC 的结构上限约 0.4–0.6，即使选股完美也无法趋近 1.0，因此 TC 的绝对值不能跨策略类型直接比较。

### 7.4　根因诊断：序数 vs 基数问题

当发现 QP 损耗是系统性现象后，项目先后检验了两个直觉上的解释。第一个直觉是 TE 约束本身在限制信号发挥：若组合被迫贴近基准，高 alpha 股票的超配空间就受到压缩，优化器的潜力无法释放。为此，将 TE 目标从 6% 依次放松至 10%、15%，乃至完全去掉 TE 约束（强制走 L2 线性模式）。结果与直觉相反——所有放松配置的 QP IR 均**低于或持平**于 6% TE 约束版本：TE 约束不是阻力，而是防止组合无节制偏离基准的保护机制，去掉它只会引入更多不受控的风险暴露，进一步损耗 IR。第二个直觉是行业约束造成了过度中性化，压制了因子在行业层面的横截面效能——将行业偏离上限从 3% 放宽至 5%，以及完全去掉行业约束，两种放松同样使 QP IR 略有下降。两组实验的结果方向一致：约束体系是保护机制，而非瓶颈。

**确认根因：信号基数 vs 序数问题**

QP 的数学结构要求传入**连续的 alpha 绝对量级**（基数）作为目标函数系数：`max α^T · w`。alpha 绝对值的大小直接决定权重分配。然而，经过五步预处理后的因子合成信号，其绝对量级携带了大量噪声——截面 Z-score 使不同时点、不同市场环境下的信号量级不可直接比较，"信号=1.5"与"信号=0.8"的差值（0.7）没有稳定的经济含义。

TopN EW 只依赖**排名序数**：持有信号最高的 N 只股票，其余全部不持有，权重均等。序数信息比基数信息对噪声鲁棒得多——排名的稳定性远高于绝对量级的稳定性。

**排名变换实验的最终证伪**：为进一步验证，在 IC_IR 信号上实施排名百分位变换后再输入 QP（`rank(pct=True) - 0.5`，将信号压缩到 (−0.5, 0.5] 的均匀分布），使 QP 使用"更接近序数"的输入。结果：IR=0.299，比原始 QP（0.402）**更差**。原因是均匀排名使 alpha 景观趋于平坦，TE 和行业约束主导权重分配，信号贡献被稀释。这证明 TopN EW 的优势不来自"更高效地转移信号"，而来自"二值化+等权"本身的鲁棒性——QP 的"基数→序数"修复路线在本框架下无效。

### 7.5　TopN 数量的实验选择（N=150）

在确定使用 TopN EW 路径后，系统对比了 N∈{25, 50, 75, 100, 150, 200, 250, 300} 共 8 个配置（信号固定为 rolling48 Ridge，以排除信号变量），结果如下：

| N | IR | 超额MDD | 月胜率 | 年化换手 | IR✓ | MDD✓ | TO✓ |
|---|-----|--------|-------|--------|-----|------|-----|
| 25 | 1.771 | −5.68% | 65.2% | 973% | ✓ | ✓ | ✓ |
| 50 | 1.771 | −5.68% | 65.2% | 973% | ✓ | ✓ | ✓ |
| 75 | 2.248 | −4.91% | 65.2% | 939% | ✓ | ✓ | ✓ |
| 100 | 2.073 | −4.74% | 69.6% | 863% | ✓ | ✓ | ✓ |
| **150** | **2.274** | **−3.55%** | **78.3%** | **763%** | **✓** | **✓** | **✓** |
| 200 | 1.946 | −2.59% | 78.3% | 644% | ✓ | ✓ | ✓ |
| 250 | 2.321 | −2.71% | 78.3% | 568% | ✓ | ✓ | ✓ |
| 300 | 2.201 | −2.59% | 82.6% | 476% | ✓ | ✓ | **✗** |

N=300 年化换手 476%，跌破 500% 硬指标下限，直接淘汰。N=250 虽然 IR（2.321）高于 N=150（2.274），但年化换手仅 568%，距 500% 下限只有 68% 的安全边际，在市场波动较大时有触发下限风险。N=150 在 IR（2.274）、月胜率（78.3%）、换手（763%，距两端均有舒适边际）的多维综合表现上最优，且 MDD（−3.55%）优于 N=75/100/25/50 的所有配置。选定 N=150 作为主线配置。

## 第八节　实验治理体系

### 8.1　五类实验角色

实验治理的核心思想是**角色隔离**：不同目的的实验使用不同命名规范、不同注册路径、不同权限约束，防止实验结果混淆或无意识地用测试集信息指导模型改进。

| 角色 | 前缀/标识 | 职责 | 可晋升主线？ |
|------|----------|------|------------|
| **冻结基线**（frozen_baseline）| `frozen_baseline_*` | 永不重跑的参照锚，所有实验的下限 | 否（永不晋升）|
| **主线基线**（mainline）| 注册在 `registry/mainline.json` | 当前生产方案，challenger 的比较对象 | — |
| **挑战者**（challenger）| `challenger_*` | 待验证新方案，需超越主线 | 是（三硬指标 PASS 后）|
| **消融实验**（ablation）| `ablation_*` | 单变量贡献量化，不进入主线竞争 | 否 |
| **测试集运行**（test_run）| `period_scope="test_run_N"` | 最终样本外评估 | 只有主线候选才运行 |

**冻结基线的特殊地位**：`frozen_baseline_icir_topn50_ew`，run_id=`20260529_034947__frozen_baseline_icir_topn50_ew`，IR=0.924，2026-05-29 建立。"冻结"意味着三个约束：①数据区间不随时间延伸（固定在当时的 train_valid 范围）；②不因模型改进后重跑；③不进行晋升流程。这三个约束消除了最常见的基线失效原因——基线随着数据增多而自动变好，导致新实验的"改进"部分来自数据而非方法。每次 `compare_runs.py` **必须**包含此 run 作为所有实验的下限参照。

### 8.2　晋升流程

一个挑战者实验从运行到晋升主线的完整流程如下：

```
1. 编写 ExperimentSpec（configs/pipelines/*.py）
   ↓
2. python scripts/run_experiment.py --config <spec_file>
   ↓（产物：signal/、portfolio/、backtest/、reports/）
3. python scripts/compare_runs.py --runs <run_ids> --include-frozen-baseline
   ↓（生成：reports/experiment_board.md，含六项指标和三项 PASS/FAIL）
4. 人工审阅：三项硬指标全 PASS？与冻结基线对比改进幅度是否合理？
   ↓（若 PASS）
5. python scripts/promote_run.py --run-id <run_id>
   ↓（写入：registry/mainline.json）
```

晋升后，旧主线的 run_id 在 `mainline.json` 中被覆盖（保留 `promoted_at` 和 `reason` 字段），成为历史记录。当前已晋升主线：`20260602_104439__rolling48_topn150_ew_hk_quarterly`，晋升时间 2026-06-02T10:46:49Z，原因：`hk_hold 季度化修复后主线：验证期 IR=2.150，超额MDD=3.03%，换手722%，三硬指标全PASS`。

挑战者实验注册在 `registry/challengers.json`，记录 run_id、指标和当前研究状态（`researching` / `rejected` / `frozen_baseline`），作为实验历史档案。

### 8.3　测试集纪律

测试集纪律是本项目工程严谨性中最重要的一项规定，核心原则：**全项目测试集运行总次数 ≤ 3 次**。

**为什么限制次数**：如果研究者可以无限次查看测试集结果，并据此调整模型，则测试集从"真正的样本外"退化为第二个"验证集"——每次看完结果并做调整，等效于用测试集信息参数化了模型。3 次上限的设定保留了有限的"复查"机会（如发现明显的代码错误可重跑），同时防止系统性地用测试集反馈改进模型。

**技术实现**：测试集保护锁内置于 `ExperimentSpec.__post_init__()` 中，运行前验证 `period_scope` 和 `allow_test_set` 标志的组合是否合法，不满足条件立即抛出异常，从框架层阻止误触。计数权威来源为 `docs/logs/test_set_runs.json`，由 `scripts/test_set_ledger.py` 维护，每次有效运行后自动更新。

**历史记录**（来源：`docs/logs/test_set_runs.json`）：

| 运行次数 | 状态 | 时间 | git commit | 结论 |
|---------|------|------|-----------|------|
| 废除运行（不计数）| 操作性错误 | 2026-05-30 | — | 因子面板未覆盖测试期，信号全空，实际为买入持有策略，IR=0.149；废除 |
| [TEST_SET_RUN_1] | **有效** | 2026-06-02T11:15Z | `f2c3b5d` | 三项硬指标全 PASS，IR=0.645 |

**每次测试集运行的 git 纪律**：commit message 必须包含 `[TEST_SET_RUN_N]` 标记，使测试集运行在 git history 中可溯源（`git log --grep=TEST_SET_RUN` 即可列出全部记录）。

## 第九节　消融实验与因子诊断

### 9.1　消融实验设计原则

消融实验的核心约束是**单变量原则**：每次实验只改变一个因子（移除或替换），其余所有配置（信号方法、优化器、训练窗口、约束参数）完全不变。若同时改变多个因子，观测到的 IR 变化无法归因到任一具体改动，实验失去可解释性。

本节消融实验的参照基线是 **expanding Ridge + QP**（IR=0.408，run_id=`20260527_141545__baseline_expanding_ridge_te6_lam0050`），而**非当前已晋升主线**（rolling48+TopN150 EW，IR=2.150）。这一选择有两个原因：①消融实验在 2026-05-29 运行时，rolling48+TopN150 主线尚未建立；②expanding+QP 基线参数固定（expanding 窗口 + QP 优化），对因子变化更敏感，更适合诊断单因子的信号质量问题。因此，消融结论对当前主线的适用性需要另外验证（见后续工作 P2）。

### 9.2　消融实验结果

三个消融实验均已运行并记录（2026-05-29）：

| 实验 | 操作 | IR | 对比基线（0.408）| 超额MDD | 月胜率 | 换手 | 结论 |
|------|------|-----|----------------|--------|-------|------|------|
| 基线（expanding+QP）| — | 0.408 | — | −8.16% | 43.5% | 974% | 参照 |
| `ablation_no_piotroski_f` | 剔除 piotroski_f | **0.524** | **↑+0.116** | −8.08% | 47.8% | 972% | REMOVE_CANDIDATE |
| `ablation_no_high_52w_v2` | 剔除 high_52w_v2 | 0.423 | ↑+0.015 | −6.44% | 43.5% | 999% | 无显著价值 |
| `ablation_no_piotroski_high52w` | 同时剔除两者 | 0.430 | ↑+0.022 | −6.99% | 47.8% | 986% | 交叉效应弱 |

**piotroski_f 的结论**：单独剔除后 IR 提升 0.116（+28%），是三个消融中唯一具有实质改善幅度的操作。改善来自 piotroski_f 与其他因子之间的信号干扰（在 expanding Ridge 框架下，piotroski_f 的系数估计可能吸收了其他因子的部分信号方差，导致其他因子权重被压低）。该因子被标记为 `REMOVE_CANDIDATE`。

**high_52w_v2 的结论**：单独剔除后 IR 仅微升 0.015（+3.7%），没有实质性的统计意义（在 24 个月验证期样本量下，IR 变化 0.015 属于估计误差范围）。该因子保留在因子池中。

**交叉效应分析**：同时剔除两者的 IR（0.430）低于仅剔除 piotroski_f（0.524），说明 high_52w_v2 在 piotroski_f 被移除后反而有正贡献。两者的交叉效应为负：piotroski_f 存在时压制了 high_52w_v2 的信号，两者共存时 high_52w_v2 处于"被压制"状态。

### 9.3　待验证的关键限制

**消融实验基线的时效性问题**：三个消融实验的基线是 expanding+QP（IR=0.408），这是一个已经被 rolling48+TopN150 主线（IR=2.150）远远超越的旧配置。piotroski_f 在 expanding+QP 框架下产生干扰（+0.116），不等同于在 rolling48+TopN150 框架下也产生相同方向和幅度的干扰。两种框架的差异（expanding vs rolling 训练窗口 + QP vs TopN EW 优化器）足以改变因子间的相互作用模式。

因此，当前消融结论的**准确表述**是：**在 expanding Ridge + QP 基线配置下，piotroski_f 对信号合成产生了显著负干扰**。在已晋升主线上的影响是后续工作（P2）的首要任务。若消融结果在主线上可复现，可直接从因子池移除 piotroski_f，为引入新因子腾出"因子预算"。

### 10.4　结果解读

#### 方向一：信号与组合方法演进的效果脉络

回顾全部实验，超额收益的提升路径可以拆解为三次独立的改进：

**第一次提升：从 IC_IR 加权到 Rolling Ridge（+QP 框架内）**

IC_IR+QP（0.402）→ Rolling48+QP（1.489），提升 +1.087。Rolling 48 个月窗口的引入使信号质量大幅改善，在 QP 损耗依然存在的条件下 IR 仍接近翻四倍。这说明**信号质量是超额收益的最主要驱动力**，组合构建方式是其次。

**第二次提升：从 QP 切换到 TopN EW（信号固定）**

Rolling48+QP（1.489）→ Rolling48+TopN50 EW（1.771），提升 +0.282（+19%）。在信号完全不变的情况下，仅替换优化器，IR 即提升，印证了 QP 损耗的真实性和根因分析的有效性。TopN 从 50 扩展到 150 后进一步提升至 2.274，贡献来自组合分散（更低 MDD、更高月胜率）而非信号本身。

**第三次提升：hk_hold 因子修复（2026-06-02）**

Rolling48+TopN150（2.274，无 hk）→ Rolling48+TopN150+hk（2.150）。注意这里 IR 从 2.274 **降至** 2.150，而非提升。原因是 hk_hold 因子的引入虽然修复了数据层 P0 问题（消除了 2024 年后的全空月），但也引入了更多噪声——修复后的季度因子在部分月份的预测能力低于其他财务因子，略微降低了验证期整体 IR。

这一现象值得警惕：因子"修复后可用"不等同于"修复后一定贡献正 IR"。季度频率因子（hk_hold）相对于月频调仓策略存在内在的时效性错配，当月调仓用的是最近季末的持仓数据，其预测能力受制于数据新鲜度。

滚动 IR 视图能捕捉到验证期向测试期过渡期间 IR 的连续演化，弥补了区间平均统计掩盖结构性拐点的不足。滚动 IR 在 2023 年持续维持在 0.8 以上，与月度热图（图 3）中该年高密度绿色区域相呼应；2024 年下半年开始，滚动 IR 跌至 0.5 附近；2025 年部分时段降至 0.5 以下，但整体未出现持续跌破 0 的情况，说明策略的超额产生能力虽然减弱，但尚未发生方向性失效。这一时序图是下节衰减归因分析的定量基础。

IR 从验证期 2.150 降至测试期 0.645，衰减幅度约 70%。三项硬指标仍全部通过，策略未丧失基本有效性，但超额收益质量的显著下降是需要正视的核心问题。将测试期超额收益按年拆分，可以看到一个呈现系统性特征的递减趋势，而非随机波动：

|------|---------|---------|-------|
| 2021 | +9.7% | −1.3% | — |
| 2022 | +6.8% | −9.3% | — |
| 2023 | +4.4% | −7.4% | 10/11（91%）|
| 2024 | +3.4% | +7.7% | 7/12（58%）|

**因子层证据**

将测试期各因子的 IC_IR 与验证期对比，可以将因子池拆分为两类截然不同的行为模式：

| 因子 | 全期 IC_IR | 验证期 IC_IR | 测试期 IC_IR | 稳定性 |
|------|----------|------------|------------|--------|
| ivol_60d（低波动） | −0.681 | −0.621 | **−0.881** | 高稳定，测试期反而增强 |
| turn_20d（低换手） | −0.668 | −0.702 | −0.639 | 高稳定 |
| rev_acceleration | +0.570 | +0.662 | +0.497 | 高稳定 |
| cfp | +0.388 | +0.162 | **+0.534** | 测试期增强 |
| hk_hold_ratio | +0.343 | **+0.488** | **+0.091** | 测试期显著衰减 |
| amihud | +0.365 | +0.240 | **+0.018** | 测试期几乎失效 |
| q_roe | +0.311 | −0.041 | +0.015 | 测试期几乎失效 |

三个核心发现由此浮现。其一，策略最可靠的信号——低波动和低换手反转效应——在测试期不仅没有衰减，`ivol_60d` 的 IC_IR 绝对值反而从 0.621 升至 0.881，说明超额下降不是"所有因子都失效了"的全面崩溃，而是结构性分化。其二，`hk_hold_ratio` 的 IC_IR 从验证期 0.488 骤降至测试期 0.091——这一下降有明确的制度根源：2024 年 8 月 HKEX 将北向资金持股披露频率从日频改为季度披露，原本能捕捉外资周度调仓动向的因子变成了每季度才更新一次的快照，信息时效性的大幅下降直接导致了预测能力的收缩。其三，`amihud`（非流动性溢价）测试期 IC_IR 接近零（0.018）——2024-2025 年市场流动性充裕，小盘低成交量股票的非流动性溢价在牛市中基本消失，这是市场环境变化对具体因子机制的直接映射。

图 7 将各因子的验证期 IC_IR 和测试期 IC_IR 并排展示，在视觉上将因子池分为稳定型（低波动/低换手/成长类，条形高度接近）、增强型（cfp，测试期条形更高）和衰减型（hk_hold、amihud、q_roe，测试期条形大幅缩短甚至归零）三类。从衰减型因子的占比来看，超额收益下降有可识别的因子层根因，不完全是随机波动。

**综合判断**

综合年度分解数据和因子层证据，可以对衰减给出比并列假说更具体的解释。约 40–50% 的超额下降可以追溯到具体的结构性变化：`hk_hold` 数据披露频率的制度性改变和 `amihud` 在流动性充裕的牛市中自然失效；其余部分与整体市场环境切换（强 beta 市中质量/价值因子的相对 alpha 被稀释）有关，难以通过因子层调整直接消除。这一区分对后续工作有直接指导意义：结构性衰减部分（hk_hold、amihud）有明确的改进路径——替换为与当前披露机制相适配的替代数据因子，或在因子预算允许时直接剔除；环境依赖性衰减则需要引入在强 beta 市中有效的进攻型因子（如中短期价格动量）来补充因子池。当前剩余 2 次测试集机会，应在完成上述因子层调整并在验证集上确认改善后再审慎使用。

#### 方向三：交易成本的影响

交易成本参数来自 `src/config.py`（经此前核实）：

| 成本项 | 费率 | 适用条件 |
|-------|------|---------|
| 印花税 | 10 bps（卖出单边）| 2023-08-28 之前 |
| 印花税 | 5 bps（卖出单边）| 2023-08-28 之后（政策调整）|
| 佣金 | 2.5 bps（买卖双边各一次）| 全期 |
| 滑点 | 8 bps（保守估计）| 全期 |

主线回测中 v1=v2（策略在 TopN EW 模式下无独立的"仅优化权重"版本，所有 NAV 曲线均已含成本），因此无法直接从指标文件分离税前税后差异。从年化换手率（验证期 722%、测试期 728%）可以估算年化成本拖累量级：

- 2023-08-28 前：印花税 10 bps + 佣金 2.5 bps × 2 + 滑点 8 bps × 2 = 31 bps/单边换手
- 2023-08-28 后：印花税 5 bps + 佣金 2.5 bps × 2 + 滑点 8 bps × 2 = 26 bps/单边换手
- 年化双边换手 722%（≈7.22 次）× ~28.5 bps（混合均值）≈ **206 bps/年成本拖累**

成本拖累约 200 bps/年，在年化超额 935 bps（验证期）中占比约 22%。测试期的印花税率更低（2023-08 之后全为 5 bps），加之换手率 728% 与验证期基本持平，成本因素对两期结果的影响量级一致，IR 衰减主要来自超额 alpha 的绝对量级下降（+9.35% → +3.11%），而非成本上升。

## 第十一节　结论与后续工作

### 11.1　核心成果

项目的核心成果可按系统、信号、优化、因子、样本外五个层次总结。这五个层次不是并列的条目清单，而是构成了一条从基础建设到外部验证的递进链条：系统层搭建的工程闭环是一切实验可复现的前提；在此基础上，信号层的方法演进才能在受控条件下积累可比较的实验记录；优化器层的根因诊断是在信号足够强时才会暴露出来的瓶颈问题，没有稳定的信号基础，优化器的损耗会淹没在信号噪声中；因子层的修复和识别进一步精炼了信号的输入质量；最终，样本外层的测试集评估是对上述所有工作的一次独立检验，也是整个研究链条的收尾。沿着这条递进关系阅读，五个层次才能被理解为一个自洽的论证，而非五个独立成就的并列罗列。

**系统层——完整的量化工程闭环**

建立了覆盖数据下载（Tushare Pro）→ PIT 财务数据处理（`pit_loader._filter_visible()`）→ 因子构建（18 个因子）→ 单因子 Gate 评估（四道检验）→ 信号合成（IC_IR / Ridge）→ 协方差估计（LedoitWolf）→ 组合优化（QP / TopN EW / Fallback）→ 回测（T+1 开盘成交，成本建模）→ 归因（Brinson）的端到端可复现流程。

工程规范层面，建立了五类实验角色隔离体系、Python 数据类驱动的 ExperimentSpec 配置框架、测试集保护锁机制（`allow_test_set` 标志 + 3 次上限纪律），以及 `compare_runs.py` 驱动的横向比较和 `promote_run.py` 驱动的单线晋升流程。整个系统设计使每次实验从运行到记录均有完整产物追溯（signal/portfolio/backtest/reports 子目录）。

**信号层——Rolling Ridge 为最优合成方法**

IC_IR 加权（冻结基线，IR=0.924）→ Expanding Ridge+QP（IR=0.408，信号提升被 QP 损耗抵消）→ Rolling48 Ridge+QP（IR=1.489）→ Rolling48 Ridge+TopN50 EW（IR=1.771）→ Rolling48 Ridge+TopN150 EW（IR=2.274）→ +hk_hold（IR=2.150）。Rolling 48 个月滚动窗口在"近期市场适应性"与"训练样本充足性"之间取得最优平衡，是当前最优信号合成配置，经系统实验（expanding/rolling 36/48/60）选定。

**优化器层——QP 系统性 IR 损耗的发现与根因确认**

发现 QP 优化器对所有信号类型均造成系统性 IR 损耗（IC_IR 信号损耗 56%，Expanding Ridge 损耗 29%，Rolling48 Ridge 损耗 16%）。通过松弛 TE 约束（IR 不升反降）、松弛行业约束（IR 不升反降）、排名变换实验（IR=0.299，比基线更差）三组对照实验，确认根因为"序数 vs 基数"信号错配：QP 使用 alpha 绝对量级（对噪声敏感），TopN EW 仅依赖排名序数（鲁棒）。这一发现是本项目最重要的工程结论，它不仅确立了 TopN EW 作为正式主线路径，也对未来可能引入的其他优化器框架（如因子协方差矩阵约束的 Black-Litterman）提出了同样的诊断要求。

**因子层——hk_hold 修复与 piotroski_f 识别**

北向持仓季度因子（hk_hold）在修复数据 P0 问题（2024-08-19 后全空月）后首次正确参与信号合成，使验证期 IR 从 1.771（TopN50 EW 基准）提升至更完整的因子覆盖。Piotroski F-Score 被标记为 `REMOVE_CANDIDATE`：在 expanding+QP 配置下剔除后 IR 提升 +0.116（+28%），其在当前主线配置下的影响仍待验证。

**样本外层——测试期三硬指标全 PASS**

[TEST_SET_RUN_1]（2026-06-02，git: `f2c3b5d`）：测试期 IR=0.645（PASS ≥ 0.5），超额最大回撤 −5.70%（PASS ≤ 10%），年化换手 728%（PASS 500%–1500%）。策略在从未被模型见过的 2023–2025 年数据上维持了基本有效性，是项目最重要的外部效度证据。

### 11.2　后续工作优先级

根据测试集结果和当前已知问题，后续工作按优先级排列如下：

**P1（最高优先级）：诊断验证期 → 测试期 IR 衰减根因**

验证期 IR=2.150、测试期 IR=0.645，衰减约 70%。这是当前最重要的未解问题，诊断思路：

- **因子层分析**：计算 18 个因子在 2023-2025 年的逐月 IC 序列，找出哪些因子在测试期失效（IC_IR 大幅下降），特别是 hk_hold 系列和盈利成长类因子
- **市场风格归因**：Brinson 归因拆分选股贡献 vs 行业配置贡献，判断衰减主要来自选股层还是风格层
- **时间段细分**：2023、2024、2025 三年分别计算 IR（月度超额数据已有），确认衰减是从哪一年开始的（从月度明细看，2023 年月胜率明显高于 2024–2025）

这一诊断不消耗测试集次数（基于已有的测试期产物文件分析），可以充分展开。

**P2（次优先级）：在主线配置上验证 piotroski_f 消融效果**

当前消融实验基于旧的 expanding+QP 基线，需在 rolling48+TopN150 EW 配置下重新运行单变量消融。若剔除 piotroski_f 后主线 IR 改善，直接从因子集移除，为引入新因子腾出因子预算（18 个因子在较优控制范围内，建议保持在 15–20 个）。这属于验证期实验（`period_scope="train_valid"`），不消耗测试集次数。

**P3（因子扩充，视 P1/P2 结论决定）**

若 P1 确认 IR 衰减主要来自因子层（当前因子在 2024–2025 年有效性下降），则引入新因子：

- **动量类**：`mom_12_1`（12 个月动量，跳过最近 1 个月）重新评估——此前被排除，但排除决定基于 2012-2020 训练期，若 2023-2025 市场风格向动量倾斜，值得重新检验；
- **分析师预期类**：拆分分析师预测修订的行业内 vs 行业间效应，构建更精细的分析师因子；
- **主动流量类**：机构调研频率因子（`stk_surv`），若 2024–2025 的 alpha 来源转向信息优势领域，机构关注度变化可能是有效代理。

任何新因子必须经过完整的四道 Gate 评估（训练期），并通过单变量消融实验确认贡献后才可入主线。**关键约束：剩余 2 次测试集运行必须留给最终产品化方案的评估，不用于因子探索阶段的测试。**

### 11.3　项目总结

本项目从零搭建了一套工业级标准的 A 股中证 500 截面多因子指数增强研究系统，在严格的样本外测试纪律（测试集 ≤ 3 次）下完成了从数据治理到策略评估的完整链路。核心工程贡献在于：通过系统实验发现并确认了 QP 优化器的"序数 vs 基数"损耗机制，将这一常被忽视的优化层问题量化并解决；通过 PIT 集中化设计消除了最常见的财务因子未来函数风险；通过五类实验角色和测试集保护锁建立了可复现的研究纪律。

测试期三硬指标全 PASS（IR=0.645）证明了方法的样本外有效性，而 IR 从 2.150 衰减至 0.645 则提醒我们：在有限的历史窗口内取得的高 IR，在市场环境变化后存在真实的衰减风险。诚实面对这一衰减、系统性地诊断其根因，是本项目后续工作的核心任务，也是量化研究区别于过拟合的关键所在。
