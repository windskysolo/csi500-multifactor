## 一、检验代码自身的问题

### Bug 1 【P0·阻断性】高相关因子检测完全失效

**现象：** notebook 输出 `✅ 无高相关因子对（所有 |r| ≤ 0.70）`，但相关矩阵图中清晰可见多对 r > 0.70 的因子：

| 因子对 | 实际 Spearman r |
|---|---|
| `ivol_60d` & `vol_60d` | **0.93** |
| `roa` & `roe` | **0.91** |
| `q_roe` & `roe` | **0.88** |
| `q_roe` & `roa` | **0.80** |
| `accrual` & `cfp` | **-0.70**（恰在阈值边界）|

**根本原因推断：** `compute_factor_correlation()` 返回的 `corr_matrix` 其 index 与 columns 之间存在对齐错位，导致 `corr_matrix.loc[row_f, col_f]` 在所有非对角线位置均返回 NaN，`pd.notna(v)` 判断全部跳过，高相关对从未被记录进 `high_corr_pairs`。

**后果：** `roa / roe / q_roe` 三个测量几乎相同信息的因子全部进入合成，`ivol_60d / vol_60d` 同理，最终信号在"盈利质量"和"波动率"两个方向存在隐性双重或三重计权，严重扭曲合成权重。

**排查方式：**
```python
print(corr_matrix.index.tolist())
print(corr_matrix.columns.tolist())
# 直接验证
print(corr_matrix.loc["roa", "roe"])  # 应为 ~0.91
```

### Bug 2 【P1·逻辑错误】分组回测多空 Sharpe 符号方向硬编码

**现象：** `margin_ratio` 的 IC_IR = -0.374（因子方向为负，高值股票未来跑输），但其 `sharpe_ls = -1.22`，即"多空组合"持续亏钱，与 IC 信号方向直接矛盾。

**根本原因推断：** `batch_quintile_summary` 中多空组合固定计算 `Q5 - Q1`，未根据因子方向（`sign(IC_mean)`）自动翻转。对于负向因子，有效的多空应为 `Q1 - Q5`，当前实现方向相反。

**受影响的所有负向因子（已确认通过IC检验者）：**

| 因子 | IC_IR | 推断Sharpe真实值 |
|---|---|---|
| `turn_20d` | -0.665 | 实际Sharpe应为正值 |
| `ivol_60d` | -0.552 | 同上 |
| `vol_60d` | -0.527 | 同上 |
| `max_ret` | -0.518 | 同上 |
| `short_ratio` | -0.427 | 同上 |
| `margin_ratio` | -0.374 | -1.22 → 应为正值 |

**修正方式：**
```python
direction = np.sign(ic_mean)  # +1 或 -1
sharpe_ls = compute_sharpe(direction * (ret_q5 - ret_q1))
```

### Bug 3 【P1·逻辑存疑】时间错位测试方向待核查

**现象：** `ret_1m`（1个月反转因子）的错位测试结果为：原始 IC_IR = -0.247，错位后 IC_IR = +0.060，**符号发生翻转**，`ic_ir_drop = +0.187` 为正（未触发警告）。

对于反转因子，错位一期后其预测能力应衰减至 0 附近，但不应出现符号翻转并变为正值，这在经济上无法解释。

**根本原因推断：** `batch_shift_test` 中对因子 panel 的错位方向可能写反。检测未来函数（look-ahead bias）的正确做法是将因子向后错位（即用"提前一期拿到"的因子值测试），操作应为：
```python
factor_shifted = factor_panel.shift(1)  # 正确：向后错位，模拟提前获取
# 若误写为：
factor_shifted = factor_panel.shift(-1)  # 错误：向前错位，测试的是过去信息
```
若方向写反，则所有因子的错位测试实际上是在检验"用过去信息预测当期收益"，这对大多数因子仍有效，因此无法触发警告，导致该环节名存实亡。

### Bug 4 【P2·统计偏差】IC 检验期数不一致，未统一处理

**现象：** 大多数因子 n = 72 期，但以下因子实际有效期数缩减：

| 因子 | 有效期 n | 缺失期数 |
|---|---|---|
| `ivol_60d` | 69 | 3 |
| `vol_60d` | 69 | 3 |
| `mom_12_1` | 61 | **11** |
| `mom_6_1` | 66 | 6 |
| `ret_1m` | 71 | 1 |

同时这些因子的「最少股票数 = 0」，说明某些月份该因子在全截面均为 NaN。IC_IR 的分母 `ic_std` 是基于实际有效期计算的，期数越少、标准误越大，统计检验力越弱；但 `t_stat` 的计算若仍以固定 n=72 作为自由度，则 p 值会被人为压低，显著性被虚报。

**排查重点：** 确认 `batch_ic_test` 中 t 统计量的自由度是否使用了实际有效期 n，而非固定的 72。

## 二、因子分析结果本身的问题

### 问题 A 【P1·严重】因子有效覆盖率系统性偏低（~42-46%）

所有 27 个因子的有效率均在 42~46% 之间，意味着每个调仓期约有超过一半标的没有有效因子值。

- 若 Universe 为中证500（约500只），财务因子覆盖率应 ≥ 85%
- 若 Universe 为中证1000（约1000只），也不应低于 75%

**可能成因（按可能性排序）：**
1. 财务数据使用了报告期（`report_date`）而非公告日（`ann_date`）做 PIT 对齐，导致每个月末大量季报数据尚未"发布"，被合规过滤掉
2. 上游 `build_factor_panels` 的缺失值填充策略过于保守（如不允许向前填充财务数据）
3. 动态成分股表某些月份缺失，导致 Universe 本身就不完整

**后果：** 所有 IC 均基于约 450 只股票而非完整 Universe 计算，存在系统性样本选择偏差，IC 和 Sharpe 的绝对数值均不可信。

### 问题 B 【P1·严重】roa / roe / q_roe 三因子高度冗余，均被纳入合成

由相关矩阵图可见：
- `roa` & `roe`：r = **0.91**
- `q_roe` & `roe`：r = **0.88**
- `q_roe` & `roa`：r = **0.80**

三者几乎测量相同的信息（盈利能力）。加之 Bug 1 导致高相关检测失效，三因子全部入选，在 IC_IR 加权合成中，盈利方向的实际权重为其他类别因子的 **3 倍**，严重破坏多因子分散化的初衷。

### 问题 C 【P1·严重】ivol_60d 与 vol_60d 高度冗余，均被纳入合成

- `ivol_60d` & `vol_60d`：r = **0.93**，是矩阵中最高的非对角线值

ivol（特质波动率）与 vol（总波动率）在截面上几乎等价，两者共同纳入合成等同于波动率因子双重计权。建议保留 `ivol_60d`（学术文献支持更强，已剥离系统性风险），去除 `vol_60d`。

### 问题 D 【P2·重要】验证集方向翻转率 37%，成因混淆

10 个因子在 2022 年验证集出现 IC_IR 方向翻转，其中核心质量因子全部翻转：

| 因子 | 训练IC_IR | 验证IC_IR | 下降幅度 |
|---|---|---|---|
| `q_roe` | +0.587 | -0.159 | -0.746 |
| `roa` | +0.495 | -0.288 | -0.783 |
| `roe` | +0.495 | -0.200 | -0.695 |
| `asset_turn` | +0.385 | -0.326 | -0.711 |
| `gross_margin` | +0.342 | -0.170 | -0.512 |

**需要区分两类成因：**
1. **市场制度性失效（非因子本身问题）：** 2022 年 A 股单边下跌约 -20%，质量因子在全球范围内普遍失效（价值反弹、高杠杆股补涨），从 IC 时序图也可见 q_roe 在 2018 年（另一个熊市年）同样出现过平台期。这是市场状态切换，不代表因子无效。
2. **验证集统计检验力严重不足：** 有效期仅 11 期，对应 t 检验的置信度几乎为零，翻转结论本身就不可靠，不应作为排除因子的依据。

**建议：** 将验证窗口延伸至 2022-2024，或采用滚动扩窗方式验证，2022 单年结论参考意义有限。

**后果：** 三因子的 Sharpe 和 IC_IR 被训练集末期特殊行情虚抬，2022年后风格切换导致验证集立即翻转，与观测到的验证集失效直接呼应。

### 问题 G 【P3·方法论】final_include 筛选标准过于单一

当前选择逻辑：`effective_ic AND NOT shift_warning`

未纳入以下维度：
- **Sharpe_LS**：margin_ratio 因 Bug 2 导致 Sharpe = -1.22 仍被选入（修正后应为正，但若修正后仍为负，则应排除）
- **验证集方向翻转**：gross_margin 等方向翻转因子被无差别纳入
- **IC 时序稳定性**：累计 IC 曲线出现平台期或区间震荡的因子，其 IC_IR 均值掩盖了时序不稳定性

建议增加辅助筛选条件：Sharpe_LS（修正后）> 0.5，并对方向翻转因子降权（而非硬排除）。

### 问题 H 【P3·方法论】Forward Return 定义未显式核查

`compute_forward_returns()` 的实现未在 notebook 中展示，以下三点需要显式确认：

1. **原始收益 vs 超额收益：** 若使用原始月收益做 IC 检验，因子中会混入市场 Beta 信息，低估了因子的纯截面预测能力；对于中证500体系，应使用相对中证500指数的超额收益
2. **T+1 对齐严格性：** 调仓日当天收盘价是否已被排除，是否使用下一交易日开盘或收盘价
3. **首尾期处理：** 验证集最后一期 forward return 确认为 NaN（已提示 11 期有效），需确认训练集首期同样被正确处理
